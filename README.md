架構決策、實作紀錄與尚待部署驗證的項目請見 [架構改善與功能實作計畫](ARCHITECTURE-PLAN.md)。

動畫、音效、UI/UX、玩家互動與美術風格的研究提案及原始來源見[遊戲互動與沉浸感設計研究](docs/IMMERSIVE-EXPERIENCE-RESEARCH.md)；送禮達人已開始實作的項目、素材授權查核與暫緩項目見[送禮達人素材與實作進度](docs/GIFT-IMMERSION-PROGRESS.md)。

## 帳號與留言板

需使用 **Node.js 22.13 或更新版**。首次啟動前，在伺服器執行 `node admin.js init <管理者帳號>`，終端機會顯示一次性初始密碼；登入 `/login` 後可在 `/admin` 產生單次邀請碼與可分享的註冊連結、停用會員或提供密碼重設連結。邀請連結會自動開啟註冊表單並填入邀請碼。註冊不要求 Email 驗證。遊戲、留言與角色頁面都需要登入。帳號和留言存在 `data/afterhours.sqlite`，房間仍只存在記憶體。

留言板的新主留言會建立 `stanley021039/BGA` 的 GitHub Issue；回覆與管理者狀態變更也會送到同一張 Issue。正式服務須在伺服器的 `.env` 或環境變數設定 `GITHUB_TOKEN`，權限至少包含該倉庫的 Issues 讀寫。GitHub 確認成功後網站才顯示送出成功；結果不明會保留待確認提交，管理者可在 `/admin` 查核。舊版留言會匯入 SQLite，但不自動回補 GitHub。

會員可到 `/profile` 選用 10 位圖片角色，或上傳自己的 PNG／GIF／WebP 主角色圖片，再為它新增最多六個自訂名稱（1–20 字）的 PNG／GIF／WebP 表情。上傳不限制圖片像素寬高，單張檔案仍限 1 MB。遊戲座位顯示保存的角色圖片，未設定者使用預設角色。四款遊戲共用角色、回合提示、表情、文字彈幕與返回大廳入口；彈幕短暫顯示在遊戲畫面中，不保留遊戲留言區。各遊戲畫面仍各自實作。規格見 [圖片角色](docs/CHARACTER-ASSET-TEMPLATE.md)與[遊戲共用介面](docs/GAME-SHELL.md)。免費素材來源見 [素材來源備忘](docs/GAME-ASSET-SOURCES.md)。使用 Windows 開發與 Linux 部署可共用程式碼，但兩邊需各自安裝相同 Node.js 主版本。正式部署若讓帳密經公開網路傳輸，應在服務前配置 HTTPS；`PUBLIC_URL` 不會自行啟用 HTTPS。

## 目前包含的遊戲

- 德州撲克：2–6 人。
- 雷霆之路：2–4 人，含教學與可選擴充。
- 同頻俱樂部：3–12 人，多數答案得分；支援二選一、三選一、填空，以及生活／台灣題庫與自訂題目。詳見 `MAJORITY.md`。
- 送禮達人：3–8 人，秘密選禮與標記喜好，揭曉後同時計算送禮和收禮分數。內建 300 件原創禮物，均有圖示；可到 `/gifts` 投稿自訂禮物與選填圖片。房主可選玩家投稿禮物的抽取比例；詳見 [線上版規則](docs/GIFT-GAME.md)。

本機可執行 `npm start` 或 Windows 的 `start.bat`。直接連線模式讓朋友透過同一個 VPN／區網連到主機的 3000 埠；Cloudflare 模式則使用 HTTPS 網域。兩種模式的 `HOST`、`PUBLIC_URL` 與驗證方式見[部署指南](docs/DEPLOYMENT.md)。這是需要 Node.js 伺服器的專案，不能只用 GitHub Pages 執行多人遊戲。

Git 僅保存程式與執行所需資源；`data/`（玩家對局歷史）、`work/`（本機工具與暫存）、`reference-assets/`（整理用素材）、日誌與環境設定不會上傳。下方為各階段功能記錄；參考素材索引需搭配本機素材使用。


## 遊戲大廳

首頁 `http://localhost:3000` 可選擇雷霆之路、德州撲克、同頻俱樂部或送禮達人。建立房間後分享邀請，加入時會自動進入對應遊戲。

- `/race`：雷霆之路主遊戲機制、自製賽道測試版，2–4 支車隊。三輛車、四骰、指令、逐格移動、射擊、碰撞重擲、危險／損傷、三路板更新與終點。可加入練習電腦。每步 90 秒超時代操作。
- `/poker`：原有 2–6 人德州撲克。
- `/rules`：操作說明、版本差異、官方規則與素材來源；研究記錄另見 `RULES-SOURCES.md`。

雷霆之路的道路布局與標記數量配比尚未做到零售版一致，不含擴充，遊戲內已明確標示。官方產品圖用於識別，互動車輛與棋盤為自製功能圖形。

測試：`npm test` 包含兩款引擎；`node work/http-check.cjs` 是對執行中的 3000 伺服器執行雙客戶端測試（會建立測試房間）。

## 啟動

雙擊 `start.bat`（需要 Node.js 22.13 或更新版），保持視窗開啟。
本機開啟 http://localhost:3000 。朋友連上同一個 Radmin VPN 網路後，使用首頁的「複製連線網址」取得主機位址 。VPN 位址若改變，請使用頁面上的「複製好友連線網址」。

登入後建立房間，再將邀請網址或 6 碼代碼交給已註冊的朋友。房主可加入練習電腦或在至少兩人入座後發牌。2–6 人、起始 2,000 籌碼、盲注 10/20、無限注德州撲克。僅供娛樂，無金流。45 秒未操作會自動過牌或棄牌。籌碼歸零後可在局間補充。中途加入會等到下一局。

重新整理或重新登入可恢復原座位。房間與牌局保存在記憶體，關閉伺服器會清空；同一帳號在同一房間只會有一個座位。測試多人時請使用不同帳號。目前電腦玩家為簡單跟注練習對手。

## 連線問題

**Windows 直接連線模式**的伺服器監聽所有網路介面的 TCP 3000。若本機能開、朋友無法連線，先確認雙方 Radmin VPN 已在同一網路且對方顯示在線，再檢查 Windows 防火牆是否允許 Node.js 的 TCP 3000 入站。右鍵 `allow-vpn.bat` 選「以系統管理員身分執行」，僅需設定一次；規則只允許遠端 26.0.0.0/8 連到本機 Radmin 位址的 3000 埠。如果 VPN 位址變動，可在管理員 PowerShell 使用 `allow-vpn-firewall.ps1` 自動讀取新位址。不要關閉整個防火牆。不需要路由器轉發。**Cloudflare 網域模式**的 BGA 只監聽 `127.0.0.1`，由 Tunnel 對外連線，不需開放 TCP 3000 入站。

## 開發與驗證

同頻俱樂部支援中途加入：新玩家先觀看當前題目，下一題才加入作答並從 0 分開始；當前題的參與人數、扣分門檻及等待交卷條件不變。等待期間可以預備題目或送出表情。最後一題才加入的玩家等下一局入局，不參與本局勝者排名。德州撲克中途加入者在下一手牌開始參與；雷霆之路需等下一場開房。送禮達人需等本局結束才能加入下一局。

房主可使用「管理玩家」踢人，操作前會顯示確認警告，被踢者收到通知且不能以相同帳號重新加入該房間。雷霆之路棋盤上的金色虛線分隔後、中、前三段；分界會隨道路延伸而更新。

`npm start` 啟動；`npm test` 執行遊戲規則、帳號、HTTP 與 GitHub 模擬 API 測試。遊戲資源全部本機提供；GitHub Issue 同步需要網際網路。

## 對局歷史與房間網址

大廳與遊戲頁的「對局歷史」可開啟 `/history`。雷霆之路每場比賽、德州撲克每手牌各自一份記錄，保存在 `data/history/`，不因開新局、房間過期或伺服器重啟刪除。備份請複製整個資料夾。舊版未記錄的對局無法追溯補回。

格式為版本 1 JSONL，包含開局前完整狀態、設定與入房記錄、遊戲引擎版本雜湊及原始碼、每次操作的來源／玩家／輸入／成功或失敗、操作前後狀態、內部結算順序、隨機抽樣與部分中間棋局。伺服器在執行操作前後同步寫入；底牌、完整牌堆、隱藏危險及損傷標記保存在本機記錄中，不保存登入 token。寫入失敗會暫停該房間後續操作。這些檔案是回看資料，不是恢復房間登入用的存檔。

回看頁提供棋局、逐步選取、原始記錄與完整 JSON 下載；進行中的對局不開放完整資料。結束後會顯示完整資訊，包括底牌與隱藏地形。意外中斷的對局於服務重新啟動後標為中斷存檔，保留已落盤資料。

HTTP 連線位址由主機自動偵測，或在 `.env` 設定 `PUBLIC_URL`。各房間使用 `/race/ABC123`、`/poker/ABC123`、`/majority/ABC123` 或 `/gift/ABC123`。已入房的會員可以直接返回座位；新朋友登入後再加入。教學仍使用 `/race?learn=1`，送禮達人玩法可在 `/gift?learn=1` 查看。

連線中斷後遊戲頁會自動重試；同一帳號重新登入或從房間連結進入時會找回原座位。若輪到自己且離線超過 15 秒，重連時可取得一次最少 15 秒的操作緩衝；已由逾時計時完成的動作不會回復。房主踢出的玩家不可重連，伺服器重啟後記憶體房間消失，也無法恢復。

大廳「找一桌加入」會列出目前開啟的房間，顯示遊戲、房號、席位及進度，並可直接加入或返回自己的座位。列表定時更新，亦可手動重新整理；賽車開局後不接受新玩家，同頻俱樂部開局後可中途入房並從下一題參與，撲克可在對局中入座並等待下一局，送禮達人需等本局結束。房間資料在服務記憶體中，重啟後列表會清空。

## 本機設定

可將 `.env.example` 複製為 `.env`，設定 `PORT`、`HOST`、`PUBLIC_URL`、`HISTORY_DIR`、`COMMUNITY_DIR`、`DB_FILE` 與 `GITHUB_TOKEN`。`.env` 及資料目錄不納入 Git；系統環境變數優先於 `.env`。未設定 `PUBLIC_URL` 時自動偵測 VPN 位址，邀請按鈕使用偵測結果。Windows 防火牆工具同樣自動偵測網卡位址，不需將私人 IP 寫進程式。

`PUBLIC_URL` 僅設定邀請連結來源，不會自行啟用 HTTPS。更改 `.env` 後重啟服務才會生效；重啟會清空記憶體中的房間，已保存的歷史、留言與題庫會保留。
