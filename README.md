# Afterhours 好友桌遊空間

## 目前包含的遊戲

- 德州撲克：2–6 人。
- 雷霆之路：2–4 人，含教學與可選擴充。
- 同頻俱樂部：3–12 人，多數答案得分；支援二選一、三選一、填空，以及生活／台灣題庫與自訂題目。詳見 `MAJORITY.md`。

需要 Node.js 18 或更新版；執行 `npm start` 或 Windows 的 `start.bat`，開啟 `http://localhost:3000`。朋友透過同一個 Radmin VPN 連到主機的 3000 埠。這是需要 Node.js 伺服器的專案，不能只用 GitHub Pages 執行多人遊戲。

Git 僅保存程式與執行所需資源；`data/`（玩家對局歷史）、`work/`（本機工具與暫存）、`reference-assets/`（整理用素材）、日誌與環境設定不會上傳。下方為各階段功能記錄；參考素材索引需搭配本機素材使用。


## 遊戲大廳（2026-09-13 更新）

首頁 `http://localhost:3000` 可選擇「雷霆之路：末路狂飆」與「德州撲克」。建立房間後分享邀請，加入時會自動進入對應遊戲。

- `/race`：雷霆之路主遊戲機制、自製賽道測試版，2–4 支車隊。三輛車、四骰、指令、逐格移動、射擊、碰撞重擲、危險／損傷、三路板更新與終點。可加入練習電腦。每步 90 秒超時代操作。
- `/poker`：原有 2–6 人德州撲克。
- `/rules`：操作說明、版本差異、官方規則與素材來源；研究記錄另見 `RULES-SOURCES.md`。

雷霆之路的道路布局與標記數量配比尚未做到零售版一致，不含擴充，遊戲內已明確標示。官方產品圖用於識別，互動車輛與棋盤為自製功能圖形。

測試：`npm test` 包含兩款引擎；`node work/http-check.cjs` 是對執行中的 3000 伺服器執行雙客戶端測試（會建立測試房間）。

## 啟動

雙擊 `start.bat`（需要 Node.js 18 或更新版），保持視窗開啟。
本機開啟 http://localhost:3000 。朋友連上同一個 Radmin VPN 網路後，使用首頁的「複製連線網址」取得主機位址 。VPN 位址若改變，請使用頁面上的「複製好友連線網址」。

輸入暱稱，建立房間，再將邀請網址或 6 碼代碼交給朋友。房主可加入練習電腦或在至少兩人入座後發牌。2–6 人、起始 2,000 籌碼、盲注 10/20、無限注德州撲克。僅供娛樂，無金流。45 秒未操作會自動過牌或棄牌。籌碼歸零後可在局間補充。中途加入會等到下一局。

重新整理可恢復原座位。房间與牌局保存在記憶體，關閉伺服器會清空；同一瀏覽器共用一個身分，測試多人時請用不同瀏覽器或無痕視窗。目前電腦玩家為簡單跟注練習對手。

## 連線問題

伺服器監聽所有網路介面的 TCP 3000。若本機能開、朋友無法連線，先確認雙方 Radmin VPN 已在同一網路且對方顯示在線，再檢查 Windows 防火牆是否允許 Node.js 的 TCP 3000 入站。右鍵 `allow-vpn.bat` 選「以系統管理員身分執行」，僅需設定一次；規則只允許遠端 26.0.0.0/8 連到本機 Radmin 位址的 3000 埠。如果 VPN 位址變動，可在管理員 PowerShell 使用 `allow-vpn-firewall.ps1` 自動讀取新位址。不要關閉整個防火牆。不需要路由器轉發。

## 開發與驗證

`npm start` 啟動；`npm test` 執行牌型、邊池、短額 All-in、私牌與隨機完整牌局測試。無第三方執行套件，前端資源全部本機提供，無需網際網路。

## 對局歷史與房間網址

大廳與遊戲頁的「對局歷史」可開啟 `/history`。雷霆之路每場比賽、德州撲克每手牌各自一份記錄，保存在 `data/history/`，不因開新局、房間過期或伺服器重啟刪除。備份請複製整個資料夾。舊版未記錄的對局無法追溯補回。

格式為版本 1 JSONL，包含開局前完整狀態、設定與入房記錄、遊戲引擎版本雜湊及原始碼、每次操作的來源／玩家／輸入／成功或失敗、操作前後狀態、內部結算順序、隨機抽樣與部分中間棋局。伺服器在執行操作前後同步寫入；底牌、完整牌堆、隱藏危險及損傷標記保存在本機記錄中，不保存登入 token。寫入失敗會暫停該房間後續操作。這些檔案是回看資料，不是恢復房間登入用的存檔。

回看頁提供棋局、逐步選取、原始記錄與完整 JSON 下載；進行中的對局不開放完整資料。結束後會顯示完整資訊，包括底牌與隱藏地形。意外中斷的對局於服務重新啟動後標為中斷存檔，保留已落盤資料。

HTTP 連線位址由主機自動偵測，或在 `.env` 設定 `PUBLIC_URL`。各房間使用 `/race/ABC123` 或 `/poker/ABC123`。有該房間身分的瀏覽器可直接返回；新朋友會先到大廳填暱稱加入。瀏覽器分房間保存座位，進入其他房間不會誤連上最後一次的房間。教學仍使用 `/race?learn=1`。

## 本機設定

可將 `.env.example` 複製為 `.env`，設定 `PORT`、`HOST`、`PUBLIC_URL`、`HISTORY_DIR` 和 `COMMUNITY_DIR`。`.env` 及資料目錄不納入 Git；系統環境變數優先於 `.env`。未設定 `PUBLIC_URL` 時自動偵測 VPN 位址，邀請按鈕使用偵測結果。Windows 防火牆工具同樣自動偵測網卡位址，不需將私人 IP 寫進程式。

`PUBLIC_URL` 僅設定邀請連結來源，不會自行啟用 HTTPS。更改 `.env` 後重啟服務才會生效；重啟會清空記憶體中的房間，已保存的歷史、留言與題庫會保留。
