# 組隊房間與遊玩畫面分離

2026-10-12，1.28.1；固定程式 tree `3f50e81adfab7409f9d14041e9b65bd9bc0debc5`。最終測試、審查與部署結果見 [PR #96](https://github.com/stanley021039/BGA/pull/96) 的驗收留言。

## 已確認需求與實作

- 十款組隊房間以雷霆之路插畫／介紹卡為模板；其他九款使用共用 `room-waiting.js/css`，雷霆保留原始模板。
- 等待時只保留介紹、入座名單、邀請、房間設定與開始／測試夥伴操作。回合、分数、骰子、車況、賽道／牌局紀錄、猜題與作畫舞台只在對局中顯示。
- 同頻、送禮及畫猜的設定舞台在等待時放進操作欄，開局時還原原舞台位置；重複 snapshot 不移動同一節點，以免失去焦點。
- 瞎掰王保留難度 fieldset／checkbox 與看身分時間 select，移除保存按鈕，change 後自動提交；至少選一個難度，無效取消會還原原選取並提示。傳情畫意切換題庫後直接提交。沿用其他遊戲既有的自動設定與錯誤／重試流程。
- HTTP 只增加兩個明確允許的靜態資源，沒有改遊戲規則、伺服器狀態資料或資料庫 schema。

## 實際驗收範圍

隔離 Linux 伺服器、合成帳戶及 headless Chrome：1440×900／390×900、日／夜主題，每款四個等待布局共40個，無頁面水平溢出或可見遊玩資訊；十次真實開始 API 後介紹卡隱藏、遊玩狀態出現。另驗瞎掰王真實自動設定、503失敗／再次變更恢復、最後一個難度不可取消；同頻／送禮設定欄位在輪詢時保留焦點及真實自動提交；五款訪客設定隱藏，傳情畫意自動題庫提交。

新增回歸測試涵蓋有效／無效選項、忙碌時保留最新設定、序列化、錯誤與退出取消，以及 HTTP MIME／精確 source。首轮旧代码测试发现 optional module 在既有声音 harness 未提供的回归，已修正并 focused 重验通过。完整本地测验曾在既有 market-image 大 BLOB 测验遇 `/tmp` tmpfs 空间不足的 SQLite I/O错误；改用磁碟上的隔離 TMPDIR 復驗，不更動產品配額或正式資料。

限制：桌機／手機均为瀏覽器 viewport，非真人觸控設備；未宣稱全部遊戲階段、讀屏、每種輸入設備或第三方影片播放都驗過。作畫 renderer／transport 沒有修改，其途中持筆與觀看者接收另以原生瀏覽器補驗，結果記於 PR 驗收留言。
