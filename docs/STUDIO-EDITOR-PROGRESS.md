# 繪畫編輯器擴充進度

更新：2026-10-02。目標是讓帳號圖庫的獨立繪畫頁面能製作角色、表情和送禮達人圖片，並可重複使用圖庫作品。這次不變更 SQLite schema 或原有的私人存取權限。

| 步驟 | 狀態 | 結果 |
| --- | --- | --- |
| 色彩與常用工具 | 完成 | 依使用者提供的設計參考，採圓形色輪、下方亮度與透明度滑桿、目前色塊與滴管；另有色號、最近 10 色。畫筆、橡皮擦、直線、矩形、圓形／橢圓、填滿、復原／重做、清空、PNG 下載。 |
| 寬畫布與照片 | 完成 | 512 × 256 透明畫布；一次匯入最多八張照片，支援順序、透明度、顯示狀態、完整放入／填滿裁切。照片層在筆跡下方。 |
| 上傳圖片去背 | 完成 | 相近純色背景可從邊角自動偵測，或在畫布點選背景色；連通區域去除、容差調整、復原與還原原圖。處理在瀏覽器中進行，不傳送原始照片給外部服務。 |
| 帳號圖庫串接 | 完成 | 儲存成合成的 512 × 256 PNG；原有作品也能載入為新圖層，再用於角色、表情或禮物。 |

| Linux 與 shhuang.cc | 完成基本驗證 | Linux 獨立版本目錄 `npm test` 116/116；部署前 SQLite 線上備份完整性 `ok`，schema v8、帳號 4 筆；切換到 `e040927` 後資料狀態一致，網站與 Tunnel 都是 `active`。從 Windows 經公開 HTTPS 驗證新版腳本、色輪樣式、登入頁與 robots 皆為 200，匿名 `/studio` 導向登入、圖庫 API 回 401。 |

去背以色彩與連通區域判斷，適合白底或單純背景。複雜照片、半透明邊緣或背景與主體同色時可能殘留或誤刪；可改用點選、調低容差，或還原原圖。各照片在目前頁面保留為圖層；重新整理後只保留已存入帳號圖庫的合成圖片，不保留圖層工程檔。每張來源照片限制 12 MB，直接上傳圖庫及合成圖的伺服器限制仍為 1 MB。

正式資料庫備份為 `shared/backups/pre-e040927-20261002-051221.sqlite`。公開帳號實際操作色輪、圖層及去背仍待使用者驗收；本機背景瀏覽器已完成這些互動的端到端測試。依使用者指示直接重啟服務，原記憶體房間會隨之清空。
