# 繪畫編輯器擴充進度

更新：2026-10-02。目標是讓帳號圖庫的獨立繪畫頁面能製作角色、表情和送禮達人圖片，並可重複使用圖庫作品。這次不變更 SQLite schema 或原有的私人存取權限。

去背以色彩與連通區域判斷，適合白底或單純背景。複雜照片、半透明邊緣或背景與主體同色時可能殘留或誤刪；可改用點選、調低容差，或還原原圖。各照片在目前頁面保留為圖層；重新整理後只保留已存入帳號圖庫的合成圖片，不保留圖層工程檔。每張來源照片限制 12 MB，直接上傳圖庫及合成圖的伺服器限制仍為 1 MB。WebP 降容會有畫質損失；若降容後仍超限，須減少照片細節或圖層。
