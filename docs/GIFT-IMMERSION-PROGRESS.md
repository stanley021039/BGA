# 送禮達人：素材可行性與逐步實作

更新日期：2026-10-02。此表只追蹤送禮達人的互動、聲音與美術改善；其他遊戲沿用[設計研究](IMMERSIVE-EXPERIENCE-RESEARCH.md)的方向，待這一款驗證後再安排。素材可以從不同網站挑選，但每一件都要先確認**可取得、授權可用、適合現有介面**；沒有合適素材的演出先列出並暫緩。本站不直接複製參考遊戲的視效或音樂。

Kenney 的[官方支援說明](https://kenney.nl/support)稱其素材頁資產可用於商業專案且不強制署名；真正選用時仍保存**該下載包內授權檔、素材名稱及官方來源**。若未來從 OpenGameArt 或 Freesound 選取個別作品，逐件核對授權與署名後才列為「可用」；搜尋頁或免費標籤不算查核完成。玩家投稿圖片只按現有用途展示，不當作本站可重新編輯或預設採用的美術素材。

Noto 圖示來自 [googlefonts/noto-emoji](https://github.com/googlefonts/noto-emoji) 的 `2D/png/72`，固定 commit `e20cbc2bbec1926686be9f9bee7d1d2cfa1fea0e`。官方 README 說明圖像資源採 Apache 2.0；`public/assets/gifts/noto/` 保留來源、原始授權聲明與完整授權文字。190 張 PNG 合計約 0.55 MB，只在頁面需要時載入。沒有改動玩家投稿圖或重製第三方遊戲卡面。
