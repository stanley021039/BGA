# 同頻俱樂部「三選一」互動卡：九視角討論與試玩

研究日期：2026-10-02。這是**玩法提案與現況試玩紀錄，卡片尚未實作或部署**。「三選一」是同頻俱樂部的題型，不是獨立遊戲。九位是依[公開來源建立的 AI 評審視角](DESIGN-COUNCIL-ROLES.md)，不是來源人物本人；本文件中的卡片名稱、規則、秒數及取捨均是本站推論。研究範圍先限三選一；二選一與填空題維持現行玩法。

## 現況與實測邊界

現行規則為 3–12 人秘密作答，出題者也投票；120 秒或全員交卷即揭曉。只有**唯一最多票且至少兩人同選**的選項，其投票者各得 1 分；平票或全部分散則沒有基本分。作答期間只公布交卷人數，玩家可在揭曉前撤回自己的答案。出題、投票、分組、揭曉與結算由伺服器的 `MajorityRoom` 執行。[現行規則](../MAJORITY.md)。

主持者另用隔離的本機服務、臨時 SQLite 與三個測試帳號，透過**背景執行的真實 Chrome／Playwright 畫面**完成三題三選一，未佔用使用者前景視窗、未操作公開網站，也未碰正式資料：

| 題 | 投票分布 | 實際結果與觀察 |
| --- | --- | --- |
| 1 | 2–1 | 多數兩人各 +1；三個帳號都完成交卷與揭曉。 |
| 2 | 1–1–1 | 基本分全為 0；結果頁立即顯示三組票數、各自姓名與零分原因。逐組焦點仍會播放，零分局顯得偏慢。 |
| 3 | 3–0–0 | 三人各 +1，三題後正常結算。 |

九個 AI 視角則各自用**遊戲引擎模擬**至少三題、檢視前端程式；部分另檢視上述真實瀏覽器截圖。這不是九名真人好友在公開網域上試玩，不能用來證明社交趣味或平衡已經成立。現行網站**沒有卡片**，所以卡片效果尚未經遊玩驗證。

共同觀察：出題者挑題時，其餘人主要等待；選答案後至揭曉只能看交卷進度，社交操作主要是既有角色表情和文字彈幕。結果頁對票數與姓名交代完整，但在平票時逐組焦點較拖；某一人獨選時也可能被全桌看見而尷尬。選項點擊會重繪 `#stage`，鍵盤焦點可能消失，若新增卡片 UI 要一起修正。

## 九視角的第一輪與交叉評審

| 視角 | 試玩後的主張與反對條件 | 第二輪取捨 |
| --- | --- | --- |
| 情緒與玩法；參考 [Mark Rosewater](https://magic.wizards.com/en/news/making-magic/twenty-years-twenty-lessons-part-1-2016-05-30) | 幫助朋友與設下小圈套要有被猜中／反將的情緒；不要把落單者變成固定笑柄。 | 認為只給出牌者獎勵時「陷害」感偏弱；可留待第二版研究**目標收到私人挑戰提示**，不公開點名或扣分。這會改變秘密階段，先不納入首版。 |
| 桌遊節奏；參考 [Jamey Stegmaier](https://stonemaiergames.wordpress.com/about/) | 不要為出牌再增加一個全桌等待點；平票時的卡分須獨立說明。 | 支持與答案同次鎖定、揭曉自動結算；反對揭曉後才輪流出牌。曾提每題全桌限一張，因會引出搶先提交或抽籤規則，首版先不採用。 |
| 卡片資訊；參考 [Daniel Solis](https://danielsolisblog.blogspot.com/2024/02/three-principles-of-card-design.html) | 卡名、受益者、觸發條件與限次應先於裝飾；平票票條要靠近零分原因。 | 支持把基本分、卡分拆開；12 人不展開 12 張大卡，細節放入可展開清單。 |
| 新手 UX；參考 [Celia Hodent](https://celiahodent.com/gamers-brain-ux-onboarding/) | 第一輪想先揭曉再讓玩家出牌，讓新手看懂局勢；卡片應明確標「可選」。 | 看到最後一人交卷即結算、事後出牌會必中後，改支持**作答時可選暗牌，預設不出卡**；只在選完答案後露出短教學。 |
| 動效與音效；參考 [Jan Willem Nijman](https://jwaaaap.substack.com/p/disc-room-game-feel) | 卡片應依附既有結果區與玩家分數，不遮住票型；短音維持預設靜音。 | 支持暗選、揭曉時短暫局部提示；多張卡同步呈現，不排隊播放，減少動態時直接顯示完整文字。 |
| 社交動機；參考 [Nicole Lazzaro](https://www.nicolelazzaro.com/the4-keys-to-fun/) | 曾提出私人耳語推薦選項，接受者可忽略；不應公開其是否聽從。 | 先選低傷害的同選／異選卡：比私訊容易理解，避免誘導跟票與新權限面。觀察有無自發表情、彈幕與談論；現行確有**文字彈幕**，它不是持久聊天紀錄。 |
| 懷疑型玩家；參考 [Quintin Smith](https://videosgames.wordpress.com/2012/04/27/hard-copy-pt-3/) | 直接扣掉領先者 1 分會大幅改變三題短局；會否從猜朋友變成圍毆某人？ | 提議先讓「援手」同選時給**目標** +1，「唱反調」異選時給**出牌者** +1，目標不失分；異選較容易猜中，須量測平衡。 |
| Node／瀏覽器工程；參考 [Matt DesLauriers](https://github.com/mattdesl/canvas-sketch/blob/master/docs/animated-sketches.md) | 伺服器必須持有卡牌、目標、剩餘張數與結算；重連不得重播。 | 認為直接改目標 ±1 更貼近「互相幫害」，但同意首版先用較低風險機制測試；卡須與答案原子提交，基本分與卡分分開存。 |
| 資安；參考 [Troy Hunt](https://www.troyhunt.com/understanding-xss-input-sanitisation/) | 不可由前端指定出牌者或查到他人未公開答案；中途加入、撤回、重送、踢人須有明確規則。 | 偏好作答時的簡單暗牌：比私訊或事後出牌少一個權限與洩密面。 |

來源文章只支持各視角的**一般設計理念**，不表示作者提出、玩過或認可本站卡片。上表的第二輪是 AI 視角間對候選方案的交叉評論。

## 建議先做的可玩原型：可選的「默契卡」模式

房主在等待室決定這局是否啟用卡片；**預設仍可玩原本的三選一**，卡片不套用二選一或填空。啟用時，每人每局有一張「援手」、一張「唱反調」，每題最多使用其中一張，也可整局都不用。選答案後才展開可選卡與指定**本題另一位已入座、尚未被踢出的參與者**；同一次交卷原子鎖定答案、卡種與目標。最後一人交卷仍可立即揭曉，不另設出牌階段。

| 卡片 | 揭曉時的候選效果 | 為何是候選而非定案 |
| --- | --- | --- |
| **援手** | 出牌者與目標**最終答案相同**，目標得「卡片 +1」。不改兩人的投票或多數判定。 | 能真實幫朋友；平票仍可能有人靠卡拿分，須明確與多數票基本分區分。若同一目標收到多張成功援手，本題卡分最多 +1。 |
| **唱反調** | 出牌者與目標**最終答案不同**，出牌者得「卡片 +1」，目標不扣分。 | 有猜心／唱反調感，卻不奪走他人的基本分；三個選項近似隨機時異選機率高於同選，可能過強。測試時比較「異選即成功」與「異選且目標拿到基本分才成功」兩種門檻，不在研究階段宣稱已平衡。 |

若真要更直接的**陷害**，可另做房主可選的強對抗原型：交卷時暗選目標，揭曉後抵銷其本題已獲得的 1 個基本分、最低 0；相對的援手可補原本 0 分者 1 分。這樣的卡有真實攻防，但一張就可能把四人短局的「1–2–1–1」改成四人平手，也容易連續針對領先者；**目前不建議直接上線**。揭曉後才出有分數效果的卡同樣暫緩，因已知答案與排名會讓決策變成必中補刀，還要等全員再操作一次。私人耳語與卡牌反制也留到獨立測試，不在首版混入。

### 需要寫死的結算與互動邊界

1. 先按現行三選一計算唯一最大組的**基本分**，再按最終答案結算**卡片分**，最後加總。結果頁顯示「基本 +0／卡 +1／本題 +1」，平票文案應是「多數票無人得分；卡片另計」，不能仍寫「無人加分」。卡片不改票數、獲勝組或他人的答案。
2. 首次交卷即鎖定「出卡或不出卡」、卡種與目標。收回答案只收回答案，可換答案再交，但不能改卡；若截止前未重交，卡失效且仍消耗。這些效果要在提交前寫清楚。若任一方被踢出，卡失效；中途加入者不能參與這題或被指定。
3. 交卷前別人只看見已交卷狀態；本人可看到自己的卡已鎖定、剩餘張數，不得查到他人卡種／目標／命中與否。揭曉時一次公布文字結果。卡牌事件必須由伺服器驗證登入座位、時機、限次、目標；同一操作 ID 重送只能結算一次；重連拿到靜態結果而非再次加分／播音。未揭曉或中斷房間的歷史不得公開秘密答案與卡。
4. 首題選好答案後才給一句提示「卡可不出」，預設主按鈕「鎖定答案（不出卡）」。選卡後才顯示目標與簡短觸發條件，主按鈕改為「鎖定答案並暗出卡」。原生按鈕、可見焦點、`Tab` 順序與 `Enter`／`Space` 操作要完整；點選答案時保留焦點，手機不讓卡片蓋住交卷鈕。
5. 卡面用現有 HTML／CSS 及圖符配**文字**，不需新插畫。揭曉先顯示完整票型，再於得分旁標示卡分；詳細「誰對誰、是否成功」可展開。局部動效最多約半秒且不阻擋下一題，使用現有短音但**預設靜音**；減少動態、背景分頁與重連直接顯示文字結果，不重播音效或焦點。

## 真正決定是否做、怎麼調整的試玩

先做可關閉的規則原型，再請至少兩組真人好友各玩一次原版與卡片版；三人短局與 6–8 人局都要測 2–1、1–1–1、2–2、全員同選、未交卷／重連。每局記錄：每人每題是否能說明基本分與卡分、援手／唱反調命中率、選卡與交卷耗時、是否一直指定同一人、被指定者是否覺得有趣且願意續玩、表情／彈幕或自發談話是否增加。若異選獎勵明顯較容易，可改為「目標須在原多數組」或降低可用次數，再比對一次。若有人將平票卡分誤認成多數票分、不能解釋自己的分數、等待變長或被反覆針對，就先修規則／呈現，不擴充攻擊卡。

此研究用的資源已足夠：現有三選一引擎、題卡與得分 UI、角色表情／文字彈幕、CSS 卡框、已入庫的 Kenney CC0 短音；不需先找免費插畫。下一步是規則原型與**真人**試玩，而非在文件中把候選方案標成已完成。
