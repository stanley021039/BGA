# 效能量測紀錄

以 `tools/qa/perf-measure.cjs` 量測（Playwright＋Chrome，1440×1000）。每個場景先以全新瀏覽器設定檔「冷載入」，再於同一設定檔「再次進入」。位元組為線上傳輸量（含標頭）；測試站未經 Cloudflare 壓縮，所以數字會比正式站大。

```bash
PERF_BASE=http://127.0.0.1:3150 PERF_CREDENTIALS_FILE=login.json node tools/qa/perf-measure.cjs
```

憑證檔只能放測試帳號：腳本會用它建立並離開 Quacks／MusicQuiz 房間。
