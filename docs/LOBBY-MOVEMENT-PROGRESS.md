# 好友大廳角色移動

更新：2026-10-02。

| 步驟 | 狀態 | 結果 |
| --- | --- | --- |
| 大廳場地與角色 | 完成 | 首頁在遊戲清單前加入共用場地，直接顯示帳號目前選用的角色圖片與暱稱；自己有橘色名稱標示。角色位置限制在場地內，移動時有簡短步伐效果；減少動態偏好會關閉該動畫。 |
| 操作 | 完成 | 點選場地後可用方向鍵或 WASD，桌機及觸控裝置亦可按住四個方向按鈕。輸入欄、連結及一般按鈕取得焦點時不攔截鍵盤。 |
| 多人同步 | 完成 | 登入會員讀取 `/api/lobby`，移動時送 `/api/lobby/move`；伺服器以登入身分決定角色，驗證方向並限制移動速度及範圍。前端約 1.8 秒輪詢，移動時最多每 100 毫秒傳送一次；背景分頁停止更新。連續 15 秒不在大廳便從在線清單消失。最多同時顯示 80 位會員。位置僅保存在伺服器記憶體，服務重啟後重新入場。 |
| 安全與驗證 | 完成 | API 僅對登入會員開放，客戶端不能指定別人的帳號或角色圖片，暱稱用純文字呈現；HTTP 及單元測試驗證未授權、方向驗證、邊界與逾時。Windows 全套 `npm test` 117/117；隔離背景 Chrome 實測方向鍵、按住方向按鈕、手機 390px 版面與無橫向溢出。 |
| Linux 與 shhuang.cc | 待部署 | 先在 Linux 獨立版本目錄測試，再備份正式 SQLite、切換版本並檢查 HTTPS 與 Tunnel。 |

此版是可行走的共用場地。家具碰撞、房間入口互動、表情或聊天與更高頻的多人同步尚未加入；目前角色會穿越其他角色。若將來同時在線人數增加，可依實測連線量評估 WebSocket，現階段維持短輪詢以沿用既有部署。
