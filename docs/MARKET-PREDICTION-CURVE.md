## 新、舊場次的界線

升級前已存在的所有場次（包括仍開放的場次）保持原本 v1／v2 六區間、截止、0% 和局及 +5／−1 分。既有票、結算、更正、積分和圖片審核不改寫。只有升級後新建立的場次使用 v3 數值曲線。

每位會員可選 −10% 至 +10%，每格 0.1 個百分點，預設 0%；預設值不是已送出預測。截止前可修改，版本衝突必須重新整理後明確重送。台北時間目標交易日 00:00 起截止，前一天 23:59 整分鐘仍可提交。取得 SQLite 寫入鎖後才判斷截止，並沿用帳號／管理權限。

## 每日參考分布 F

開場 transaction 在插入可見場次前，一次凍結規則、來源、時間、參數與 201 個機率。之後新增行情、重啟、投票、結算或更正，均不重新估計該場 F。

- 格點 xᵢ 為 −10、−9.9、…、+10，單位為百分點
- 機率 pᵢ 與 exp(−xᵢ²／(2τ²)) 成正比，正規化總和為 1；永遠以 0 為中心、對稱單峰
- 最多取開場前已完成、已取得且交叉核對的最近 252 筆官方日漲跌幅；樣本日期必須早於目標交易日，資料實際取得時間不能晚於凍結時間。待覆核資料不入樣本
- 完成門檻為該樣本日期台北 14:00；次日早上取得的歷史回補可用，當日 13:00 的資料不能因為日期相符就使用
- 有至少 30 筆時，τ = 1.4826 × median(|r − median(r)|)，限制於 1～5 個百分點。少於 30 筆時明確使用固定 τ=2 先驗，記錄 insufficient-history；不假裝已有完整一年校準
- 凍結來源保留每筆日期、漲跌幅、fetchedAt、來源網址、語意 fingerprint 及原交叉核對證據 JSON。介面顯示來源／樣本數／區間／凍結時間及先驗狀態

這是遊戲計分使用的參考分布，不是真實市場機率或投資預測。現有行情流程只補可用歷史；不因缺少 252 筆阻擋開場，也不以未來資料補滿。

## 公式與「期望 0」的精確意思

預測為 x、實際官方漲跌幅為 y：

- K(x,y) = exp(−(x−y)²／8)，固定寬度 2 個百分點
- μ(y) = Σ pᵢ K(xᵢ,y)
- D = 1 − min（格點 z 的 μ(z)），在開場前就凍結
- 分數 S(x,y) = 100 × [K(x,y) − μ(y)] ／ max(D, 1−μ(y))

給定同一實際 y，越接近 y，原始分數越高；等距分數相同。若實際恰好位於合法格點，峰頂在猜中處；非格點實際值則最近合法格點最高。離得很遠可以負分。對稱單峰參考的 ±10% 精準命中可達 100，中央精準命中比較低；不是每個交易日都能拿到 100。

K≤1、分母≥1−μ，故任何有限實際值的分數都不超過 100。實際超過 ±10% 時照真實 y 計算，不夾到端點，也不對個人分數事後截頂。實際 0% 在新制照曲線計分。非常遠的值可因浮點指數下溢或微分量化同分，不能宣稱所有差距在顯示上都嚴格不同。

「期望 0」只指每次按該場凍結 F 隨機抽出預測 xᵢ，對任何固定實際 y 都有 ΣpᵢS(xᵢ,y)=0。它不是 −10～+10 均勻亂猜的期望，也不是所有策略、真正玩家平均或真實市場的期望。

## 精度、下界與更正

新制 1 分 = 1,000,000 整數微分；單場四捨五入至六位小數，中點遠離零，負零轉為 0。顯示可取兩位，但帳本不以顯示值累加。量化後參考期望不再數學精確等於零，偏差絕對值最多 0.0000005 分。測試另留極小浮點容許誤差。對每個已知 y 的下界是合法格點分數的最小值；界面可顯示該場示意／實際曲線範圍，不承諾固定最低分。公式在本版參數界限內仍落於 −100～100，DB 對分錄保存此安全界限。

每次更正沿用原本凍結 F，以新 y 重算。先用相反整數撤銷前版已存的 points_units，再寫新 award；撤銷不重跑舊公式。來源、結算、所有分錄、結果版本和 requestId 收據在同一 transaction 原子提交。重送不重複加扣分，失敗完全回滾。

## 圖片相容與響應式規則

五等分為 [−10,−6]、[−6,−2]、[−2,+2]、[+2,+6]、[+6,+10]，插圖中心為 −8、−4、0、+4、+8。這些是裝飾位置，不把原上傳區間改成新的圖片資格。

- −8：只抽原 crash；−4：只抽原 fall；+4：只抽原 rally；+8：只抽原 surge
- 中央：原 dip 或 rise 的聯集，顯示該張圖片原本的小跌／小漲資格；不改寫已審核規則，不暗示該圖可用於所有中央數值
- 仍須已審核，且目標交易日星期符合原規則。作者、配額、投稿和批次審核機制不變
- 每次進入、換日期或明確重抽，固定選取五個槽；無候選保留佔位。全部五張非空圖預載，縮放只改 CSS 可見性，不請求、不重抽、不換身份
- 五個物理錨點固定在滑條 10／30／50／70／90%；窄屏顯示一張中央、兩張 30／70%、三張 10／50／90%、四張外側四錨點、五張全部。边缘卡片必要時向容器內收，標記保留錨點關係
- 放大按鈕與預測操作分離；Escape、背景、關閉、焦點還原、換日和過期 async 回覆均須測試

## Schema 18、完整備份與回退

只新增 market_forecasts 與 market_curve_ledger，不重建或轉換舊表。新數值預測與舊 option_id 分開；ledger points_units 是整數微分。共用排行榜查詢把舊整數分暫時乘 1,000,000 合併求和，不修改舊 points。共同結果表以 bucket=curve 標示新制；不將其當成第七個舊選項。

migration 在原有 transaction 中建立新表、索引與約束；完整備份包含新增表、快照、原資料與分錄。驗證拒絕遺失／弱化 schema、混用新舊票、損壞公式／快照／積分／反向分錄。舊版備份只在還原副本升級，来源不改。schema 17 程式不能開 schema 18；回退須對應舊程式及升級前完整備份，不能只退 code，接受新寫入後不得直接覆蓋丟失交易。
