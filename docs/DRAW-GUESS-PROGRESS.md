# 你畫我猜實作進度

更新：2026-10-02。依[玩法與技術規劃](DRAW-GUESS-GAME-PLAN.md)交付第一版，使用既有帳號、角色、房間、表情及私人繪畫圖庫。題目是本專案原創文字，不需要外部圖像或音效素材。

| 步驟 | 狀態 | 實際成果與驗證 |
| --- | --- | --- |
| 1. 共用畫布基礎 | 完成 | public/shared/stroke-canvas.js 提供座標換算、筆畫與形狀繪製；遊戲畫布使用共用渲染，原畫室改用同一座標換算。畫室的照片圖層、去背及既有筆刷保持原控制方式。 |
| 2. 規則與題庫 | 完成 | 2–8 人；三題選一、15 秒自動選題、60／90／120 秒作畫、8 秒揭曉；每人輪流畫一次。猜中者依剩餘時間得 30–100 分，畫者每位猜中 +15。題目與別名只在選題時提供畫者，答對後向其他人顯示姓名但不揭露答案。120 個原創內建詞分三種難度。SQLite v9 保存好友題目、最多五個別名；房主可設 0／25／50／75／100% 投稿比例。 |
| 3. 房間與共用介面 | 完成 | 大廳第五款遊戲卡、開房／加入／回房、房間列表、角色與表情、房主管理、對局歷史摘要及留言板標籤。遊戲中可觀戰加入，下一輪開始猜題；當局畫者順序固定。畫者離線 15 秒則揭曉並繼續。 |
| 4. 即時畫布 | 完成 | 512 × 256 白底畫布；畫筆、橡皮擦、直線、矩形、圓形、常用色、原生色彩選擇、筆刷滑桿、復原與清空。畫者小批次 POST，伺服器驗證身份、回合、工具、色號、座標、每秒批數及總量；SSE 傳送增量，斷線取得快照，短輪詢作後備。筆畫只留在房間記憶體，不逐筆寫對局歷史。揭曉後畫者可手動保存合成 PNG 至私人帳號圖庫。 |
| 5. 驗證 | 本機完成；公開站待驗證 | Windows 序列全套 node --test --test-concurrency=1 122/122；新增規則、SQLite 與 HTTP 權限測試。背景 Chrome 以三個帳號完成三輪、另以兩個帳號完成兩輪；驗證猜題者看不到正解、畫布同步、錯誤／正確猜測、重連快照、手動存圖、結算與無 JavaScript 錯誤。390px 猜題畫面無水平溢出，1365 × 900 桌機畫者的畫布與常用工具同屏可達。本機截圖與試玩腳本放在忽略的 work/。Linux 與 shhuang.cc 的 SSE、資料庫遷移及實際跨網路延遲待部署後驗證。 |

本版仍使用服務記憶體中的房間；重新啟動服務會清除未結束的對局。畫布底圖固定白色，遊戲中不能匯入照片或圖庫作品。對局歷史只保存選題、猜測、得分與結果摘要，不提供事後逐筆重播畫作；畫者須在揭曉時自行選擇存入圖庫。
