# 送禮達人：線上版規則與範圍

這個遊戲以 [GiftTRAP 原版規則](https://www.world-of-board-games.com.sg/docs/GiftTrap.pdf)的「送禮／收禮兩條計分軌」為核心，網站使用自製的中文禮物題庫及介面，沒有複製商業版禮物卡文字或圖片。若「送禮達人」指的是另一款桌遊，應先確認規則再調整此模組。

## 一輪怎麼玩

1. 3–8 人入座後，房主開始；展示比玩家數多一件的禮物。
2. 每位玩家為其餘玩家各點選一件禮物；三人局有四個禮物圖示可選，更多人依「玩家數＋1」增加選項。同一位送禮者不能重複使用禮物，再點已選圖示可取消；選另一位朋友已選的禮物時，原選擇會自動清除。
3. 每位玩家依序點四件**不同**的禮物，標為最想要（+3）、想要（+2）、還可以（+1）、最不想要（−4）。再次點已選圖示可取消，後面的順位會往前補；未標記的禮物是 −1。送禮和標喜好可以自由先後進行、分別鎖定，其他玩家在揭曉前看不到內容。
4. 所有人**兩項都鎖定**後才揭曉。每件禮物對送禮者的送禮分數、收禮者的收禮分數造成相同變動。各軌最低 0 分、最高為目標分數；達到目標後仍可能在同一輪後段被扣回。
5. 一輪結束時，若有人兩條分數均達目標，該玩家獲勝；多人同時達標則共同獲勝。否則房主開始下一輪。

房主可在等待室設定目標 8–30 分，預設 15 分。原版的進階道具卡本次不實作。此線上版不設強制倒數，避免朋友短暫斷線時被代選喜好；中途不能加入進行中的一局，結束後可加入下一局。房主踢出玩家時，該玩家未揭曉的送禮與喜好不參與結算；不足三人則提前結束。

登入會員開房或加入房間時不需再填暱稱；玩家名稱直接採用帳號現有的顯示名稱，角色圖片沿用個人頁設定。伺服器不接受請求中的自訂 `name` 覆蓋該名稱。

禮物內容由 `src/games/gift-catalog.js` 提供 300 個原創項目，每類 75 件。原有 64 件的名稱及 ID 不變，既有 15 件插圖仍使用 [Kenney Generic Items](https://kenney.nl/assets/generic-items) 的 CC0 圖片；其餘內建禮物配對 [Noto Emoji](https://github.com/googlefonts/noto-emoji) 72px 彩色 PNG 作為**象徵圖示**，不是每件禮物的寫實插畫。Noto 圖像依官方 README 的 [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0) 授權使用，原始版本、來源與授權檔保存在 `public/assets/gifts/noto/`。投稿禮物仍可不附圖片；圖片載入失敗時名稱仍可閱讀。本站沒有使用原版商標或卡牌美術。

登入會員可在 `/gifts` 投稿禮物名稱（1–60 字）、分類與選填圖片（PNG／GIF／WebP，最多 1 MB，無像素尺寸限制）。所有投稿立即加入共用題庫，與同頻俱樂部的自訂題目相同；投稿名稱不得與現有禮物重複，每人最多 100 件、全站最多 5000 件。資料與圖片保存在 SQLite 的 `community_gifts` 表，備份 `data/afterhours.sqlite` 時會一起保存。房間在**下一輪抽禮物**時讀取最新題庫；進行中的本輪禮物不會更動。抽過的禮物會先避開，題庫用盡才重新循環。

房間只存於服務記憶體，重啟會清空；結束的對局可於 `/history` 回看。送禮與喜好在伺服器保存，其他玩家在揭曉前看不到選擇；歷史記錄在對局結束或中斷前不對會員開放。

揭曉後立即列出全員送禮／收禮分數、每位玩家收到的禮物、送禮者、評價與得分；達標結束時也保留本輪明細。可選的三件禮物焦點演出可以跳過、重播或關閉，系統設定減少動態時停用。短音效預設關閉，玩家可主動開啟並調整音量。完成一輪有效送禮與喜好標記、且該輪正式揭曉後，帳號會獲得一次「第一份心意」成就，可在 `/achievements` 查看；成就不影響分數或能力。素材來源、尚缺資源與本機驗證狀態見[送禮達人素材與實作進度](GIFT-IMMERSION-PROGRESS.md)。

2026-10-02 以三個隔離測試帳號透過 HTTP 完成兩輪對局：自訂禮物及圖片、入座、房主操作、重連、秘密選擇、揭曉計分、下一輪與達標結束均通過。後續本機加入同時選禮／標喜好及點選卡片，三人與八人流程、重選及取消已列入驗證；最新部署狀態見[進度表](GIFT-IMMERSION-PROGRESS.md)。
