# #136 測試分層與輕量化

2026-10-16 使用者確認規劃並授權實作；途中依指示整合 main 1872f78（PR #137、v2.16.1）。本批僅測試與文件，產品、歷史格式、等待室紀錄、fsync、SQLite durability、CI 門檻均未變更，不升版、不打 tag、不部署。

## 原則與本批範圍

測試保障遊戲規則、權限與容量邊界、跨模組接線、資料可靠性、安全、資源有界及既有回歸。每項測試都要能說明失敗代表的錯誤及移除後的保障缺口。規則以小型單元／引擎案例覆蓋，真實資料邊界用短整合案例，保留代表性完整流程；不以全 mock、停用耐久性或略過慢測試換速度。

本批完成 #136 已盤點的慢測試整理。沒有逐項重新審核全專案每個案例，也沒有變更獨立壓力測試排程。等待室是否移除持久化仍是產品討論，未由本次測試整理推定刪除。

## 為何未刪郎中完整模式

盤點發現各 purpose 的正式授獎、測試不授獎、失敗後刪房重試，以及煉金私有資料／模式交互都有獨立整合保障；單純刪掉完整流程會失去接線證據。此次先消除重複的真實等待和註冊成本，保留五個九輪流程，不將「候選拆分」機械解讀成必須刪除案例。

- 本機 Windows、Node 22.22.3；npm run test:affected 選出直接修改的 7／236 檔，最終 55／55 通過，fail／cancel／skip 0，26.73 秒，包含小區域配額邊界與失敗清理；release check 及 diff check 通過。
