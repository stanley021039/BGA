# 遊戲共用介面與個別遊戲畫面

三款遊戲共用 `public/game-shell.js` 和 `public/game-shell.css`。共用側欄固定在桌面版右側，提供角色列、明顯的輪到誰操作提示、玩家自身角色可用的表情、桌邊留言及回大廳入口。手機版收合在畫面下方，取得焦點時展開。`public/room-host.js` 在各遊戲狀態更新時呼叫 `GameShell.update(state)`；牌桌、賽道、題目與各自操作仍留在 `public/app.js`、`public/race.js`、`public/majority.js`。

共用層只讀取各遊戲回傳的標準欄位：`code`、`phase`、`me`、`players`。輪到誰操作依遊戲適配：撲克用 `turn` 玩家索引；末路狂飆用 `actor` 玩家 ID；同頻俱樂部用 `presenterId` 與 `phase`，作答階段提示自己是否尚未作答。遊戲特有回合規則不放入共用層。

`POST /api/social` 接收同房間已入座會員的留言或表情；留言 1–160 字，表情必須是自己已保存角色具備的表情。伺服器檢查房間歸屬、登入狀態與傳送間隔，房間狀態附加最近 50 筆事件供既有輪詢刷新。送出表情後，該玩家在遊戲座位與共用角色列的圖片會暫時切換約五秒。留言目前只存在記憶體中，房間清除或伺服器重啟會消失，不屬於永久留言板／GitHub issue。離開入口目前是返回大廳，原座位保留以便重連；若要真正退出房間需另行定義各遊戲的中途退出規則。

沒有瀏覽器本機房間紀錄時，三款遊戲頁可憑登入帳號與房號呼叫 `POST /api/reconnect` 找回座位。既有頁面斷線後會持續輪詢並顯示重連狀態；被踢出的玩家不能透過此 API 恢復座位。自訂表情 GIF 的名稱隨角色選項提供，表情按鈕及桌邊動態使用該名稱。

頁面配置參考 [Board Game Arena](https://zh.boardgamearena.com/)「在瀏覽器遊玩多種桌遊」的產品方向，採專案自行設計的共用側欄與遊戲獨立舞台，沒有複製其介面或素材。
