## 已檢查路徑

- 非同步：store 先確認世代才採納快照；reset 銷毀 owner 並取消請求。音效 revision／disposed 防止靜音、離頁、換帳號後的遲到錯誤復活提示；同步拒播以 failed 防止保留錯誤 clip。
- 去重：每批先刷新活躍 ID 再淘汰，最多 256 筆；儲存讀取限制 40000 字元並檢查陣列與 ID 型別／長度，讀寫例外不破壞邀請流程。既有 API 的邀請上限小於快取，未新增任意來源或跨帳號共享。
- 音訊生命週期：owner 最多保留一段 clip，重播前停止；destroy 解除訂閱及事件。共用播放器維持全站四聲道／遊戲兩聲道、載入期限及播放期限，stop 釋放 src 與計時器；通知只使用既有壓縮資源，沒有新增音源或提高預算。
- 靜音與背景：先檢查效果音偏好與 document.hidden，不建立 Audio；收件仍記 ID，避免恢復補播。關閉效果音、hidden 或 pagehide 停止，啟用按鈕不改靜音偏好。
