# Stitch 動態彈幕框

2026-10-15，功能版號 2.9.0。

設計來源：[BGA 小 UI 設計實驗室](https://stitch.withgoogle.com/projects/10999676405834166796)，畫面 `e8196d77fdda40219b3f7a9c1b5bc711`。原稿的 CSS／SVG 框飾已轉成本地資源；執行時不載入 Stitch、Tailwind CDN 或外部圖片。

## 功能

保留原有預設、紙張、漫畫與像素框，新增以下 20 款。收藏庫新增「彈幕框」分頁，可搜尋、依風格篩選、直接套用；右上角的選框視窗使用同一份卡片與預覽元件。

| 風格 | 款式 |
| --- | --- |
| 科幻科技 | 電流霓虹、星際軌道、全息故障、街機像素、機械核心 |
| 可愛療癒 | 奶油草莓、貓咪肉球、軟糖雲朵、深海水母、柴犬吐司 |
| 奇幻自然 | 森林精靈、龍焰寶藏、冰晶王冠、月光魔法、蘑菇藥釜 |
| 古典戲劇 | 水墨游魚、御守櫻花、蒸汽郵件、漫畫爆擊、皇家劇院 |

框飾包含獨立的星球軌道、齒輪、貓耳、肉球、氣泡、葉片、翅膀、冰冠、櫻花與流光。動畫只作用於裝飾，文字保持靜止。預覽卡尺寸固定，視窗標題和關閉入口固定，內容在視窗內捲動。

## 實作契約

- 前端與伺服器都以內建 ID 白名單辨認框；沿用 `{kind:'builtin',id,version:1}` 訊息描述。玩家無法傳入 CSS、網址或 SVG。
- 只有隨程式部署的靜態模板使用 HTML；玩家名稱和訊息仍以文字節點插入。每個 SVG 漸層使用獨立 ID，避免收藏預覽和同時顯示的彈幕互相引用。
- CSS 工具類與關鍵影格都限制在框飾命名空間。共用按鈕規則將選框卡片列入既有內容選擇器例外，保持矩形卡片與選取邊框。
- 外層彈幕仍負責既有移動；框飾留出上下 36px、左右 32px 的裝飾槽，納入既有高度量測與放置演算法。內容完整換行，靜態彈幕不再以單行省略新框文字。
- 動畫遵循共用 MotionPolicy、裝置減少動態設定及頁面可見性；收藏庫的播放開關明示為共用設定。
- 選取沿用瀏覽器本地設定，可跨同來源分頁同步；未新增帳戶端收藏資料表、付費或解鎖條件。接收者關閉框飾時保留文字及原有佔位。
- GameUI 的選框視窗直接重用 `.game-dialog-body`，避免嵌套捲動區縮窄預覽。

## 已觀察驗收

- 隔離測試服務中，20 個新 ID 逐款經真實房間 API 傳送，第二個登入玩家均收到相同 ID 和文字，並產生對應框飾。另以實際聊天輸入框送出龍焰框。
- 現行整合測試服務完成收藏庫 24 款、搜尋與風格篩選、空結果、重載後保存、共用動畫開關和裝置減少動態設定驗證；無頁面 JavaScript 錯誤。
- 桌機 1440px、手機 viewport 390px／320px 檢查收藏卡片及選框視窗；卡片等高、選框視窗未水平溢出。深色框的玩家名稱保持高對比。
- 現行整合服務再次以兩個玩家驗證聊天表單、龍焰及霓虹／星球／貓咪／皇家框同步。390px 的長文字可完整換行；關閉框飾前後彈幕外框尺寸相同。
- 語法、版號一致性與本批差異空白檢查通過。本輪未執行自動測試套件；上述為瀏覽器與實際 HTTP 操作驗證，不代表所有遊戲階段、實體手機、讀屏或 FPS 已驗收。正式站未更新。
