# 抽藥語音與效果翻看分離

2026-10-15，本機候選2.12.1；基準48dbe21／v2.12.0。使用者指定新的「要拚!.mp3」，並明確要求烏鴉頭骨翻看／選擇不要音效。

## 原因與修正

舊版每次 drawOne／look 都產生 drawEvents，前端逐片排入抽藥語音。例如主動抽到烏鴉頭骨2後再翻兩片，會排三次「要拚」；停在效果畫面時，後面的語音仍繼續播放，並非使用者真的再按抽藥。快速的合法連抽也可能形成語音積壓。

- 保留私人、唯一且有界的 drawEvents；只有同步主動抽藥（含改放預抽藥材）標記 decision=true 及同步 step。烏鴉頭骨、占卜、預抽、喝藥水及其他效果翻看保留紀錄但不標記為主動語音。其他玩家看不到這份私人資訊。
- 播放器只採主動事件，重複快照／重試仍去重。播放中或已有一筆等待的主動語音時，後續語音不積壓；待目前音效結束後，新的一次抽藥仍可正常播放。原有忙碌鎖、伺服器同步step與已選擇驗證保留。
- 烏鴉頭骨的翻看、放入、全部放回、停留畫面與輪詢均無額外抽藥語音。真正的結算階段切換、藥水、停止與爆炸維持各自規則。
- 換用使用者新提供580ms錄音，保留其原速度，不再沿用前版尾音拉長處理；24kHz mono16bit、65–5000Hz濾波、10ms／40ms漸入漸出及安全峰值，來源／輸出SHA256見quacks-action-user-manifest.json。不要錄音未改。抽藥播放保護上限1580ms含1秒媒體時鐘安全餘量，正常由ended完成；爆炸仍接在音效清理後短停頓。
