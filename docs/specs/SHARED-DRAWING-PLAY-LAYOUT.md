# 三款繪畫遊戲共用遊玩排版

2026-10-12 最新候選：使用者明確補充要以傳情畫意的三欄配置為準：玩家在左側、聊天室在右側、中間上方作畫／看圖、中間下方猜題或送出。此筆取代同日先前的直向排列規格與驗收結果。

## 共用契約

- `GameUI.layoutDrawingPlay(type, phase)` 與 `drawing-board.css` 負責三款共同 grid、欄寬、列高、間距與斷點。桌機左欄 220px、右欄 300px，中欄填滿剩餘空間；1600px 以上左右欄為 240px／320px。三個面板同列上下緣對齊，列高由 `--ui-drawing-row-height` 固定為 `max(740px, 100dvh - 220px)`，長玩家列表／訊息在區塊內捲動。
- `GameUI.createDrawingBoard({title, canvas, countdown, tools})` 共用題目、倒數、畫布與工具列。`GameUI.frameDrawingTask(controls)` 在原控制容器內分出上方畫布與下方操作槽，保留原生 canvas、表單節點、事件與指標操作；原生 `#controls` 換頁重建時重新套用，不將節點搬出 renderer 的所有權範圍。你畫我猜沿用原生 board／guess panel，套相同幾何。
- 下方猜題／送出槽桌機保留 220px，內容在槽位內捲動。傳情畫意、極簡畫家保留角色與階段限制；畫家下方為作畫送出，猜題者下方為猜題表單，未揭曉內容仍由原 API 保密。512×256 畫布與筆跡協議保持原樣。
- 共用 ResizeObserver 與 rAF 依上方可用高度、標題／倒數及工具列測量畫布顯示寬度，保持 2:1 比例、不更改 backing bitmap，也不讓畫布延伸至下方操作槽。選題／揭曉的原生 stage 使用自然內容高度與上方區塊捲動；無工具的觀看畫布在中欄置中。手機直接用 100% 寬，避免桌機寬度在切換斷點時短暫溢出。
- 760–1100px 改為玩家左側、中間工作區，聊天室換至工作區下方。760px 以下換列：玩家 → 作畫／猜題 → 聊天室；玩家列表預留 320px、聊天室 440px，工作區採自然高度以完整顯示工具與表單。
- 桌機聊天室跟同列玩家／工作區等高，訊息數量不改變外框與底部操作列位置；emoji／媒體位於輸入框上方，離房操作靠右。其餘遊戲的聊天室高度配對保留。
- 等待房間與結束階段仍沿用既有共用房間／結算操作。退出進行中布局時還原 home marker、清除畫布顯示寬度並解除尺寸觀察；再次開局可重新套用。
