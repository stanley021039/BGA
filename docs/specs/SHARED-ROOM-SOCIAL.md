# 共用房間操作、設定與彈幕

本輪範圍為撲克、雷霆之路、你畫我猜、多數決、禮物、傳情畫意、TRPG、猜歌、極簡畫猜與瞎掰王。實作與驗證結果見 [本輪紀錄](../SHARED-ROOM-SOCIAL-PROGRESS.md)。

## 已確認的使用方式

- 房間只有一個文字輸入框，位於聊天室，最多 160 個 Unicode 字元。
- 送出一次，同時留下完整聊天紀錄與文字彈幕。彈幕單行呈現，超過 40 字保留前 40 字加省略號；換行在彈幕改为空格，聊天紀錄保留原文。
- 大廳不提供聊天送出入口；伺服器也拒絕大廳頻道。只有已入座、未被踢出的玩家可讀寫本桌訊息。
- 表情、emoji、媒體按鈕位於聊天室。emoji 與角色表情也留下可讀文字紀錄。媒體沿用既有接受影片流程。
- 移除保留則數／記憶體／房間結束清除的介面說明文字；既有資料清理方式維持。

## 共用元件

`RoomControls` 與 `room-controls.css` 提供設定卡片、開始／加入 AI／離房操作列及離房對話框。圖示與可讀名稱由既有 GameUI registry 提供。設定欄位與按鈕間距使用共用 tokens，操作槽保持 44px，高度超出設定槽時在槽內捲動。

各遊戲沿用自己的設定欄位、開始與 AI 指令；共用元件呼叫原有操作，不更動最低人數、AI 支援、玩法或私人資訊。原有按鈕作為內部轉接節點，不重複顯示，也不進入鍵盤焦點順序。手機可換列，保留既有手牌、賽道、畫布、音訊與角色布局。

傳情畫意保留最新 main 的「名單最後一格」AI 入口，卡片變體也由 RoomControls 提供；其他遊戲使用操作列變體。兩者共用中文名稱與圖示 registry，傳情畫意不重複顯示操作列的 AI 按鈕。

離房統一顯示確認／取消、依遊戲提供離席影響文字。取消或 Escape 不送出離房指令；送出中鎖定按鈕，錯誤留在房間並可重試，成功返回該遊戲的大廳。

## 伺服器契約

`/api/chat` 的 table POST 與舊 `/api/social` message／barrage 共用 `sendRoomMessage`。訊息使用同一識別碼生成完整紀錄及彈幕，重試不重複新增。既有權限、純文字檢查與傳送間隔沿用；超長或不合法的彈幕框不留下部分紀錄。

聊天 POST 回覆本桌訊息與 roomState，立即更新自己的彈幕；其他玩家使用原有房間同步及聊天輪詢。房間／座位／登入身分變更後丟棄舊回覆，聊天室文字透過 textContent 呈現。

## 驗收範圍

十款遊戲均檢查房主、一般玩家、開始、AI 支援、設定欄位、取消／確認離房，以及 1440px／390px 的亮暗版面。訊息檢查 40／41／160／161 字、emoji、重試、跨房權限與離席後禁止存取。畫猜另驗持筆、傳送 ACK、觀看者逐點播放、倒數、揭曉與換輪。未宣稱真人觸控、所有遊戲的完整場次或第三方影片播放均已驗證。
