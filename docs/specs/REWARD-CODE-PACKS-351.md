作者碼保留現有戰鬥加成，新版不再授予全背景。使用者表示尚未領取，這次不做舊資料撤銷、補發或正式資料操作；既有舊版領取紀錄仍防止再次領取。

五類獎品由共用目錄挑選，優先未持有；原版、異色按各自 ID 分別持有。該類全持有時，依共用規則轉成重複碎片。大招與普通招式由正式配裝規則區分，新增獎品會自動進入對應類別，不維護第二份獎品清單。

領取在單一 SQLite 交易寫入五件持有權、碎片、禮包紀錄與零聖潔石帳本。領取不直接抽卡。券數由可信任禮包紀錄扣除已結算抽卡券請求推導；抽取沿用請求冪等與交易，重試不重扣，也不能由個人設定注入券數。備份驗證檢查禮包指紋、帳本與券數，無資料庫結構變更。

抽卡機提供用券單抽／十連，券數不足時不能使用。此類一般抽卡券依當前卡池機率並累計該池第 50 抽加成；不與登入史詩十連券、傳說單抽券混用。

領取成功用共用 UiDialog 列出實際抽卡券及五件名稱／稀有度，提供前往抽卡機。重複領取顯示原紀錄，明示不重新抽取、不重發。
