# #150 送禮圖片邊界修正

2026-10-21，本機候選 2.19.1，基準 main `b3edde5b735fef0125be6e78c4044feac2657055`。使用者指定先預覽、不合併；本批只修送禮圖片，深色文字稽核仍由 #151 追蹤。

## 原因與修正

`GiftArt` 使用固定高的 Grid 圖片槽，但未定義內部軌道；圖片的 intrinsic size 與百分比高度讓 auto track 撐大。原收禮畫面實測槽高 84px、圖片高 286.4px，超出 202.4px。`object-fit: contain` 只控制圖像如何填進圖片盒，不能修正已超出的圖片盒。

共用 `.vue-gift-art` 明定兩軸 `minmax(0, 1fr)`、清除圖片最小尺寸並限制最大寬高；保留等比例 contain，沒有裁切整張卡。既有選禮／心願／收禮 84px、桌機明細及焦點 64px、手機明細 44px 高度不變。手機焦點沿用原 44px 寬、64px 高，不擅改版型。另將備援禮物字形改為 2rem、行高 1，避免在 44px 槽超出。

## 瀏覽器回歸

- 原生 IAB 實際遊戲：1920×1080 深色收禮、確認後結算（64px）、下一輪選禮與心願（84px）、進出專注模式；390×844 淺色收禮、深色心願與結算明細（44px）。觀察到的圖片盒都在槽內，名稱及分數保留，手機沒有水平溢出。
- 可重跑的版面 fixture：先安裝前端依賴，再執行 `node tools/gift-art-layout-fixture.cjs`，開啟輸出的 loopback 網址。直接編譯實際 gift.scss，不複製修正樣式；四種使用情境各測 72px 方圖、1600×90 橫圖、90×1600 直圖、4096px 透明邊界圖及備援字形，共 20 個圖片槽。
- 1920×1080 與 390×844 各 20/20 通過；檢查實際 `getBoundingClientRect()` 邊界、圖片載入、標題遮蓋及水平溢出。使用 main 舊樣式執行相同 fixture，確實回報方圖／直圖／大圖溢出與標題遮蓋，證明能抓到原問題。
- fixture 是 CSS 幾何回歸，備援為等同 markup，沒有宣稱它涵蓋 Vue 圖片失敗事件或完整多人玩法。真實圖片載入錯誤切換、實機觸控、Safari 及八人全流程本輪未新增驗收。
