# 房間設定與非房主唯讀候選

2026-10-12：移除「你的操作」標題，改為房間設定；一般玩家仍可看到目前設定但控制項disabled。bluff／musicquiz／minimal使用同一外層標題，RoomControls避免重複內標題。

有原生設定表單時沿用原節點；非房主缺少表單時，RoomControls依公開state產生disabled設定快照（傳情題庫／每頁秒數、同頻題數／投稿比例、送禮目標／投稿比例、猜歌片段秒數、瞎掰難度／身分秒數）。快照隨公開設定更新，不綁定儲存callback。其他固定規則遊戲顯示固定規則說明。伺服器HOST_ONLY驗證保持不變。

本文件先記錄隔離測試站的實作驗收；最終完整測試與審查狀態見本批驗收紀錄。


## 共用區塊元件

房間設定與聊天室透過 `GameUI.framePanel(panel, {header, content, footer, body})` 共用 `.ui-panel-frame` 結構。標題位於大面板內、content 上方；content 以兩條上下分隔線包住，填滿可用高度並在區內捲動；footer 固定靠下。header / content / footer 之間使用聊天室的 `--ui-panel-gap: 12px`。

房間設定的狀態回饋與操作列都在 footer；聊天室的狀態回饋、表情／媒體列與發送表單都在 footer。空白回饋不占用高度。各遊戲舊操作區仍保留原事件處理，但不再占據面板槽位；跑團的個人角色選擇保留在 content 中。

本輪以隔離測試站的真實房間檢查 10 款遊戲、1440px 與 390px 版面：header 和 footer 邊距一致，content 前後均為 12px，長內容捲動不移動 footer。另確認你畫我猜從等待切換進遊戲後可發送聊天訊息，管理／離開同列對齊，且不顯示加入 AI；跑團角色控制位於 content 並可操作。此為本功能的針對性驗證，尚未執行 PR 前完整 checklist。


## 遊戲中的聊天室固定高度

`SharedChat.matchRosterHeight(peer)` 在進入遊戲時配對朋友面板，預留等高的外框；基本預留高度為 440px，桌機以該朋友面板的高度為準。只在配對面板或視窗尺寸改變時重新計算，不監看聊天室訊息來調整高度。訊息與玩家列表在既有槽位內捲動；切回等待房間、離席或頁面離開時移除高度配對。

你畫我猜實際測試房間：1440px 寬時兩側均 796px 高，390px 寬時兩側均 440px 高。空訊息與 24 則較長測試訊息前後，外框寬高及 footer 相對位置一致，長訊息只在內容區產生捲動。此為本功能的版面驗證，未執行完整 PR checklist。
