# 猜歌買歌回饋（#259）

2026-11-05。候選 3.18.1 以 `80c9b0ee` 為基準，分支為 `codex/musicquiz-buy-259`。使用者已確認接續既有議題，並要求其他玩家也能得知卡片已被購買。

## 問題與改動

目前 main 的引擎已能於聽歌前扣 3 枚標記、購入下一張年代卡，原買歌測試也有覆蓋。這輪沒有重現請求完全未送出的故障，不將該現象冒稱為已定位的伺服器錯誤。已確認缺口是成功後前端清空一般操作提示，只靠卡片／標記變更呈現結果，且原事件只寫「玩家買歌」。

沿用同一條按鈕 → party-actions → action API → 引擎與快照流程，將成功的 buy 事件補齊買家、歌名、年份與 3 枚標記花費。Vue 契約讀取既有公開事件，所有房內玩家於收到新 buy 事件時，透過原 StatusSlot 顯示成功訊息約 4 秒；年代卡仍留在公開音樂卡中。不新增 UI 外觀或 Figma 設計，本輪沿用第三份共用元件契約。

只有比上一份快照新的伺服器買歌事件會觸發提示。重新掛載不重播舊事件，換房或換輪時清除提示。同一份快照有多筆新購買時逐行顯示，提示槽保持固定高度，較長的內容可在槽內捲動。操作中、失敗原因及同筆重試沿用既有流程，失敗回饋優先。購入的是牌庫中的另一張卡，本輪待播放的歌曲仍然保密。
