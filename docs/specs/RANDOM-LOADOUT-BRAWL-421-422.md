# 一鍵隨機配裝與競技場亂鬥（#421／#422）

2026-11-24，使用者確認一鍵抽選後固定配裝；亂鬥型態指攻擊／速度／防禦／生命／能量，包含尚未解鎖項目但只限該局。候選3.35.0，沿同批#420未提交成果，基準main 8b7b078196f6f9a5fa0ca64728ac590bfe1e6cd5。

## 配裝

設定／競技場配裝共用AttackChoices新增「隨機配招」，只抽已擁有的Q／E普通招式與R大招，包括已解鎖異色；沒有大招則保留空R，兩個普通槽候選足夠時不重複。透過chooseAll單一請求整套提交，伺服器接受才替換；失敗保留舊配置。所有權載入與失敗期間不允許隨機。進場沿EntranceChoices新增獨立按鈕，只抽免費與已持有項目，以既有本機偏好保存；非持續隨機模式。

SceneBotPanel及訓練設定提供「隨機配招與進場」，先填好表單，再沿「儲存設定／加入機器人／確定設定」套用。保留角色、行為與隊伍，沿既有權限、對戰鎖定及設定邊界。按鈕與表單沿第三份Figma既有UiButton／UiField外觀，沒有另設新樣式、插圖或媒體。

## 亂鬥

「開始亂鬥」是獨立第三種競技場模式，至少兩位報名者，沿全員準備、五秒倒數、時限、房間隔離及個人得分結算。隊伍只沿用報名入口；場中所有參賽者互為對手，旁觀者不能打進比賽。現有機器人參賽時一併抽選，不新增Boss能力。

伺服器使用crypto.randomInt從全獎池抽取Q／E普通、R大招、進場與五種戰鬥型態，包含原版和異色；每位參賽者各配一套，該場鎖定、重生不重抽。地圖是全場共用的一次抽選，60秒只抽小圖，120／180秒沿所有合法地圖。一般地圖選單仍用於PK／團隊戰，亂鬥忽略選單結果。權威快照傳回實際招式、進場、型態與地圖，戰況可查看；HUD提示亂鬥與型態。

使用lockedAttackLoadout／lockedEntrance作暫時狀態，不寫入profile或解鎖。HTTP不接受玩家指定effect；進場快照優先鎖定值。完成、棄權、離房均沿原清理契約清除，不影響原配裝／進場偏好與機器人表單。原成就與有效場次的資格條件保留；有機器人的場次仍不發正式成就。
