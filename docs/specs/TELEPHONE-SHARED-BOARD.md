# 傳情畫意共用畫板

2026-10-12：使用者要求移除筆畫額度／分頁／揭曉的技術說明，使用你畫我猜同款畫板與倒數，題目移到相同的畫板上方位置。

本批在獨立分支實作，未切換正式服務。兩頁共用drawing-board.css、StrokeCanvas renderer／SVG工具與CountdownBar進度條。傳情畫意提供畫筆、橡皮擦、直線、空心與實心矩形／橢圓、填色、復原、清除、調色盤及1–40px筆刷。題目與倒數在同一畫板上方；桌機160px左工具軌，手機工具改放畫板下方。猜詞頁保留上一張私人圖與猜詞欄，不公開完整傳遞簿。

每頁採你畫我猜預設90秒，由伺服器提供deadline／serverNow；重新整理與輪詢不重設截止，換頁才重設。時鐘與進度條共用CountdownBar，0秒停止進度；到時自動送出／由房主傳頁／自動傳頁的偏好尚待使用者回答，目前保留原手動送出與房主傳頁，沒有假稱自動截止完成。畫作原有100筆／3000點仍在伺服器驗證，移除常態技術文案不等於移除容量邊界。

目前證據：19項傳情畫意單元／客戶端測試；Chromium1440／390、亮暗、作畫／猜詞共8布局，無水平溢出，題目在畫板上方；15次持筆採樣無白屏，實心矩形與填色可送出，猜詞可送出，數字倒數與進度條正常。此為隔離合成房間，真觸控、跨瀏覽器、完整多人原生HTTP與正式站尚未驗證。完整測試／CI以PR證據為準。

整合審查補修：合法長畫作可大於原8KiB請求預算，action body採128KiB硬上限，筆畫100筆／3000點等遊戲級驗證不變。原生HTTP補驗大於8KiB可送出、超128KiB拒絕，完整與CI結果見PR。
