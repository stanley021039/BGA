# 大廳／本桌聊天室（Issue #63）

2026-10-08；候選 1.22.0；基準 main `dae903e3d6e0f3eebc7d6999aa00a64e4fec4042`。#60、#61 已合併變更保留。本文件描述候選實作，沒有部署。

## 行為與權限

大廳及五款有桌遊戲共用頁面內可收合面板。預設收合，進桌選取「本桌」，可切「大廳」。頻道、房碼與大廳可見範圍在輸入 label 持續顯示。各頻道有未讀數；首次載入歷史不當成新訊息，開啟所選頻道清除未讀。輸入最多 160 個 UTF-16 code units，與原文字留言上限一致；名稱及訊息一律 textContent，不解讀 HTML、Markdown 或自動連結。

大廳讀寫需有效登入；本桌讀寫每次檢查房間、帳號席位及 kicked 狀態。僅房號或其他桌席位不足以存取。角色升降不影響一般成員聊天資格。停用帳號／撤銷登入即失去存取；不修改網站或房間權限設定。新的聊天讀寫不刷新遊戲席位、倒數或執行遊戲動作。

`GET /api/chat?channel=lobby` 或 `channel=table&code=ABC123` 取得 snapshot；POST 同一路徑帶 channel、可選 code、message、requestId。舊 `/api/social kind:message` 共用本桌記憶體歷史與限流，保留原 snapshot 回傳；emoji、expression、barrage 與猜答案不變。

## 資料與負載界線

每個頻道最近 50 則僅存同一 Node 程序 RAM，不寫 DB、遊戲歷史、localStorage 或永久聊天紀錄；程序重啟消失，本桌隨房間清理刪除。沒有固定小時保留期限，未滿 50 則的大廳訊息可能留到重啟。多程序部署不提供跨程序同步，沒有永久／跨裝置已讀游標。

每帳號所有聊天頻道共用 1.5 秒發送間隔，切頻道或走舊 API 無法繞過；發送 rate map 最多 4096 位近期使用者，60 秒到期。重送 requestId 在該頻道保留的 50 則內按帳號去重，相同識別碼改內容拒絕；窗口外不能保證去重。原始使用者 ID／requestId 只在 WeakMap，不放進公開訊息。

每帳號 chat API 最多 120 次／分鐘，前端順序讀最多兩頻道、每輪成功後 3 秒、失敗漸退最多 30 秒；每個請求 10 秒 timeout。頁面隱藏中止請求並停止排程，回前景／online 重試。收合面板仍輪詢以更新未讀，不做全站廣播。多分頁共享 API 帳號限流。

## 生命週期與 UI

換桌／席位或房間 instance 變更、離桌、踢出會取消舊請求、清除本桌訊息及 DOM、丟棄晚到回覆。發送 pending 防重複點擊，失敗保留 requestId 供原內容重試。發送會中止舊輪詢避免回覆倒退；切頻道不把舊發送內容放入新頻道輸入框。登出清除所有歷史；其他分頁透過登出通知或下次認證請求清除，通知僅存時間、不存訊息。權限撤銷在下一次 API 回應／既有 kicked 事件清除，不能遠端抹除使用者已看過的資料。

面板位於 sidebar／大廳正常文件流，不用固定浮層；手機可收合、訊息清單有高度上限且長字折行；label、焦點及送出按鈕可讀名稱保留。傳送沿用 GameUI send registry。
