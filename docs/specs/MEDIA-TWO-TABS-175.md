## 介面與行為

2026-10-22 使用者驗收追加（最新更正）：上傳入口在共用音樂庫標題右側，整列為「共用音樂庫 · 上傳新歌曲↗」，取代較早左側指示；分隔點在連結外且無底線，連結使用深淺色主題的藍色 token，文字與箭頭之間不留空格。刪除原獨立長連結列。播放清單不再收合，直接顯示標題與待播項目。此追加取代下列早期「可展開／收合清單」敘述，其他播放生命週期及權限不變。

- header 移除播放清單按鈕，保留既有移動、外觀、縮小／最小化及關閉操作。body 最上方只有「播放中｜點播」兩個等寬 tabs。
- 播放中：影片區 → 影片名／狀態 → 全桌進度 → 功能按鈕 → 個人音量。原常駐權限長文、本機選項區、捷徑與底部回饋區移除；必要錯誤／載入回饋放於媒體狀態，權限原因保留於可及說明。恢復播放、原生播放器備援及個人退出歸入功能按鈕。
- 點播：共用音樂庫 → YouTube 連結 → 前往音樂收藏庫／上傳歌曲連結 → 可展開的播放清單。沒有影片區、播放控制、目前影片摘要或其他常駐區塊。清單沿用房主／管理者排序／移除權限、拖曳與鍵盤操作；展開／收合會取消未完成排序。
- 關閉或 Esc 隱藏視窗，不退出已同意的影片；重新開啟接續同一播放器，不重新 seek。切 tabs、捲動／遮蔽、展開清單與其他 dialog 都不因幾何不可見而退出。最小化／小窗仍保留。
- 明確「退出自己的影片」、全桌停止、換片、離房／斷線、元件卸載仍依原權限及時序處理。關閉不是全桌命令，不更動全桌播放狀態。

## 實作契約

Vue `RoomMedia` 將視窗可見狀態和觀看意圖分離；影片 DOM 常駐於播放中 panel，以 v-show 隱藏，切 tab 不卸載。`RoomMediaPlayer.setWindow(open, collapsed, keepVideo)` 第三參數是新 opt-in；此 Vue 宿主啟用，允許已接受影片在面板隱藏時播放，略過不適用的 IntersectionObserver 自動退出。未傳參數的既有 leaf／legacy 呼叫保留舊契約；沒有修改 legacy 媒體頁面布局。

同意流程、YouTube API／原生 fallback、個人音量、同步進度與房主授權保持。尚未同意不建立影片；關閉中接續下一筆已接受影片不自動彈出視窗。讀取個人進度的工作仍在視窗關閉時取消，不把舊讀取結果發送至全桌。
