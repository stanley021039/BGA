# #176 最近播放影片名稱

2026-10-22 使用者在 #175 驗收時要求 YouTube 網址欄的紀錄以影片名稱顯示，本輪接續實作；候選 2.29.0、worktree `codex/media-two-tabs`。本機預覽，尚未合併／部署。

- 點擊／聚焦網址欄展開最近播放名稱；選取僅填入標準 HTTPS YouTube 網址，不送出點播、不載入新播放器。關閉瀏覽器的表單自動完成提示，避免與自製清單混淆；瀏覽器是否遵循 autocomplete=off 仍由其決定。
- 來源是已接受的媒體 snapshot 中處於 playing 的 current 影片，排隊、失敗點播與暫停不新增。這代表全桌進度已播放，不宣稱每個裝置均實際發聲。相同播放 session 的標題更新不重排；同 videoId 重播最近置頂、去重並保留十筆。
- 影片名稱先用既有伺服器 metadata；已同意載入播放器者，可用 provider 回傳且 videoId 符合目前影片的名稱補正。缺名保留可識別的「影片名稱暫時無法取得（編號）」；晚到的無名稱資料不覆蓋已知片名。沒有為歷史功能新增外部查詢或繞過觀看同意。
- 僅存本瀏覽器 origin 的 localStorage，key 依登入帳號 ID 隔離，跨房間保留，不跨裝置同步或提供給全桌；儲存不可用時本次留在記憶體。非加密私密儲存，共用電腦仍受瀏覽器本機存取邊界限制。
- ArrowDown／ArrowUp 移至清單項，Enter／點選填入；Escape 先關清單、保留輸入與媒體視窗；Tab 可進出，焦點離開區域關閉。原生按鈕保留中文名稱，長名稱換行、四列高度後局部捲動，無紀錄顯示空白提示。

回歸涵蓋十筆上限／重播去重／跨房間重新載入／帳號切換／壞資料／儲存失敗／協定白名單；實際編譯 Vue setup 驗證 queue 與 paused 不新增、playing 才記錄、選取不 enqueue，以及 Escape 不關媒體。leaf 驗證片名對應 videoId、過期名稱與 metadata 例外不影響續播。實際介面與完整測試結果另依本輪驗收紀錄，不將模擬 viewport 當作實體觸控或讀屏測試。
