# 大釜自動抽牌與指定媒體

2026-10-15，本機候選 v2.9.0；未推送、發布 PR 或部署。

## 行為

- 大釜以方框標出下一格結算位置，保留目前藥材圓形標記。第52格後指向獨立終點格53（35金錢／15分）；不是把52格重複計算。
- 釜名留在釜框左上，文字在名稱牌內置中，牌寬依字數調整，長名限制寬度；不是把牌移到整個釜的正中央。
- 起始玩家在可見頁面進入占卜階段後，中間直接顯示牌背，650ms後自動抽取，不需再點按。旁觀玩家不顯示中央抽牌；仍可讀取公開卡片。
- 每輪固定 fortune-加roundId作請求識別，伺服器原有receipt去重，避免刷新或多分頁重複抽取。隱藏、換輪、離頁取消待發請求；忙碌時延後。失敗走既有錯誤／重試流程，不無限重試。
- 金綠牌背為原創SVG，參考使用者附圖的門扉與裝飾概念，沒有複製附圖點陣素材。降低動態偏好下牌背靜止，卡片結果由原本公開卡片區呈現。
- 瞎掰王「哦是哦」圖示換成使用者提供照片，原PNG不修改，以CSS縮圖顯示，文字及可讀名稱保留。
- 同頻俱樂部揭曉結算改用使用者「結算.mp3」的既有660ms轉換檔，普通、殘酷與單人模式共用；保留音量／靜音與只在新結果播放的限制。重新整理不補播。

## 驗證

- 回歸涵蓋自動抽牌權限、忙碌／隱藏／離階段／換輪、失敗不重試、固定receipt只消耗一張牌；結算下一格／終點格、釜名寬度與置中、非起始玩家不播放中央牌演出及指定音效映射。
- Windows Edge原生DOM，1440與390 viewport：中央牌背正常載入、自動送出一次、旁觀者無中央演出、刷新不重播，下一格9／終點53，名稱牌102／240寬且中心誤差小於1px。使用真引擎快照並攔截傳輸，不能視為完整多人真人實玩。證據：work/qa/quacks-auto-fortune/evidence.json。
- 瞎掰王同兩種viewport：照片完成載入、舊問號SVG移除、九人質疑可並列且音效僅一次、專注模式／刷新無重播。證據：work/qa/bluff-reaction-stack/evidence.json。
- 同頻俱樂部隔離真HTTP多人流程與單人流程，瀏覽器原生Audio playing事件各確認新結算錄音一次，普通模式刷新無補播。證據：tools/qa/majority-settlement.cjs、work/qa/majority-settlement。
