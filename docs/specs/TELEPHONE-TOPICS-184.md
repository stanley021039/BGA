# 傳情畫意：先各自出題（#184）

2026-10-23，候選 2.33.0。依使用者確認：開局先讓每人想主題，限時 90 秒；全員送出可提早開始；逾時空白由選定題庫補上。此規則取代開局直接拿系統題目作畫，只有出題階段可提前結束，後續作畫／猜詞仍依共同 90 秒截止傳頁。

## 行為與資料

- `prompting` 為第零輪，每人輸入 1–80 個 Unicode 字元。主題及私人草稿不向其他席公開；開始作畫後，把每本主題交給下一位玩家。既有 3–8 人、奇數 n−1／偶數 n 頁畫猜規則不變。
- 全員送出後立即建立全新 step 與 90 秒作畫期限。截止時保留已送出的主題及伺服器已接受的非空白草稿；空白才用開局預選、符合房間設定的備援題庫。前端不把尚未同步的文字宣稱為伺服器已接受。
- 歷史第零頁由佔位資料替換為真實主題／備援，保留作者、逾時及題庫補題標記。中途踢人依既有中斷規則結算，不憑空補上尚未提交的主題。
- 已接受的出題請求在第一張作畫期間重試同一 receipt 為無副作用成功；不同內容衝突，後續頁或新局的舊 step 拒絕。收據數受最多八席限制，新局清除。出題與跨 step 的無副作用重試不計為畫猜參與成就。
- 排程與腳本夥伴接入出題階段；沒有房主操作也會在期限到時開始。沿用原生 v-model 的中文組字保護、私人草稿／刷新與房主逐頁結算。

## 介面與驗證界線

使用已確認的傳情畫意版面與共用輸入／按鈕；開局顯示「先想一個主題」，不顯示畫布。送出後顯示等待全員，備援題庫標籤及教學說明同步更新；手機出題前後保留相同內容槽，長主題可換行／鍵盤聚焦捲動。沒有新 Stitch 稿或 Figma 匯出；既有第三份 Figma 參考詳 `docs/refactors/STITCH-DRAW-TELEPHONE-PAGES.md`，本次讀圖遇方案呼叫額度限制，不宣稱已同步設計稿。

規則回歸涵蓋六種人數、提前開始、新期限、非空草稿／空白備援、題庫選擇、私密投影、80 個 emoji、非法請求、重試／重開、中斷及真實歷史還原。另補排程、腳本夥伴、成就漏畫不能被出題／舊請求補足的回歸，以及三個真 Pinia／編譯 Vue 場景的主題交接、IME 與新 step 清空；電話前端共七項。

`tools/qa/telephone-topics.cjs` 使用隔離 HTTP、三個合成帳戶及 Chrome 桌機／390px 深色視窗，檢查原生 CDP 組字、草稿刷新、專注／Esc、主題交下一席、早開與真實 90 秒逾時、結算主題逐頁揭露。證據位於忽略的 `work/qa-telephone-topics/`；最終執行結果與失敗追查、完整測試／CI 身分記錄在 PR。手機為視窗模擬，沒有宣稱實體觸控或 Safari 驗收。
