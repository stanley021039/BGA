## #299 範圍與驗收

大廳現有十三款桌遊與股市冥燈都提供自己操作與全自動演示，桌遊使用真正遊戲引擎、獨立教學狀態及原有操作畫面（畫猜使用簡化練習筆刷）；股市使用原正式計分函式與本機假設行情；雷霆保留原完整章節入口。教學示範主要一輪的選擇、其他玩家回應、公開結果與計分，不能把完成一輪教學冒稱完整多輪遊戲。未完成前可重試、切換模式、暫停及離開；背景不繼續自動操作。每個遊戲有對應目標／步驟說明，說清目前角色、正在做什麼及下一步。

教學不加入正式房間列表、不寫成就、分數、題庫或媒體，不觸發外部服務。教學 session 依登入帳號隔離，有限數量／存活時間／命令上限；同一版本操作防重、過期操作拒絕。音樂以本站自製的教學旋律示範，不請求 YouTube 或會員音源。新增遊戲必須註冊兩種教學與驗收資料，不能默默缺入口。

驗收包含每款雙模式可完成主要循環、教學狀態隔離、切換／重試／卸載取消、桌機／手機／明暗及錯誤恢復。正式連線功能沿用，不能由教學傳輸落入正式房間 API。
