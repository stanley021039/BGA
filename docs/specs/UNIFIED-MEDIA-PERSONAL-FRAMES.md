# 播放器整合與個人風格（2.16.0）

2026-10-16，依使用者四項要求、每位玩家各自選擇、整窗套用、避開右上工具列、未來模板同步及設定／形象頁入口的後續確認完成本機實作。本文件取代舊媒體規格中獨立「點播與清單」視窗及其入口的布局；保留既有播放權限、同桌影片選擇、同步與排隊規則。

## 行為

- 影片、播放控制、歌曲／YouTube點播表單與待播清單位於同一播放器。預設可用高度從可見遊戲header下方計算；保留拖曳、縮放與已存設定，展開的header選單在浮動播放器上方。移除獨立清單視窗、原點播與清單入口及小播放器的清單入口。桌機左右排列；窄視窗上下排列，清單可局部捲動，更新後保留捲動位置。手動或影片自動開窗都載入歌庫；普通更新及最小化／還原不重複請求。
- 最小橫條依可見的三個操作計算寬度，不再留下左側空位。預設控制尺寸下為164×56px；可切小視窗、展開或關閉。最小化保留既有播放器及聲音，縮小視窗維持360px上限及至少210px播放器空間。
- 預設外框採網站中性面板色，取消固定紫色。模板背景、文字及邊線從共用裝飾的實際樣式取得，套用內容、表單、控制與清單，並轉接既有Stitch／template／playful tokens；沒有第二份模板或配色清單，之後新增彈幕框會自動出現。關閉時先選風格，延至播放器開窗再量取表面。風格入口使用GameUI圖示、中文可讀名稱與提示；沿用BarrageFrames的24種內建模板與裝飾，不另複製模板。
- 共用media-appearance.js提供播放器內、右上設定與形象設定頁三個入口；26頁在彈幕模板後載入同一模組。每個瀏覽器的個人選擇存於localStorage的bga.media.frame.v1，重新整理保留；不更新彈幕風格，不送媒體或房間狀態變更，也不影響其他玩家。未知值回預設、儲存不可用時仍能在本頁選擇。
- 郎中未選藥材書面使用淺紙色與深墨色，選取面保留金色區別；所有面文字不因disabled透明度而變暗。配色位於遊戲主題，視窗幾何例外留在共用composition。

YouTube標題查詢可用youtubeMetadataEnabled與其他外部副作用分開設定；預覽明確啟用唯讀oEmbed。保留固定YouTube端點、11字ID、禁止轉址、32KB與兩秒上限及權限／revision重驗；失敗備名快取15秒後可重新查詢，不再整個程序永遠保留失敗名稱。私人或無法公開取得的影片仍使用備名。
