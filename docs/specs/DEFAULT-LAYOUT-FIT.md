# 預設版面比例與藥材數字修正

日期：2026-10-16；本機候選 2.14.1。

## 需求與實作

依使用者兩張已確認的預設比例截圖，維持最新 main 的頁首、聊天與手機介面，調整大廳與郎中候場的可用高度。新局、遊戲規則、已提供的音檔及圖片維持既有接線。

- 大廳在細指標、至少960px寬／560px高且非大字模式時保留角色區、卡片與右側房間區。卡片插畫依容器剩高調整，完整卡名、選取與開桌操作保留；短視窗縮減裝飾高度，遊戲簡介仍可從原規則入口查看。返回房間與素材來源分列放置。
- 郎中候場沿用三欄名單／插畫／設定，開始操作固定於設定區底部；長設定局部捲動。手機及大字維持文件流，不強制縮放瀏覽器。
- 已放藥材的格子不建立數字及其底牌；空格保留數字，藥材本身數值、格子輔助名稱與詳情保留。藥材仍在上層。
- 整合 main 289cdc7（#127）以及 f17ea43（#131、#126）。CSS 保留 tokens／skin／composition 與郎中 theme／layout 分工，新增 RoomChrome 依賴。
- 保留十一遊戲右上管理入口。新版聊天區的管理按鈕位置統一交由 RoomControls 處理，避免候場、開局及結束時搬回聊天區。手機記分板進入既有更多選單，桌機維持頂端。
- 候場原遊玩區的隱藏契約優先於活躍聊天樣式，避免開始按鈕被聊天區擠出或覆蓋。手機從聊天 modal 開媒體視窗時先關閉來源 modal，使非 modal 的播放器與待播清單可操作。

## 驗證

- tools/qa/default-layout-fit.cjs：原生 Edge、獨立 SQLite 與合成帳號。100%／CSS zoom=1 下驗 1896×846、1847×796、1440×800、1366×768、1280×720、1280×600、1100×700、1024×640、960×600、390×844，共20個大廳／候場頁面。桌機無頁面溢出、三欄及開始操作可見、卡片不裁切；手機無水平溢出並保留垂直文件流。
- 1847、1366、1280、960 四種尺寸逐款切換十二張卡片，共48次；檢查卡片與操作框不重疊、鍵盤選卡及建立房間視窗開關。幾何矩陣使用減少動態以排除裝飾擺動；不是作業系統DPI或實體觸控測試。
- 本批新增管理入口與手機 modal 媒體回歸；受影響123項通過。Windows Node 完整2301／2301通過，fail／cancel／skip／todo皆0。
- 媒體原生驗收沿用 tools/qa/room-media-pot-polish.cjs，待播與播放端點是真 HTTP，YouTube 事件與 iframe 為 fixture；不當作真 YouTube 網路實播。
- 架構驗收沿用 tools/qa/architecture-234.cjs，更新腳本以實際中央抽卡入口操作，滑鼠作畫前先觸發處理影片同意提示；未放寬筆跡、ACK／SSE、倒數及換輪斷言。

證據保存在 ignored work/qa/default-layout-fit、work/qa/room-media-pot-polish 與 work/playtest/default-final-*.log；不提交測試資料或登入資訊。所有測試使用隔離資料，不重啟3022及其他舊試玩站。本批未推送、建立新PR或部署。

最終架構驗收通過一輪郎中女巫／購物／退款、1440／390／320原生尺寸，以及雙席畫猜持筆／延遲ACK／SSE、復原配額、重連、先清空再收到ACK、無SSE時HTTP接受、連續倒數、清空配額與自然選題／換輪。畫者736個取樣、觀看者746個取樣，22種途中筆跡量、4批確認；首筆後無歸零閃白，無pageerror。320px郎中頁首改兩列，未壓縮字體或隱藏房號。此為隔離瀏覽器尺寸驗收，不代表真觸控或九輪全擴充驗收。

最終媒體驗收通過：1280暗色與390亮色共22個十一遊戲管理入口；實際HTTP升降權、踢人確認取消、同桌影片選擇重載保留、最小化同iframe、自動續播、清單更新保留捲動，以及原生pointerleave／blur與已佔格無數字底牌。YT仍為fixture，無pageerror。手機聊天開媒體前關閉來源modal；播放器開啟時專注鍵層級低於媒體，避免蓋住清單操作，仍保留原Esc出口。
