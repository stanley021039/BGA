# 抽卡觀看與招式預覽修正（#412）

2026-11-23，候選 3.34.0，基準 main `e4a7f0fdcf3a647d68ec9a5bbd7fdf68d0ce9ac7`。同批新增 #413 主遊戲卡恢復不透明、#414 作者新碼獨立補領及 #415 一天登入大招券，原 3.33.1 本機候選合併為一次 minor 升版。

## 行為與原因

- 抽卡觀看在走勢／收盤階段使用填滿剩餘高度的 Grid。原容器僅依內容決定高度，但演出舞台使用 size containment，實測舞台只有 32px、螢幕為 0×0。修正後桌機舞台 988px 高，螢幕約 1313×844，手機螢幕約 338×217。
- 設定與收藏共用的招式預覽，讓舞台與清單共用一個依視窗高度計算的區域。舞台保留尺寸，清單取得剩餘高度並獨立捲動。移除清單原本額外的 42／62dvh 上限，避免舞台加清單超過視窗，捲軸下緣落在畫面外。
- 大嘴少華・宅宅吞原版及異色的追蹤存活時間統一為 3000ms。沿用共用 scene-rules、權威步進、400ms 接觸後咬合及失敗爆散，招式說明同步為 3 秒。
- #413 將主遊戲卡的底色改回完整共用 surface、封面透明度改回1，沿用原輪播顯隱。
- #414 停用「我愛作者」，改用「我愛作者我愛作者」；使用獨立authorRenewal紀錄，舊領取者也能再領新禮包一次，保留舊券與單份加成。此為最新確認，取代前輪共用領取設計。
- #415 登入一天可手動領一張大招券，舊帳號可補領；免費抽一個R大招，獨立於一般抽券及第50抽進度，詳[大招券規格](LOGIN-ULTIMATE-VOUCHER-415.md)。

沿用第三份 Figma 的共用元件與既有抽卡演出美術，本輪修正布局及時間設定。
