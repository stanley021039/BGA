# 共用資訊與操作列

2026-10-12，候選 1.28.4。使用者要求房號與離開房間之間有明確間距，同類排列收斂成基本元件。

採用既有 ui-control-row，加 ui-info-actions 提供 12px 的 ui-info-action-gap、垂直置中、可換列及至少 44px 操作高度。ui-room-code 保留 12ch 資訊槽；操作不縮小，父列與按鈕的 hidden 契約保持。純操作列仍沿用既有 8px，不以空白字元或逐頁 margin 排列。

套用瞎掰王、傳情畫意、猜歌、極簡、跑團及送禮／畫猜／同頻的房間 toolbar。移除跑團重複的 room-tools 幾何；雷霆與撲克已有獨立資訊區，保持各自布局。

驗證：八頁 32 組 Chromium headless CSS 布局（1440／390、亮暗），12px gap、房號切換外框穩定、hidden 狀態及無水平溢出。隔離畫猜持筆15採樣、ACK、觀看者筆跡、倒數、揭曉與下一輪通過。八個入口關係與 stylesheet 依賴回歸通過。真人觸控、跨瀏覽器與所有遊戲階段未由這組證據涵蓋；完整測試、CI、PR審查及公開站結果以本批 PR 留言為準。
