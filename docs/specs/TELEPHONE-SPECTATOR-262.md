# 傳情畫意觀戰（Issue #262）

## 首批範圍

- 首批只支援「傳情畫意」房間，使用者已確認先限單款遊戲。
- 登入使用者可從有房間代碼的入口選擇觀戰；觀戰身分獨立於玩家座位，不加入玩家名單、不占席位。
- 觀戰為唯讀：不提供玩家操作、聊天室、角色移動、表情、特效或房間管理入口；離開觀戰可返回一般房間入口。
- 觀戰畫面顯示公開玩家狀態、階段、回合與倒數。進行中不下發上一頁內容、題目、私有草稿或傳遞簿；全局結束後才顯示已公開的完整故事。
- API 不呼叫玩家 `view(id)`，使用專用的公開投影；使用者若已入座，必須回到玩家畫面。觀戰請求只允許 GET 並設速率限制。
- 第一版沒有觀戰聊天、中途轉為玩家、房主開關、延遲觀看或移動角色等功能。

## 驗收

- 遊戲結束前，觀戰 API 回傳 `task: null` 與 `books: []`，不下發私人任務、題目或草稿；完成後才公開 `books`。
- 觀戰者重新整理後以 URL 中的觀戰狀態重連，不建立席位。
- 觀戰 HTTP 端點不接受寫入；其他玩家 API 仍要求有效席位。
- 玩家可照常遊玩，觀戰者不改變玩家數、倒數、輪次或結果。
- 桌面及手機採只讀清楚布局；視覺瀏覽器驗收需記錄實際可用環境。

## 2026-10-25 候選實作

已接專用 GET 公開投影、入口觀戰按鈕、URL 重連與唯讀故事頁。每 2.5 秒讀取一次，低於每分鐘 30 次的 API 限制；背景分頁停止輪詢與畫面時鐘，回到前景恢復，離開後釋放請求與計時器。倒數偏移只在收到伺服器狀態時計算。

本機 Edge 已驗等待、出題、作畫、猜題及結束五階段的 1920 × 1080／390 × 844 畫面，未入座觀戰、秘密主題隱藏、刷新不占席、離開停止輪詢及受控 visibilitychange 暫停／恢復。全局結束才顯示三本各三頁；繪圖只讀。測試使用一位真人操作席、兩位腳本 AI 及一位獨立觀戰帳號，作畫／猜題截止由隔離 fixture 加速，沒有宣稱真實時間完整場次或實機觸控驗收。
