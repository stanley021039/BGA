# 房間遊戲唯讀觀戰擴充（#296）

2026-10-26，使用者要求「把其他遊戲的觀戰模式也做出來」。承接已完成的傳情畫意首批 #262，涵蓋目前所有房間遊戲（含 CEO／運動員）；休憩區提供唯讀房間狀態。股市為獨立頁，不在範圍。

## 契約

- 登入後以房間連結的 `?watch=1` 進入；觀戰不建立／恢復席位，不延長玩家在線，不提供房間管理、角色或遊戲寫入。觀戰可透過獨立入口傳送同桌純文字訊息，訊息註記觀戰身分。
- 觀眾可切換玩家的公開資訊。雷霆之路會標出所選車隊，切換時保留賽道比例與捲動位置。觀眾可自行開啟房間音樂，播放進度依房間狀態同步。
- 觀戰連結直接進入共用房間版面。左側人物卡可切換焦點，中央顯示公開遊戲狀態及該玩家的公開資訊，右側保留聊天室與音樂。窄畫面沿用玩家版的兩側抽屜。猜歌挑戰與郎中闖江湖顯示選定玩家已公開的年代軸或藥鍋。
- 玩家可在左側人物列表底部看到當前觀眾暱稱。觀眾離開後由房間即時狀態移除，觀眾人數與入座人數分開計算。
- 共用 GET 公開投影以白名單輸出公開桌面、階段、倒數、玩家與結果；不借用任何真實玩家身分。秘密資料依各遊戲原有揭曉時機公開。
- 雷霆之路觀戰沿用玩家版等待室及比賽版面，包括賽況列、賽道、車隊、移動骰及結果區。觀戰使用獨立的公開資料，遊戲操作停用。車輛以公開玩家代號連結車隊，未翻開的危險地形及擲骰結果照原時機公開。
- 撲克觀戰沿用玩家版等待室、環桌與下注區，切換視角時以所選席位旋轉牌桌；只顯示公共牌、籌碼及應公開的攤牌。畫猜只顯示畫布與公開提示；極簡只顯示輪到展示的畫作；傳情畫意保留結束才公開故事。
- 猜歌挑戰沿用玩家版階段、片段播放與年代軸卡片，切換視角會更新所選玩家的公開卡片。
- 同頻（含二選一變體）、送禮達人、瞎掰王、截碼戰、霧港跑團、王牌執行長、運動員、極簡畫家與傳情畫意共用各自的玩家版舞台。場外休憩區共用中央舞台與房間音樂。
- 你畫我猜共用等待、選題、揭曉、排名與公開猜題版面。即時畫布使用觀戰專用的唯讀繪圖接收器。塗鴉神諭沿用原舞台，只在原本公開的階段呈現畫板。郎中闖江湖共用占卜卡、大釜與計分板，依房間設定公開藥材進度。
- 同頻、送禮、猜歌、瞎掰、跑團保留各自的答案／分配／角色／計畫保密邊界。郎中遵守隱藏進度設定且不公開袋序、預抽、私人選項。CEO 不公開他人的公司調整；運動員不公開秘密選角、能力選項或秘密數字。
- 音樂片段沿用既有播放器與音訊裁切驗證；觀戰音訊路由只讀且驗證當前回合，不開放原生音源或其他題目。
- 同房換遊戲後，下一次公開快照直接更新觀戰畫面與 URL；再玩回等待室清空前局畫面。讀取最多一個在途，含逾時、hidden／pagehide／離頁取消與遲到回應防護。
- UI 沿用第三份 Figma 的現有 Stitch 共用元件與已接受的觀戰唯讀方向，不新增設計語言或素材。

## 驗收

逐款測公開投影、秘密 canary、無席位寫入拒絕、未登入／被踢／錯誤 method、重載、再玩與切遊戲；桌機1920×1080與手機390px查看代表階段、錯誤與完成狀態。畫猜另驗持筆／ACK／換輪與觀戰途中增量，不能只比較最終圖片。使用獨立資料庫與合成玩家，未驗證項目如實保留。完整測試與建置依序執行，避免測試讀到重建中的 dist。

新 PR／Draft 轉 Ready 依使用者長期規則另行確認；本票不代表合併或部署授權。
