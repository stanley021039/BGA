# 房間遊戲唯讀觀戰擴充（#296）

2026-10-26，使用者要求「把其他遊戲的觀戰模式也做出來」。承接已完成的傳情畫意首批 #262，涵蓋目前所有房間遊戲（含 CEO／運動員）；休憩區提供唯讀房間狀態。股市為獨立頁，不在範圍。

## 契約

- 登入後以房間連結的 `?watch=1` 進入；觀戰不建立／恢復席位，不延長玩家在線，不提供房間管理、聊天、角色或遊戲寫入。
- 共用 GET 公開投影以白名單輸出公開桌面、階段、倒數、玩家與結果；不借用任何真實玩家身分。秘密資料依各遊戲原有揭曉時機公開。
- 撲克只顯示公共牌、籌碼及應公開的攤牌；畫猜只顯示畫布與公開提示；極簡只顯示輪到展示的畫作；傳情畫意保留結束才公開故事。
- 同頻、送禮、猜歌、瞎掰、跑團保留各自的答案／分配／角色／計畫保密邊界。郎中遵守隱藏進度設定且不公開袋序、預抽、私人選項。CEO 不公開他人的公司調整；運動員不公開秘密選角、能力選項或秘密數字。
- 音樂片段沿用既有播放器與音訊裁切驗證；觀戰音訊路由只讀且驗證當前回合，不開放原生音源或其他題目。
- 同房換遊戲後，下一次公開快照直接更新觀戰畫面與 URL；再玩回等待室清空前局畫面。讀取最多一個在途，含逾時、hidden／pagehide／離頁取消與遲到回應防護。
- UI 沿用第三份 Figma 的現有 Stitch 共用元件與已接受的觀戰唯讀方向，不新增設計語言或素材。

## 驗收

逐款測公開投影、秘密 canary、無席位寫入拒絕、未登入／被踢／錯誤 method、重載、再玩與切遊戲；桌機1920×1080與手機390px查看代表階段、錯誤與完成狀態。畫猜另驗持筆／ACK／換輪與觀戰途中增量，不能只比較最終圖片。使用獨立資料庫與合成玩家，未驗證項目如實保留。完整測試與建置依序執行，避免測試讀到重建中的 dist。

新 PR／Draft 轉 Ready 依使用者長期規則另行確認；本票不代表合併或部署授權。
