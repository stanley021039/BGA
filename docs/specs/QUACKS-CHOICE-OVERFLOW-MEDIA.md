# 藥材選項、溢出盆與播放器模式

日期：2026-10-16；本機候選 2.15.0。使用者本聊天截圖與後續補充為需求來源。保留最新 main f17ea43 的共用介面與三欄架構；未推送、新建 PR 或部署。

## 行為與範圍

- 移除大釜中央「本輪投入」重複列；名冊中的已投入藥材保留。普通郎中畫面不再顯示浮動專注鍵，「更多」中的專注入口、進入後退出鍵與 Esc 保留。
- 所有 pending 藥材候選使用 QuacksArt 圖示，涵蓋愚人草收回、藍色預抽、占卜卡贈送／交換、女巫與煉金術士購藥／升級；暫存／預抽投入亦圖示化。保留數值、中文可讀名稱、滑鼠／focus／觸控提示、費用與 disabled。交換與升級展示前後圖示；非藥材選項保留文字。
- 快速成交先在本機選金／銅／銀女巫幣，再顯示該幣可換藥材；可重選或保留女巫幣。第一步不提交、不扣幣；第二步提交原本 choiceId／optionId，服務端一次驗證並執行棄幣與獲藥。輪詢保留同一選擇，換房／回合／pending 重設；busy、失效或 disabled 不提交。
- 特效藥選位面板取消內層固定高度與捲軸，保留病患、完整燒瓶軌道及確認。重複標題只在中央特效藥階段隱藏；其他煉金術士介面不套用。
- 第 52 格後大釜位置與 pot 不再變動，舊 renderer key 未包含 overflow，導致資料已進盆而畫面停住。key 納入 overflow 及女巫擴充狀態；無變更輪詢仍不重畫。沒有改動抽藥規則、爆炸門檻或分數算法。
- 播放器有三種大小：原尺寸、保留影片的小視窗、56px 橫條。依使用者最新補充，橫條仍播放音樂及已接受影片的音訊；切換不重新建立播放器、不暫停／切換全桌。僅這個明確選取的橫條模式豁免一般影片可見尺寸／intersection 退出，普通／小視窗遮擋與不足空間的保護保留。關閉自己的視窗仍沿用退出影片行為。同桌同意、音量、清單權限與續播保持原契約。
- 移除清單窗可見「點播與清單」大標題，保留 accessible title、拖曳與關閉入口。
