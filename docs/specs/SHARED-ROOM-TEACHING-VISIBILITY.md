# 房間教學顯示條件

日期：2026-10-12。來源：使用者要求「一分鐘學會傳情畫意」這類教學在遊戲中都不要顯示。

## 行為

- 等待開局：保留教學。五款「一分鐘學會」仍在介紹圖片右方的敘述區塊最下方。
- 遊玩中的所有階段及結算：隱藏教學與教學入口，不保留占位空間；重新整理直接進入對局時也隱藏。
- 等待時已開啟的遊戲說明 dialog，在對局開始後關閉。
- 未加入房間的介紹頁及獨立賽車教學桌保留教學。教學桌的離開入口仍可使用。
- 當前可執行操作、倒數、題目、角色與作畫限制等必要資訊維持顯示。

## 共用實作與盤點

`public/shared/room-waiting.js` 的 `updateTeaching` 統一處理狀態，所有遊戲由既有 `GameShell.update`／`RoomWaiting.update` 呼叫。HTML 以 `data-room-teaching` 明確標示內容或入口，`data-room-teaching-dialog` 標示教學視窗；不以文字關鍵字搜尋或隱藏一般操作提示。房間路徑在等待初次狀態時先隱藏，非房間介紹與 `RaceLesson` 保持可用。`room-waiting.css` 保證標記節點的 `[hidden]` 不被各頁 display 規則覆蓋。

| 遊戲 | 教學內容／入口 |
| --- | --- |
| 傳情畫意、極簡畫家、猜歌挑戰、瞎掰王、霧港跑團 | `details#guide` |
| 你畫我猜、同頻俱樂部、送禮達人 | `#help` 與教學 `dialog#rules` |
| 德州撲克 | 德州撲克說明連結 |
| 末路狂飆 | 新手教學連結、等待介紹的教學連結與操作提示內的教學導流段落 |

極簡畫家移除個別教學判斷，沿用同一套共用條件；本場回顧仍獨立依結果數量顯示。作畫、猜题、送出與換輪邏輯沒有更動。
