## 主持連線

測試站採支援的 SSH worker：管理者在已正常登入 ChatGPT 的電腦手動啟動 `tools/coc-cli-worker.py`，呼叫官方 Codex CLI。登入資料留在官方 CLI，沒有讀取或搬移 auth 檔。VM 原生隔離 CLI 仍是另一個選用模式；本機 worker 不需要先完成 VM 登入。操作方式見 [CLI 操作說明](../COC-CLI-OPERATIONS.md)。

完整冒險開關已在隔離測試站開啟。CLI 中斷不自動改用付費 API。網站仍可查看保存進度；重連後由房主明確重試。正常回覆、失敗與未知消耗寫入呼叫帳本，未知用量保留預留額度。網站 token 上限不能換算為訂閱剩餘百分比。OpenAI／Claude API 為額外選用連線，未用實際 API key 驗收。

## 合成分支、實際 HTTP 驗收

下列使用專屬合成冒險 checkpoint，再走網站 API／伺服器真實骰值；不能當成正常完整實玩。部分分支明確使用未設定的 QA API，僅在失敗後移除該段敘事等待；沒有把它當成真實 AI 成功。

- 四席準備、非房主／非成員／私人角色權限、同 requestId 冪等性、修改內容重用 ID 拒絕；原卡改版不影響已建立副本。
- 多傷者、兩人離席／重返、原 SAN／戰鬥結果與順序恢復相同；已脫離戰鬥者重返仍維持脫離；離席者有未決結果時不可繞過。
- 全隊失能保持暫停。三票不足、一票否決取消，四票同意才以 overwhelmed 結束，不給治療、復活或額外時間。
- 巨物 HP0 即 repelled，其他守衛存活不會封死結局。
- 儀式 89.9 分鐘失敗、90 分鐘成功；開始時刻、目標缺席、魔力不足、施法力量不足均拒絕，資源與時間不變。新增十分鐘等待與開始前可持續時間提示。已離席的唯一老師不出現在可用教導行動，直接請求亦拒絕。

## 交付與限制

只部署隔離測試站；程式語法、Vue 型別、Vite 建置、差異與 minor 版號／CHANGELOG 檢查另留部署收據。沒有執行 test 套件，沒有 PR、push、main 合併、tag 或正式站變更。

schema 21 的 COC 表需要與未來主線整合時重新核對，不可只看 schema 數字相同就當成相容。API 金鑰以 AES-256-GCM 保護，主密鑰在資料庫及公開目錄外；備份搬移須保留原保護金鑰或重新輸入 API key。

所有結局與任意操作組合沒有窮舉。真實多人同時操作、實機手機、真實付費 API、公開代管資格及商業發布授權沒有在本輪宣稱驗證。後續若要正式發布，另核對來源授權及固定 main 提交。

## 2026-10-29：主持簡短回覆與直接裁定

一般主持敘述改為一至二句、原則80字內，伺服器保留最多120字。不重述時間、房門、場景與歷史，不以詢問下一步或確認意圖收尾；完整線索、骰值與事件仍保存在手記。

自由輸入先承接最近八筆公開紀錄與同一角色在同場景的一次澄清。已描述清楚的調查與移動直接選擇支援行動；重大代價、共同移動與手動檢定仍遵循原規則。交談直接由同一次 CLI 回覆結束，時間與資源不變。沒有重大效果、無須判定或改動持久物件的小動作，可以產生可見反應並前進一分鐘；不存在的材料／對象或尚不能成立的重大做法，直接說明眼前受限結果，零分鐘。這些回覆不授予新線索、物品、數值或逃離條件。
