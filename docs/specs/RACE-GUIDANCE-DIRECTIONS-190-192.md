# 雷霆之路：路線提示與骰面方向（#190、#192）

2026-10-23，候選 2.34.1。依使用者要求，兩張修正合在同一 PR，完成後再另外處理 #193。沿用第三份 Figma 已核准的 RD／RD-X 棋盤與碰撞視窗（`docs/refactors/STITCH-BLUFF-RACE-APPROVED.md`），沒有新增設計稿或宣稱本次 Figma／Stitch 匯出。

## 已確認原因與修正

Vue 路線落點及其車輛的 SVG `title` 仍會提供原生延遲提示。舊版頁面的地形提示在 500ms 後開啟，也未排除引導路線。另在原生驗收發現 Vue 的 watch getter 每次建立新陣列，使相同 version／phase 的 presence 輪詢仍清掉預覽；實際編譯場景回歸先失敗再通過。

目前路線 Map 涵蓋的落點與車輛不產生原生 title，舊版延遲提示在進入及 timer 到期時都檢查路線；不攔截滑鼠、鍵盤或觸控選路。地形完整說明與公開危險資訊保留在可及名稱，非路線格／車輛原有 title 及地形圖例仍可查看。Vue 線上與教學只在真正的 version／phase 改變時清除舊預覽，同狀態輪詢保留持續預覽。本條取代較早 `RACE-TERRAIN-HELP.md` 對棋盤 tooltip 全部原樣保留的說明，例外僅限引導路線。

賽道投影以前方朝右、車道依畫面上下排列，舊 WebGL 骰面卻把前方畫成朝上、後方朝下。新增純呈現用 `RaceDirections`，供 DOM SVG、WebGL 貼圖、結果補充與舊版待確認文案共用；方向中文與箭頭直接採畫面方向，可及名稱及結果仍附原規則名稱。骰值、機率、遮罩、重擲權限、時機、server neighbor／碰撞規則與歷史資料不改。

方向名稱不解讀為新的規則方向；未知或非方向骰沿用既有文字／點數回退。新 helper 在兩份入口先於骰子 renderer 載入，經 HTTP 白名單提供。方向名稱在 WebGL 顯示及關閉回退時都可見，不把可選 GPU 當成唯一必要資訊。

## 回歸與驗收

- 延遲提示回歸先證明引導期間會顯示，再驗停留、重入、鍵盤聚焦、點擊不被取消及引導結束後恢復一般地形說明。
- 編譯／掛載真 RaceBoard、線上 RaceScene 與教學 RaceLessonScene：同狀態 presence 保留預覽、盤面變動清除；路線 title 排除、可及說明及 Space 啟用保留；六方向與兩種車道奇偶的實際 DOM transform 對照引擎 neighbor。
- 六方向 WebGL 貼圖向量、DOM 標籤、同 cycle 遮罩／輪詢、GL 回退及 server 值未改；helper 未知輸入、HTTP 資源與載入順序也有測試。
- `tools/qa/race-guidance-directions.cjs` 使用隔離 HTTP、兩個合成帳戶、固定起始棋盤及結果序列，經真正選車／出發、點落點、擲骰、重擲與確認執行引擎碰撞。桌機 1920×1080 淺色、390×844 深色手機模擬，核對全部六個實際位移及另一次重擲、途中長停留／重入、modal 邊界、最後位置；教學再驗鍵盤／觸控繞行到旗幟、地形圖例與專注／Esc。最終結果與截圖清單以 `work/qa-race-guidance-directions/metrics.json` 及 PR 為準，舊批截圖不冒稱本批。

手機是 Chrome 視窗／觸控模擬，沒有實體手機或 Safari 證據。原生 title 氣泡不在 DOM 截圖內；沒有聲稱擷取作業系統氣泡逐幀畫面，以真正長停留後 DOM 無 title／自訂 tooltip、回歸與預覽持續性驗證本次排除。隔離固定結果不代表自然隨機機率的統計實驗。

最終原生腳本通過七個碰撞局面：六方向各自確認實際落點，另一次重擲後再確認；兩席共 16 個結果畫面均使用實際可選 WebGL，沒有 pageerror 或水平溢位。桌機骰窗 750×606.375、手機 358×757.96875，16 次量測皆在實際 viewport 內；結果改採 viewport 截圖，沒有把長頁截圖誤當成視窗邊界證據。鍵盤／觸控繞行到旗幟、保留地形圖例與專注／Esc 均通過。這是呈現／時序及位置驗收，沒有宣稱逐幀 FPS 或真人聽感。

本輪依固定 Prettier 格式化已修改的舊版檔與測試，移除 baseline 例外，不新增忽略。幾個舊 VM fixture 的截取邊界原本硬編碼等號空白，隨格式修正為穩定邊界；初次完整測試的 command-options fixture 因此失敗，同檔四項修正後通過，最終完整與 CI 結果詳 PR。CI 由只跑電話前端擴為前端全套，納入新場景回歸；根目錄全套不縮減。未部署、未操作正式資料。
