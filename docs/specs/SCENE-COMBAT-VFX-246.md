# 場景戰鬥與新版攻擊特效

候選 2.44.0，2026-10-24；追蹤 [#246](https://github.com/stanley021039/BGA/issues/246)。從 main `b7e62ef` 建立獨立候選，保留已合併的共用場景、設定頁及傳話修正。

## 行為

- 七圓環沿用 `sphere` ID，七層粉紫花瓣圓盾作用於自己。八向實體鏈環沿用 `chains`；六具龍騎兵沿用 `funnel`，先飛行、包圍聚能，再微差齊射與折返。爆裂魔法保留施法圓陣並以蘑菇雲收尾；五根大小不同的冰川錯落破土；藍黑劍氣使用實黑核心，紅黑仍獨立。
- 新增 `flame_kick`：烈焰俯衝、十字衝擊及穿透目標後的戰靴刻紋。既有 ID／配裝與解鎖紀錄保留；新招對應 `thunder-first-drive`，其他獎勵兌換及既有 other 資格亦涵蓋新招。預設仍僅前兩招免費。
- 所有玩家暴擊率25%，倍率1.5。保留 main 已有的場景長邊50%射程、生命110萬–130萬、普通18萬–22萬（任意整數）、4秒未受擊後每秒回4萬、兩鍵各2秒冷卻及3秒重生。活著仍不顯示血條或生命數字。
- 已兌換「我愛作者」的 other 獎勵資格：生命／回血1.5倍、傷害1.15倍，分別為生命165萬–195萬、每秒回血6萬、普通207000–253000。使用既有有效兌換紀錄及相容的舊全獎勵資格，不新增資料表或偽造成就。
- 兩盾施放後提供2秒保護；每次受擊獨立抽一般30–40%、作者40–50%的整數減傷百分比。先結算攻擊加成／暴擊，再套用防禦減傷。兩盾共用到期時間，再施放只刷新、不疊加；過期、倒地、重生清除。重送舊操作不刷新保護。
- 兌換資格即時從伺服器讀取。房間座位ID經私有帳號映射判斷，不接受客戶端加成欄位。已在場角色保持受傷比例，不藉兌換直接補滿；重複兌換／輪詢不疊加。
- 一次攻擊事件只造成一次伺服器傷害；多段光束／粒子為同一事件的外觀，沒有逐顆子彈額外扣血。傷害跳字使用伺服器最終數字、限制於畫布邊界；超過剩餘生命仍顯示完整傷害，生命最低為0。收藏預覽使用一般示範範圍。
- 六角護盾依小預覽尺寸縮放，避免蜂巢環在設定頁／手機被裁切；桌機場景維持原最大尺寸。新增回歸先確認原版失敗，再驗證修正。

## 設計來源與資源

Stitch 最終原稿：專案 `14297655819267599636`，畫面 `092b55de5a37454086c03f4b02a12971`。七款演出已對照第三份 Figma [2219:11472](https://www.figma.com/design/swrZgTpIsRS4JSGBa4mQhq?node-id=2219-11472)；該區是原稿畫布擷取及可編輯說明，並非可編輯動畫圖層。完整三專案匯入另案處理。

`attack-stitch.js` 是已核對繪製程式的有限時序適配，不執行匯出 HTML、外部 UI 控制或遠端腳本。保留既有 motion-lifetime、3個並行、4.2秒、1280×900畫布及每池220筆預算。新效果沒有額外rAF／timer／網路素材；鏈環每方向最多24個，龍騎兵固定6具。修正原稿拖尾負半徑及靴印過早消失，手機靴印保持可視。停用動態／reduce／hidden／pagehide、正常到期與卸載沿用共用清理，不補播過期事件。

## 驗收與限制

- 規則回歸涵蓋暴擊25%邊界、一般／作者傷害與回血、有效資格、房間帳號映射、其他碼不授權、不可偽造、即時兌換、盾上下限／刷新／到期／死亡與重生，以及操作重送。
- 繪製回歸涵蓋七層花瓣、八方鏈環、龍騎兵先展開再射擊、錯落冰川、蘑菇雲、靴印穿透與小預覽邊界；維持原有彩虹連射、互斥劍氣與權威跳字。
- 整合前本機已做桌機1920×1080、390px預覽、深淺色、房內Q/E/R與邊界穿越、途中關閉動態及墓碑／重生觀察；本候選會另記錄最新 main 上的測試與操作結果，舊結果不代替整合驗證。
- 未驗實體手機、Safari、實體GPU FPS／聲卡聽感及OS層級reduce切換；reduce／pagehide清理由自動回歸覆蓋。本批沒有新音訊或圖片，不改私有題庫音源。
- 不改桌遊分數、遊戲存活、勝負或歷史；不操作正式資料。PR發布、CI、合併及部署狀態分開記錄。
