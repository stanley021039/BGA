## 第一批實作範圍

本批是規則資料、招募／秘密選角與競速基礎函式，尚非可操作的完整遊戲。不註冊房間 API 或大廳入口，不以角色資料存在宣稱 36 種能力已實作，也不以無能力擲骰賽冒稱 Second Wind。

- `src/games/second-wind/catalog.js`：36 名原版角色、13 張 Twist 的中文規則摘要、時機、可選性、交互註解與 PDF 頁碼；所有完整能力狀態仍為 `pending`。阿羅拉／寶可夢內容完全不採用。
- `draft.js`：3–6 人先手擲骰、兩次蛇形選秀（每次開 2n 張，第二次從原起選者左邊開始）、各四名角色、獨立第一場先手擲骰、同時秘密鎖角與全員鎖定後揭示。只執行到 `race-ready`，不偽造後續完賽。
- 先手取最高不重複點數。最高並列往下找；若無單獨點數則全員重擲。最高並列採次高依 PDF 第 12 頁；多層並列的延伸政策另留原票，不能宣稱已獲額外官方裁定。
- 主程序預設使用 256-bit 隨機 key、HMAC-SHA256 計數流及拒絕取樣，亂數狀態與未抽牌不進玩家投影。明確 seed 僅供可信任測試建構，不接受客戶端指定；每個行動在副本中處理，非法／舊版本不消耗牌序與亂數。
- `motion.js`：移動與傳送、前後超越、同時傳送、零移動及終點邊界的純函式；絆倒不提早中止當次移動，下次主移動的擲骰／恢復時機（含 Penguin 例外）；賽道→當前席位→順時針其他席位的觸發順序，以及單次結算鏈的循環／預算防護。回傳的是待能力引擎處理的事實，尚未自行執行所有停格效果。
- `powers.js`：NULL 即時失能投影、同格不算前後、原生 Re-Runner 場外效果與複製限制、Stunner／Party Pooper 的有效擲骰限制。強制骰處理會先撤回六，產生 Party Pooper 移動反應，待反應處理後才重擲；其餘候選值仍需經 Critic 等可選重擲視窗，不能提前套 Icarus 淘汰。
