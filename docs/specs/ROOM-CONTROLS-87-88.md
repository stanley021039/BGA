## 畫猜結算

建房時選固定輪數或分數達標。固定輪數明確定義為總題數，不是一整圈；1–64 題，畫者依入座順序跨圈輪替。建房 UI 預設 8 題；分數模式 10–1000 分、預設100分，當題完整揭曉後有任一仍在席的玩家達標才結束，原計分與每輪正常參與紀錄不變。不在某人猜中瞬間切斷其他人的回合。

分數模式最長64題，未達分數也會結束，UI說明此上限；題源用完或玩家不足沿用原結束原因。即時結果／收藏回顧維持最近八輪，既有歷史逐步保留題目、猜中次序與分數，不新增長期畫作保存；避免長局每次snapshot無界膨脹。舊客戶端未送 ending 時維持每人畫一次及原揭曉／結束流程；舊設定請求不送 ending 也不清掉建房的選擇。進行中仍禁止更改設定。

API只接受 mode rounds／score 和整數範圍，建房先驗才建立 history／席位；options／歷史保留條件。房間內顯示固定幾題或分數與64題上限。未做進行中切換、依完整圈設定、強制結束按鈕或新的成就。

## 影片視窗

主視窗關閉與Escape在目前為影片時改成縮小：同一個非modal dialog保留開啟、可見 iframe、觀看同意與播放狀態。小播放器可展開或直接開清單新增待播；metadata／queue更新不銷毀、重新seek或重播目前影片，換片沿用縮小模式。小窗的X是明確停止自己的影片並關閉；既有影片退出、手動暫停／停止、頁面隱藏、其他modal、空間不足與離頁清理仍保留。音樂視窗關閉沿用原背景聆聽行為。

保留YouTube原生控制、既有Referer、觀看同意與可見性判定，不做隱藏影片背景播放。小窗預設360×340，實際可用區隨viewport及工具列測量；不足時仍停止本機影片，不放寬可見性。原來源 [YouTube Required Minimum Functionality](https://developers.google.com/youtube/terms/required-minimum-functionality)（2026-10-09查閱）要求播放器至少200×200，自動播放時須超過一半可見，不能遮住原生播放器／控制項。本輪只改自己的呈現，沒有改全桌權限或播放協定。

未做跨頁背景影片、完全隱藏續播、超小視窗保證、瀏覽器自動播放限制繞過或進度心跳。房主與管理者權限、native fallback、其他房員選擇、停止後不被新增待播自動復活，沿用現有保護。
