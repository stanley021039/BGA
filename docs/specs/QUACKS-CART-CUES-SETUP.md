# 郎中：可取消購物、兩步開局與使用者音效

日期：2026-10-14（Asia/Taipei）；候選 2.5.0，本機完成，未推送、發布 PR 或部署。先整合 origin/main 1ca5eb1 的離房縮圖；保留其他人新版共用介面，原未發布 2.4.0 郎中批次升至 2.5.0，避免撞版。

## 本輪需求與行为

1. 購物選中後再次點擊原藥材即可取消。退還原價格，只撤回這次購買的精確 chip ID，不刪除既有同色同級藥材；第一片／第二片都可取消。紫色獨立預算另算；双買贈便宜片同步撤回；黑色第5面對鄰座的贈藥及買方实际液滴增量也同步回復。退款操作沿用 roundId／requestId 去重。
2. 依使用者提供音效轉檔：抽卡取 0.04–1.54 秒，1.5 秒、1800 Hz 低通、峰值約 23%；抽藥取 10.8–11.45 秒，0.65 秒、2800 Hz 低通、峰值約 40%。24 kHz 單聲道 PCM16，10 ms 淡入／60 ms 淡出。原 MP3 留在使用者本機，網站僅放處理後 WAV。
3. 房主先選房間設定，勾選自动儲存，無保存設定按鈕；「設定完成，選藥材書」開啟第二步。開始前 flush 共用設定佇列；錯誤保留回饋且不開始。其他玩家可投書面，票制不變。
4. 占卜牌不再印「立即結算／回合結算」標籤；immediate 是紫色，round 是藍色。顏色由真实牌 timing 決定，修正霓光主題優先權；名稱與效果保持可讀。
5. 抽／停圖片與藥水瓶統一 66×64 px，含手機；原動作與 hover／focus／點選提示保留。
6. 特效藥階段直接顯示本輪計算上限；沿用已確認規則，仍須确认領獎，亦可選較低格。首載／重新整理由伺服器 max 與 essence 同步，沒有虛構推進。
7. 大釜名稱、命名入口與人物切換移到鍋下左側；鍋圖置於主框頂部。藥袋保留右上角，資源與液滴／老鼠石資訊保持左下。

## 取消購物的边界

購物完畢、換輪或有待處理效果時不能取消。已使用女巫、紅寶石或購物階段的效果選項會提交當時購物，避免退款後保留依該購買生成的後續效果；提示會說明不能取消。若鄰座已经消耗或改動收到的藥材，也不能撤回該購買。之後新的独立購買可依其交易狀態取消。精確 journal 僅存在伺服器；本人僅收到 canUndo，不對其他玩家公開藥袋內容／chip ID。

## 來源與限制

本輪兩個聲音來源為使用者提供「抽卡.mp3」「抽藥.mp3」，不是原創合成。轉檔工具 tools/convert-quacks-sounds.cjs 接受 ffmpeg 與兩輸入路徑；manifest 保存來源檔名／輸入與輸出 SHA256、裁切與濾波參數，不存憑證或私人路徑。原創爆炸仍由 generate-quacks-sounds.cjs 生成；該工具不再覆蓋使用者音效。人物 PNG 這輪未編輯。

證據為隔離 SQLite 與合成帳號，不操作正式資料。未驗喇叭／耳機主觀聽感、Safari、實機手機或 OS 全螢幕。native playing 只證明瀏覽器播放事件，不能推定主觀音質；試玩後仍可調整裁切或音色。原片權利來源未獨立查驗，不標為本站原創或開放授權。

另建3007隔離新版試玩桌；從原3006隔離SQLite做 read-only VACUUM INTO 一致快照，保留既有帳號與登入 session。未重啟、終止或修改3005／3006的使用中牌局。新房與程序資訊僅在 ignored work/playtest/quacks-cart-runtime.json。
