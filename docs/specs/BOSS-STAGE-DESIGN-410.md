# Boss 二階段與最終階段設計提案（2026-11-15）

狀態：提案，尚未實裝招式新效果、外觀變形或本稿的新攻擊分鏡。使用者要求先想效果，之後再實裝。現有三段生命／鎖血／狂暴倍率保留；介面的第三階段更名「最終階段」。本稿也適用之後新增的Boss。

## 共通規格

- 第一階段保留目前Q／E／R；二階段開始加入各Boss獨有機制；最終階段增加可讀的招式變化。每隻仍是兩個普通招式、一個蓄力大招，不用大量換名技能湊數。
- 已確認的二／最終階段傷害、移速、出招頻率分別×1.15／1.30，相對第一階段；下表新增機制不再暗中疊一輪全面倍率。
- 一條長血條以兩道刻線分成三段；每次施放合計最多打完當前一段，換段鎖血2秒，不跨段溢傷。鎖血期間不讓先前施放的尾段在結束後穿到下一段。
- 每招維持可辨識預告、危險範圍與安全區；最終階段也不能變必中。追蹤鎖定在預告結束前完成，避開玩家落點後不再瞬間校正。普通預警建議至少0.55秒、大招至少1.4秒；實裝時需與已確認攻速倍率一併核定，不直接套用未經驗收的加速。
- 新的麻痺效果建議普通招式不超過0.4秒、大招不超過0.8秒，同一施放一次；跨Boss控制要有共同保護時間，避免輪流鎖死。減速／減療／回能下降只取較強者或刷新，不疊到不能操作。持續地面區建議最多2秒，傷害另設同一目標間隔。
- 不把黑畫面、強制反轉操作、全圖無安全區或瞬間貼身必中當成難度。關閉動態仍保留靜態危險圖形、倒數與必要狀態。

## 攻擊特效重製規格

此節為美術設計，尚未重製renderer。每招重做四段：蓄力（肢體姿勢／能量路徑）→發射（真實爪／嘴／砲口／手套）→命中（壓縮、裂痕、爆發或材質）→衰退（碎屑／煙／光痕消失）。不以放大同一個圓圈、換色或增加粒子數替代重製。普通招式應能辨識Q與E，R有獨立構圖及節奏。

仍遵守既有畫布與有限元素預算、相機座標和伺服器判定；視覺加大不擅自擴大命中區。二階段增加局部細節，最終階段改變局部輪廓與節奏，不把整隻Boss持續罩在不透明特效裡。角色、預警與攻擊圖層分開；減少動態有清楚靜態版本，結束／死亡／離場即清場。

新Boss必交付：Q／E／R三招資料、三階段變化表、局部外觀變化、四段分鏡、靜態預警、控制與傷害上限、生命版本清理、玩家招式互動測試。未交付不能標成已完整支援三階段。
