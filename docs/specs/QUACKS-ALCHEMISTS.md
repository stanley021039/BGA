# 郎中闖江湖：煉金術士

2026-10-13；本機候選 2.4.0。使用者確認基本版＋草藥女巫先完成後，本輪接續煉金術士；未推送或部署本輪新增內容。

## 模式與病患
房主在房間設定獨立勾選煉金術士、草藥女巫。基本／煉金術士單獨最多4人；女巫最多5人。開始後八種病患中不重複隨機抽三種，每人選一名，可重複；全員選定才進入第一輪占卜。胡蘿蔔鼻多南瓜1，健忘症多紅色1及藍色1。局中病患鎖定。

## 階段與計算
全員完成普通抽藥、額外效果及暫存決定，先完成既有結算前女巫（保留救援重回製藥的出口），再進入特效藥階段，之後是原本獎勵骰／藥材／格位／購物。爆炸者也調製特效藥。

每輪把指示物重設0，按大釜實際彩色種類（不含白色炸彈）、白色數值恰好7時加1、每名不同的左右鄰座爆炸加1；兩人只計對手一次。新愚人草第一面每片再加1，特定占卜牌再加對應格數；最高10。以計算開始時的大釜作固定快照，耳蟲額外投入不重算。草藥女巫溢出盤不列入大釜彩色種類。

可選任一已到達的較低格再領獎勵；伺服器確認一次，重試不重複。第九輪只獲所選格數的分數，不領該格病患、骰子、鼠尾巴或其他特效藥獎勵。第八輪已取得的下一輪能力仍可在第九輪製藥使用。

## 八種病患
- 精神緊張：第1格下輪多1條鼠尾巴；第2–10格下輪預抽1／2／3／4／5／6／7／8／10片。白色炸彈放回袋；彩色只給本人看，普通抽藥可用其中一片取代隨機抽取，仍算一次普通抽藥。紅色第二面須停止後投入。未用完回袋。
- 耳蟲：第1–10格額外抽1／1／2／2／3／3／4／4／5／6片；第2／4／6／8格另給下輪1條鼠尾巴。逐片處理及執行連鎖效果，既有爆炸保留，額外投入不引發新爆炸。紅色第二面抽到也算片数。
- 胡蘿蔔鼻：開局多南瓜1；第二輪起可花2格特效藥，將新抽南瓜送至下一個紅寶石格，忽略南瓜數值。第1／3／5格下輪加1條鼠尾巴；第7／8格1分，第9／10格2分。
- 招風耳：第二輪起，未引爆的白色炸彈可花2格按實際數值走兩倍，或花3格放回袋；可照常投入。第1格下輪加1條鼠尾巴；第7／8格1分，第9／10格2分。
- 雞眼：第1–10格依序為紅寶石1、南瓜1、1級升2級、補瓶、紅色1、紅寶石3、擲骰2次、液滴+2、1級升4級、擲骰4次。只可升成實際存在的同色級別；擲骰由玩家親自操作、全桌結果公開。
- 女巫駝峰：第二輪起，製藥中投入藥材落在紅寶石格可花2格領獎勵：1級→紅寶石1；2級或黑色→擲骰一次；3級或紫色→黃色1；4級或愚人草→3分。按實體藥材種類與數值，紅色第二面停止後投入不觸發。被動鼠尾巴與分數同胡蘿蔔鼻。
- 健忘症：開局多紅色1、藍色1；第二輪起可收回已投入的彩色藥材（白色、愚人草除外），花其實際數值的特效藥；其他藥材、已得效果與目前進度不倒退。第7／8格1分，第9／10格2分。後續藥水瓶收回白色炸彈保留真實投入前格位，包括空隙。
- 吸血鬼化：第1格下輪加1條鼠尾巴；第2–10格獨立買一片預算2／4／6／8／10／12／14／16／18。不占普通購物次數，不留餘款；遵守黃色第2輪、紫色第3輪解鎖。

## 四面愚人草
與草藥女巫的兩面獨立搭配，沿用逐色真人投票、房主平票決定。內部面號7–10，畫面標示煉金術士第1–4面，價格11／16／10／12。
1. 走1格，特效藥計算每片再加1格，愚人草顏色本身仍算一種。
2. 按已有彩色種類走，包括當前第一片愚人草；忽略數值。
3. 走1格，可收回任一非白色藥材，其餘格位不變。
4. 按投入前白色炸彈數值總和走，沒有白色則走1格。
