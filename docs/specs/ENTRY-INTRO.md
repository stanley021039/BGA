# #138 每次進頁開場動畫

2026-10-21，依使用者最新確認實作，本機 2.19.0 候選；先預覽、不合併、不部署。

## 已確認範圍

- 每次載入內容頁 HTML（包含重新整理、重新開頁及 BFCache 返回）播放一次；不是每次點擊頁內操作都播放。依使用者同輪修正，登入／註冊／重設密碼頁不先播開場，直接顯示表單。
- 沿用既有圖片且不加邊框、圓角或陰影。登入／註冊成功後，從該圖片原有的位置與大小逐漸放大至中央，最後圖片與遮罩淡出，全程約 3 秒。其他直接進頁使用初華圖片由 0.72 倍放大。
- 原頁面在遮罩背後正常載入，不延遲 Vue 掛載、API 或房間連線。結束後揭露該頁；慢速網路仍依原頁面顯示載入／錯誤狀態。
- 保留現有登入 session 與深連結；不強迫登出、不另儲存帳密。
- 可點「略過開場」或按 Esc；遵循減少動態偏好，以靜態圖片淡出替代縮放。
- 不更換登入／大廳／遊戲設計稿，不修改郎中圖像效果、遊戲規則或資料。

## 實作邊界

伺服器完成原有權限檢查後，用 `src/http/entry-intro.js` 裝飾 Vue 與 legacy HTML；API、音檔、圖片不包裝。共用外部 CSS／JS 與同一圖片預載；沒有新增素材下載或音效。舊頁可省略 head/body 標籤，且支援 Prettier 在結束標籤中的換行。

原生 dialog 阻擋底層輸入，結束即釋放焦點／計時器／observer；不關閉背景頁面自己的 dialog。使用既有 `data-ui-dialog-frame` 契約避免共用框架插入標題／操作區，保持圖片置中。CSS 自行在 3 秒後隱藏，避免腳本未載入時一直遮住頁面；腳本晚到則扣除已播放時間。

成功驗證後、導航前，Vue 與 legacy 登入端只保存圖片座標／大小、圖片種類及時間到 sessionStorage。下一頁一次性取用並清除，超過 10 秒或資料不合法則使用標準動畫；沒有保存帳密、token 或目的網址。storage 被封鎖仍可登入及進頁。手機表單可能已捲離圖片，動畫依當時 viewport 座標從畫面外進入。
