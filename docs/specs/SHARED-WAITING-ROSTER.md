# 組隊房間共用人員名單

2026-10-12，候選1.28.5。使用者要求各遊戲統一採用固定大小的人員名單，並像雷霆之路加入角色。

## 實作契約

十款組隊房間共用 RoomWaiting 的 ui-room-roster，位置在介紹／操作區之下並跨同一版面全寬。卡片寬260px、高112px、角色槽64×80px、gap12px；欄寬不因一人／滿席改變，容器不足260px時縮窄。桌機名單槽112px、手機236px，人數增加在槽內捲動，面板及操作區不因多一列名單推移。人數欄預留固定寬度並提示捲動查看。

真人沿用伺服器提供的角色／目前表情，測試AI沒有指定圖片時使用內建小機器人。圖片失敗保留姓名字元fallback。自己、房主（snapshot有可辨識ID時）、測試AI與暫時離線／已入座保持可讀；不在等待畫面露出分數、骰子、車況、秘密角色或作畫資訊。姓名使用既有ui-player-name DOM與observer契約，不以長名字撐大卡片。

相同資料snapshot保留卡片節點，角色／姓名／連線狀態變更後維持捲動位置；已移除玩家排除。原生名單以data-waiting-native-roster只在等待時隱藏，開局恢復各遊戲資訊；雷霆教學不套用。沿用現有room-waiting.js/css，不改API、權限、資料庫或遊戲規則。

## 已驗證範圍

隔離伺服器與headless Chromium：十款1人→滿席，1440×900／390×900、亮暗共40個滿席布局；卡片尺寸、角色成功載入、scroll槽、無水平溢出／重複名單／遊玩資訊洩漏，以及十次start恢復原生名單通過。窄螢幕撲克容器小於260px，卡片會依容器縮窄，非固定260px造成overflow。

另驗重複snapshot的節點與捲動、長名字／離線變更的固定卡片，以及單元回歸對十個入口的身份、AI圖、kicked排除、文字安全、圖片失敗、waiting/playing往返和教學隔離。畫猜持筆15採樣、ACK、觀看者墨跡、倒數、揭曉與下一輪補驗通過。完整suite、雙平台CI、兩輪審查與公開站驗收以本批PR留言為準。

限制：viewport不代表真觸控設備；跨瀏覽器、200%字體、所有game phases、完整表情時間矩陣與讀屏沒有由本批證據涵蓋。
