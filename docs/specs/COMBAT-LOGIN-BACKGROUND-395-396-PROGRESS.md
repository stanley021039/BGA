# 背景、招式與登入抽卡券（#395／#396）

2026-11-11，候選 3.31.0；分支 codex/lobby-background-motion。實作與隔離試玩版已更新，本機驗證通過，可交付使用者試玩。尚未 PR、推送、啟動正式 CI 或部署。

本文件取代先前草稿的直接發獎及傷害數字顯示方案。使用者最後確認：登入只領券，之後到抽卡機手動使用；招式一覽不列傷害量與能量型額外數字，攻擊設定移除「立即套用」；所有遊戲回能與大廳一致。

## 最終行為

- 背景動態與背景顯示分開；關閉動態停止背景動畫排程，保留靜態美術、角色與招式。偏好在此瀏覽器保存並跨分頁同步，仍服從降低動態偏好。
- 普通招式單次施放依有效命中順序回能 12／6／6／0；能量型仍按實際規則計算 14／7／7／0，說明介面不另外列出。所有遊戲共用相同基準。受傷回能 5，移動每秒 2。
- 月輪返程半傷、不回能；兩款護盾完整階段首次擋傷額外回能 15；各招式的暴擊、回血、回能扣減、減速與麻痺規則依最後確認值接入伺服器判定。狀態列增加麻痺圖示。
- 減速各自計時，取最強效果；死亡／重生清除暫時狀態。一般麻痺禁止移動與瞬移，時間暫停另禁止攻擊。
- 招式效果一覽依共用目錄分組原版／異色，提供搜尋、Q／E 與大招切換、段數、回能及可展開規則；桌機兩欄、手機單欄。
- 首次累積三個台灣登入日，可在登入獎勵領取一次史詩十連抽券。領券只寫入一次性領取紀錄，不抽取、不增加收藏。
- 到抽卡機主動使用券後，沿用既有召喚演出、逐張翻牌與特效預覽。綜合卡池前九抽使用一般機率，第十抽固定史詩，不能由傳說取代。
- 抽卡券不扣聖潔石、不計入付費第 50 抽；翻牌提示位於卡片外。交易與冪等請求防止重試／重整重複用券，抽卡紀錄可讀取免費十連。
- 本機試玩使用獨立 work 資料庫與 isolated-playtest 標記；保留測試帳號與收藏，配置一位陪練機器人。不是正式資料或正式部署。
