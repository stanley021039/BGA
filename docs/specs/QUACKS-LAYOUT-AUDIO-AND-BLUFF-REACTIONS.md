# 郎中配置／預設音效與多人質疑提示

日期：2026-10-15；本機候選2.8.0，接續2.7.0。本批尚未發布PR或部署，保留既有試玩站與牌局。

## 已確認需求與實作

- 全站遊戲效果音預設開啟，背景音樂維持獨立。設定格式更新為version2；舊版自動保存的關閉設定一次遷移為開啟，音量保留，此後明確手動靜音會跨導覽保留。瀏覽器仍可能要求第一次手勢；不強迫重播已錯過事件。
- 大釜唯一可見名稱移到SVG左上，字體放大並限制長名寬度；底下重複名稱隱藏。查看玩家與命名／換色同列，設定鈕在玩家切換右側。永久水滴併入玩家資訊框，移除框外重複的老鼠起點資訊，原資源列的本輪鼠尾數與大釜起點標記仍保留。
- 占卜階段只在輪到本人時，牌背顯示持續發光、可讀名稱與鍵盤焦點；可直接點牌或Enter／Space抽取。其他玩家不發光；翻牌後立即撤掉，減少動態偏好保留靜態光框。
- 郎中結算聲只依結算子階段／回合完成／正常終局的切換觸發。同階段買藥、取消、紅寶石補瓶／水滴、女巫、效果選項、特效藥格位或個人確認不再因settlementEvents而發聲。抽藥、喝藥水、抽卡、骰子與爆炸各自既有音效不變。重整、隱藏、重連不補播。
- 瞎掰王最新指定取代2.7.0「好了啦」：按鈕為「哦是哦」，反應提示為「玩家名 質疑你」。多人反應分成獨立列，各自五秒後移除，輪次／離頁／背景清除全部；不再覆蓋前一人。保留五秒聲音冷卻，避免多人同按疊音。文字透過textContent插入，專注模式保留容器。沿用反應權限、個人冷卻與去重，不改公三小計分規則。

## 驗收與邊界

tools/qa/quacks-layout-audio.cjs 使用真Edge與隔離靜態HTTP／原生Audio；房間state／reconnect／action由測試攔截並呼叫真QuacksRoom引擎。三位玩家的1440／390px驗證釜名左上、工具同列、水滴在框內、沒有重複鼠起點、沒有橫向溢出；輪到本人牌背亮、同桌另一人不亮、鍵盤抽牌；買入／取消／補瓶沒有新增結算playing，進下一階段有新增。新版首次效果音開啟、舊版設定遷移、手動靜音跨reload保留，無頁面錯誤。390px同時套reduce motion。證據work/qa/quacks-layout-audio/evidence.json。

tools/qa/bluff-reaction-stack.cjs 使用真Edge及九位真引擎玩家的受控快照；桌機暗色、390px、專注模式均同時顯示九則不同玩家「質疑你」，沒有覆蓋或視窗溢出，一次原生聲音playing，reload不補播，沒有頁面錯誤。證據work/qa/bluff-reaction-stack/evidence.json。

這兩份fixture驗原生畫面與媒體，並非真人九人網路延遲或真觸控裝置驗收。喇叭主觀聽感仍由使用者試玩；不把靜音設定遷移當成瀏覽器允許無手勢自動播放的保證。

回歸測試涵蓋設定遷移／明確靜音、同階段靜音／跨階段去重、多列同時顯示／獨立期限／HTML字面文字／輪次清理。舊的控制器靜音fixture改為明確設定靜音，不依賴全站預設關閉。

本批獨立預覽資料從先前測試站作一致快照，禁止對原牌局重啟；最終房號與程序資料只存在ignored work/playtest，不放入公開文件。

## 最終結果

固定產品資產後完整 Windows Node 測試 **2232／2232** 通過，fail／cancel／skip／todo皆0，117864ms。紀錄work/playtest/layout-reactions-final-full-tests.log；新增與受影響反應／音效focused54／54，設定與倒數focused29／29。release minor base v2.7.0與diff check通過。

前兩次全套的失敗來自舊的控制器測試fixture隱含「全站預設靜音」。已將這些靜音場景改成明確設定靜音（或version2的手動選擇）；保留原有不補播、去重、背景及零音量斷言，沒有放寬正式程式的靜音判定。新測試另驗預設開啟及舊設定的一次遷移。

第一輪審閱核對兩次使用者要求：大釜標示、工具順序、水滴整合、本人占卜牌發光、結算只在階段切換、全站預設音效，以及「哦是哦」多人提示。第二輪審閱核對設定版本遷移與手動靜音、共用播放器門檻、九人文字安全與獨立期限、跨輪清理、角色秘密未擴大公開及手機布局；沒有未解重大問題。origin/main交付前仍931b602。原預覽站保留，新站以獨立資料快照啟動，不操作正式資料。
