# 特效與媒體效能契約

2026-10-23 使用者要求：新增進場、攻擊、背景、開場、音效及相同用途資源，必須完整接上既有壓縮、快取、預載與動態偏好；不能只因畫面可播放就交付。

## 素材與網路

- 內建短音效使用壓縮 MP3；原 WAV 僅保存來源及 PCM 回歸，舊網址由可信任 manifest 對應 MP3、正確 MIME 與內容 ETag。新增來源必須提供更小的壓縮副本、來源／輸出 SHA256 與容量，不用提高限制掩蓋問題。
- `compressed-manifest.json` 是來源對照，不是例外額度。每支交付音效最多 384 KiB，所有內建音效交付副本合計最多 2 MiB。不得引入未壓縮音效、遠端 CDN 或 base64 媒體繞過預算。必要提升須先取得使用者的具體授權並記錄原因。
- 自訂表情的原 WAV 及權限保留在資料庫；96 kbps mono MP3 以內容 hash 存在可重建私有 cache。正式環境必須通過 ffmpeg 執行與實際編碼檢查；不能將缺少編碼器時的相容 fallback 當作壓縮完成。
- 圖片使用現有 WebP／尺寸縮圖與 hash 去重。選單不拉原尺寸大圖；開場關閉、略過或選其他主題時，不預載用不到的預設圖。所有內建靜態圖片（含開場與 SVG）每張最多 256 KiB；原始來源區不作執行期交付。
- Vite 內容 hash 腳本／樣式，以及帶目前內容版本 `?v=` 的靜態圖片使用一年 immutable（圖片規則見 AGENTS.md「圖片交付」）；其他可重驗靜態檔及沒有或版本過期的圖片網址使用 `private, no-cache`＋ETag／304；HTML、API 與私有遊戲題庫音訊繼續 no-store。不能用時戳破壞穩定媒體網址，或將需驗權限的資源改為 public cache。
- 新的遊戲階段資源補到 `game-assets.ts`；預載透過既有 warm／idle／URL 去重，Save-Data／slow-2g／2g／3g 時跳過。不全站無條件載入遊戲素材。

## 動態與生命週期

- 程序特效共用 `motion-lifetime`：播放前檢查 MotionPolicy／系統減少動態／可見性；播放途中關閉動態、系統切換、切背景或 pagehide，立即取消。正常到期、重播及元件卸載也必須釋放 rAF、timer、DOM、listener 與 WebGL 資源。恢復時不補播過期事件。
- 進場最多同時 6 個；額外角色直接顯示，不隱藏或延後必要資訊。攻擊最多同時 3 個、4.2 秒，畫布上限 1280×900，保留既有 60 Hz 與每粒子池 220 筆上限。WebGL 採共用 context 預算；不可擅自提高 DPR、粒子或並行數。
- 連續裝飾背景在關閉動態／reduce／hidden 時暫停；恢復只恢復仍有效的背景，不能重播舊的一次性事件。聲音仍依獨立 AudioSettings；不能把關閉動態等同靜音。
- 不快取完整動畫逐幀畫面假裝省成本；必要的影像／解碼 cache 應以內容及尺寸為鍵且有容量／失效規則。

## 強制檢查與交付證據

`npm run perf:check` 檢查來源／壓縮副本、所有內建音效容量、開場圖片、特效內嵌媒體與匯入素材上限。`npm run perf:check -- --build` 另檢查正式編譯產物（單支 JS gzip ≤256 KiB、CSS gzip ≤128 KiB）；CI 必跑，不可只更新 manifest hash 或增加額度放行。`--runtime` 必須在正式候選主機檢查可執行 ffmpeg 與真實壓縮結果，失敗不得發布。

實際驗收桌機 1920×1080／手機、動態開啟／關閉／途中切換、系統 reduce、背景及離頁清理；記錄冷載／重載的實際傳輸、快取來源、304 與新版本失效。驗證靜音無多餘載入、音效能解碼與播放，沒有量測的實體 GPU FPS／喇叭聽感須另列限制。快取成功不等於繪圖效能通過，單元測試不能代替實際瀏覽器驗收。
