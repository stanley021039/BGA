## 行為

背景頁停止完整狀態輪詢與 SSE，改為每次完成後約 30 秒發送輕量 POST /api/room-presence。每次請求最多等待 10 秒；換房、離席、terminal、回前景與卸載時取消 timer／請求。手機系統凍結時不保證背景請求執行。

伺服器驗證登入、房間與未被移除的真人座位後只更新 lastSeen 並取消 emptyDeadline，回覆 alive，不產生完整快照、狀態廣播、成就操作或重連操作寬限。仍沿用既有共用 HTTP 驗證與限流。

真人 3 分鐘無訊號算斷線。全員斷線時，以最後真人訊號＋3分鐘作為起點；waiting／finished／showdown 保留30分鐘，其餘階段2小時。第一次檢查時鎖定 absolute emptyDeadline，後續階段變化不縮短、不延長。任何真人讀取／重連／保活取消期限；AI／kicked 不延長。沒有真人座位及最後真人明確離席沿用立即清理。

全員離線不執行測試 AI 主動步驟；既有到期階段仍可推進，不把斷線當成遊戲暫停。移除重複的24小時清理條件，統一由上述期限控制。既有 runtime 清理所有相關 registry／stream；既有 state stream 清理接線不變。

沿用全站100房上限，新增 MAX_ROOMS／config.maxRooms 正整數設定，不提高預設容量。滿額拒絕新增，不驅逐保留期內房間。既有保存會包含 emptyDeadline；重啟時已到期的離線房間不還原，未到期者不刷新 lastSeen，不延長牆鐘期限。尚未離線的房間沿用原有重啟重連緩衝政策。
