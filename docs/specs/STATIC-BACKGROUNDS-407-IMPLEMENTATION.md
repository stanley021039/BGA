## 範圍與來源

八款加入綜合卡池及「攻擊招式與大廳背景」卡池、碎片兌換、獎池預覽與大廳背景設定。既有房間背景機制保留靜態。新項目標記gachaOnly及gachaExclusive，排除免費背景、舊成就、舊作者全背景與舊新手禮包的自動授予；取得後才可更換大廳共用背景。

沿既有Stitch稿：七景R1、火星R2。原稿和來源畫布保留在[候選目錄](../design/candidates/407/README.md)，實裝用原生SVG在production子目錄，manifest記錄來源、稀有度、大小與SHA256。火星增加探測站、太陽能板、天線、履帶痕與前景岩層；戰場增加接地的廢墟、裝甲殘骸、鐵絲網、木板與彈殼。保留角色活動的中央空間，沒有新增人物、影片、外部圖片、腳本或動畫。

實裝SVG同步到lobby-background-live.json，沿共用LobbyBackgroundArt進行漸層ID隔離。全畫面、設定選擇與抽卡背景預覽使用同一原生向量美術；關閉動畫時也正常顯示靜態背景。設定選擇改用共用UiChoiceCard／UiButton，明示抽卡或碎片兌換解鎖，避免把新背景顯示為0次遊戲即可解鎖。移除選擇縮圖重複的CSS底圖下載。頁首依深色天空／明亮天空使用共用場景對比token。

本輪沒有新增點陣圖網址；SVG資料隨Vite內容hash模組交付，單張約4～14KiB，沿既有媒體預算，不提高容量。Figma沿本票先前使用者指示延後。
