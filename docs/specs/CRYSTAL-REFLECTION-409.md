# 晶能叱返：所有普通攻擊可反彈（#409）

2026-11-14，接續未發布的 3.33.0 候選；未 PR／CI／合併／部署。

## 本輪規則

晶體屏障維持0.8秒，期間命中的所有普通攻擊均可擋下，包含光線、近戰與範圍型普通招式。保留首位攻擊者鎖定，只將該玩家命中的各段慢速彈回；其他攻擊者的普通招式擋下但不彈回。大招、場地傷害與已反彈的攻擊不會反彈；非攻擊的護盾亦不列入。

反彈資格直接由 attack-effects 的普通攻擊分類與非零傷害判定，不再維護投射物名單，後續加入同分類的攻擊自動適用。原版與異色一致；判定以實際命中時刻為準，恰在800ms或之後的命中不在防護內。

保留1.5秒返程、32段事件上限、單次施放共用回能上限，以及原有的反彈傷害計算。已掛上的持續扣血不視為新施放的命中段。反彈不會再次進入攔截，避免無限互彈；攻擊者重生、離開或對局變動後，舊返程不能傷到新生命／新對局。

## 接線與美術

權威時間軸與前端契約均依分類判斷。修正返程來源缺少競技場 matchId／combatEpoch 的問題，並保留反彈者的位置與角色類型，讓競技場權限及牆壁判定沿用原機制。

原有投射物沿用其返程畫法；光線、光柱、黑洞、劍氣、雷電與龍捲新增對應形態的移動回擊印記，配色沿用命中招式與異色。全部在既有晶體特效的畫布與時鐘繪製，不新增 canvas、rAF、timer、網路素材或提高並行／粒子預算。設定與收藏簡述同步精簡。
