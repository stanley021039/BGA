# 場景戰績與中央面板穿越（#295）

2026-10-26 使用者指定：大廳顯示 KDA；遊戲進行中穿過中央遊戲主畫面時直接出現在對面。已確認後者指中央面板，原場景四邊穿越保留。

## 規則與責任

- K／D／A 為目前場景互動的擊倒／死亡／助攻，伺服器計算。最後一擊得 K、倒地下的角色得 D；倒地前 10 秒（含邊界）曾有效傷害的其他玩家各得一次 A。護盾不算傷害，倒地不能重計，攻擊重送沿用原去重。重生保留戰績並清除前一條生命的助攻紀錄。
- 此版統計隨既有場景 presence／房間位置存活，不寫入永久帳號紀錄。大廳離線超過 15 秒的角色會按既有規則清除，重新進場從零開始；與桌遊分數、勝負、排行榜無關。房間的戰績亦獨立於大廳。
- 大廳使用既有共用徽章顯示本人數字，桌機在左下輪播控制旁；窄版浮在左下並不攔截點擊。標籤提供中文可及名稱，斷線時顯示連線中，不偽造新數字。
- 進行中的共用房間由 RoomBackground 在每次移動命令讀取中央主面板的實際幾何，包含 display:contents 的作畫內容，並計入角色大小。等待／結束／專注模式不啟用中央穿越。
- 此幾何僅控制該角色移動，不允許客戶端指定戰鬥命中、傷害、KDA 或桌遊狀態。伺服器檢查矩形四個有限數值、順序及 0–100 範圍。
- 伺服器與角色呈現共用 scene-path 的線段／矩形算法。走到近邊後直接出現在遠邊；遮蔽路段不計行走時間，其餘路段維持既有速度。點擊面板內的目的地會延伸到同方向出口。斜向、沿邊行走、四向外框穿越也適用；幾何隨下一次操作重新量測。
- 不改 RoomSceneLayout 的布局、側欄及各遊戲規則，不覆蓋同工作目錄尚未提交的特效；本批沿用未發布的 2.45.0 minor 候選。尚未與最新 main 整合、未建立新 PR 或部署。
