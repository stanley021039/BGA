## 猜歌挑戰

1–8 人，三題不重複的六秒旋律開頭。初版題目為小星星、兩隻老虎、歡樂頌；以程式產生 16kHz／mono／16-bit PCM WAV，採簡化節奏的自製演奏，不使用商業錄音、歌詞、YouTube 或外部 API。可重聽、每人一次作答或略過，全員作答後房主揭曉，符合標準化中文／英文別名 +1，沒有速度加分。三題後列最高分與全場回顧。

未揭曉時，view 不含曲目索引、抽曲順序、他人答案；音訊 URL 只有房號與 round UUID。音訊 endpoint 驗登入、入座、房間類型、GET 與當前輪，回六秒 WAV，不以歌名當檔名。這是好友休閒猜曲，不能宣稱防止所有波形比對或知道三首題庫的玩家推測。原生播放器需手動播放；個人音量／靜音沿用 AudioSettings，換題／離頁／隱藏時暫停，不自動續播。

旋律來源查閱（2026-10-09）：[Musopen 公共領域樂譜集合](https://musopen.org/sheetmusic/)、[Mozart K.265 主題](https://musopen.org/music/composer/wolfgang-amadeus-mozart/form/theme-and-variations/)、[Beethoven 第九交響曲](https://musopen.org/music/2571-symphony-no-9-in-d-minor-op-125/)、[Frère Jacques 的歷史樂譜／Public Domain 標記](https://imslp.org/wiki/Fr%C3%A8re_Jacques_(Rameau,_Jean-Philippe))。只據既有旋律自製片段，不下載或沿用現代演奏錄音與排印版本。題庫音訊來源／自製編碼在 musicquiz-catalog.js；未知來源歌曲不會自動混入。

未做：現有上傳歌曲題源、流行歌原唱片段、曲目管理／投稿、曲長／題數設定、AI 辨識或成就。三首只是可試玩種子，真人聽感與難度仍待驗。

## 極簡畫家

3–6 人，四人以下各當兩次猜題者，五六人各一次。其他畫家看到同一秘密詞，猜題者看不到；詞使用本站原創的初始簡單題庫 40 詞，不複製商業題卡。

只畫直線與封閉圓，伺服器驗整數座標、完整圓在畫布內及非零線段；每個幾何圖形一筆，最多 40 個，固定黑色／筆寬，不接自由手繪、弧、橢圓或任意 SVG。草稿每次放開後同步；完稿送出不能改。只剩一位未完稿時啟動 server 10 秒倒數，到時採用已接受的草稿，未同步的活動圖形不計入。全部空白則中性揭曉，不產生猜圖或分數。

按筆畫少到多依序展示，每張猜一次；同數按猜題者之後的座位順序，隨猜題者輪替，避免固定第一席長期獲利。猜中畫家 +2、猜題者 +1，全部猜錯不加分。回合揭曉保留題目、各圖、筆畫數與猜詞；房主開始下一輪。完局最高分可並列。每人輪替，不設定額外 XP／日常任務／懲罰徽章。

規則參考使用者 issue 的 [龐奇 Pikto 介紹](https://punchboardgame.pixnet.net/blog/posts/9577658124)。同期查閱確認直線／圓、少筆畫優先、10 秒及輪替計分；本站的平手順序、40 圖形上限、同步截止策略是明示的數位實作選擇，不冒稱原版已規定。未做進階圖形卡、難度挑題、商業圖文或完整原版規則複製。

## 共用可靠性與玩家方法

PartyRoom 僅供兩個新遊戲共用入座／權限／事件／round UUID／requestId 指紋（128 收據上限）與完局，不重構既有遊戲。自查採 PLAYER／DESIGNER 的 P1–P8：參與、公開代價、角色資訊、輪替公平、完整回顧與取消／重試；同一實作者切換視角，沒有其他 agent 投票或真人評分。

離席中止整場，只有已完成的回合算分／回顧，不能把不完整回合當正常完局；可重連既有席位，途中不接受新玩家。草稿在同分頁 sessionStorage，無跨裝置草稿保證；伺服器重啟不續局。歷史禁公開進行中內容，保存 engine＋PartyRoom 與題源，schema 不改。腳本夥伴僅提供圖形／略過／錯猜測流程，不理解圖片或旋律。

開始、開發途中、測試前及推送／交付前持續 fetch origin/main 並比對；main 有更新時先讀差異、整合並驗受影響部分，不覆寫其他 worktree 或正式環境資料。
