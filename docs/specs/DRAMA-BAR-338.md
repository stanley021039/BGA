# 戲精酒吧｜線上玩法規格

對應 [Issue #338](https://github.com/stanley021039/BGA/issues/338)。3–8 人，從大廳「戲精酒吧」建立或加入獨立房間。採實體版的聲音表演玩法。

## 實體版玩法

1. **翻開題卡**。每句台詞有九個自編情境。開題時隨機抽六個，編為 1–6 號，全桌看到相同選項。回合中重連會保留原題卡。當回合的表演者私下抽出一張數字卡。
2. **用聲音演出**。表演者只說卡上的台詞，可重複或調整語氣、語速和停頓。猜的人只靠聲音判斷，不看臉或動作。
3. **同步揭曉**。每位猜題者選一個號碼，同時亮出各自的選擇，再由表演者揭曉正解。
4. **計算罰杯**。有人猜對時，每名猜錯的人各記一杯。全員猜錯時，改由表演者獨記一杯。全部猜對時無人記杯。下一位玩家接著表演。

參考 [山頂洞人實驗室商品說明（誠品）](https://www.eslite.com/product/10042227892682951181007) 與 [龐奇桌遊規則介紹](https://www.punchboardgame.com/blog/posts/%E6%88%B2%E7%B2%BE%E9%85%92%E5%90%A7-drama-bar-%E7%B9%81%E9%AB%94%E4%B8%AD%E6%96%87%E7%89%88-%E9%96%8B%E7%AE%B1%E5%8F%8A%E8%A6%8F%E5%89%87%E4%BB%8B%E7%B4%B9-%E9%AB%98%E9%9B%84%E9%BE%90%E5%A5%87%E6%A1%8C%E9%81%8A-%E6%88%B2%E7%B2%BE)。

## 線上版設計

- 首輪試玩採同桌語音或玩家自備的共同語音通話，遠端表演時關閉視訊。房內負責顯示題卡、管理回合與猜題結果。使用自編繁中台詞與情境。
- 伺服器只把抽出的情境號碼送給表演者。表演者按「演完了」開啟猜題，演出最多 45 秒，猜題預設 20 秒。每人送出後鎖定，其他玩家只看到提交進度。全員送出或時間到時，一起公開正解和各人的選擇。逾時未答顯示為未猜中。
- 罰杯用畫面上的虛擬杯數表示。開局前房主選擇每人演幾次，預設一圈。每個席位完成相同次數後顯示杯數，杯數最少者勝出，同杯數並列。
- 表演中斷時，房主可讓當前表演者用新題卡重來，舊題與選擇作廢。重新連線時恢復當前階段，仍依本人角色決定能看到的內容。

## 試玩驗收

- 從大廳建房與加入，以 3 人和 8 人核對開始門檻、席次輪替及末輪結果。
- 確認只有表演者收到正解，且不能提交猜測。分別驗證部分猜對、全員猜錯、全員猜對和有人逾時。
- 驗證全員提早交卷、逾時自動揭曉、提交重送和重連，都只結算一次。
- 桌機與手機同時遊玩，確認可從專注模式看到台詞、六個情境、已提交狀態與揭曉。
