# 共用組隊布局與聊天室

2026-10-12，1.29.0候選，基準main 1275e2d。替代原先各房間的等待布局；遊玩畫面仍採各遊戲布局。

## 共用契約

十款房間waiting同用ui-room-waiting-layout：桌機上列介紹／設定，下列人員／聊天室；340px右欄、16px gap、兩列各440px。1000px以下依介紹、設定、人員、聊天室順序換列；600px以下介紹依內容、人員面板360px，其餘440px。控制與人員在框內捲動；260×112人員卡及64×80形象保持。隊友TRPG公開角色名加入狀態，不公開秘密題目。

等待時聊天室直接展開、預設本桌；仍可切大廳，輸入label持續標示房號或所有登入玩家可見。50則記憶體保留、160字、速率／資格／XSS／重試契約沿用[聊天室規格](LOBBY-TABLE-CHAT.md)。電話、跑團、猜歌、極簡與瞎掰頁補載原有chat.js/css，沒有新API或schema。

同一個聊天室面板與client從等待格移至遊玩操作欄。mountIn僅移動DOM；不重建timer、清空草稿或訊息，重複snapshot不移動。回到遊玩時恢復進等待前的展開狀態。控制節點用comment保留原位置，開始時搬回；canvas／播放器／遊戲資料不搬入等待畫面。

## 特殊功能

所有等待房間共用外框；以下功能各自放在設定欄或開始後專用區。

| 遊戲 | 等待時特別設定 | 遊玩時專用布局 |
| --- | --- | --- |
| 雷霆之路 | 主遊戲／擴充玩法 | 賽道、車隊、骰子與同步演出 |
| 霧港跑團 | 每位玩家選角色 | 劇情、資源、行動與手記 |
| 瞎掰王 | 題目難度、看身分時間 | 私人身分、發言順序與質問倒數 |
| 傳情畫意 | 題目来源 | 私人本頁、畫布、傳遞簿揭曉 |
| 德州撲克 | 開桌與測試玩家 | 牌桌、私人手牌與下注 |
| 你畫我猜、極簡畫家 | 開桌／各自已有設定 | 畫布、作畫工具與猜題 |
| 猜歌挑戰 | 開桌與測試玩家 | 播放器、作答與歌曲揭曉 |
| 同頻俱樂部 | 題庫與自訂內容 | 挑題、答案與同義審核 |
| 送禮達人 | 題庫／成人選項 | 禮物卡、私人喜好與收禮揭曉 |
