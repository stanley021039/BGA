## 已實裝

- 主大廳及所有遊戲房間固定靜態背景，保留背景顯示、共用選圖與角色／攻擊特效，移除背景動畫排程與偏好開關。
- 特效訓練場：從攻擊／進場設定進入；私人配裝、補能、重置、進場重播及可設定的機器人，不覆寫正式配裝、不發正式成就。遊戲內AI玩家接上背景走動與互動。
- 三十位預設Q版角色、每位六表情；替換舊十位，舊角色ID與圖片網址相容轉接，不改寫正式資料。頭像在圓框置中。
- 十一款大型Boss，各兩個普通招式與一個蓄力大招，共33招；分層呼吸／移動／蓄力／出招／受擊與對應攻擊特效。大廳機器人、Boss各最多五隻，預告名額也計入；競技場最多一隻Boss，機器人固定主動攻擊，維持既有隊伍上限。大廳機器人只分純走動／主動攻擊；支援NPC互打，Boss優先攻擊玩家。
- 五秒WARNING預告後墜落，落地特效與接觸傷害；警告音使用使用者提供的Megaman X4錄音，交付版24kHz單聲道96kbps、68,877 bytes，跟隨音量／靜音，五秒到期或取消、隱藏、離場即停。
- 一條紅血條以兩道刻線分三段；同施放的所有段數最多打掉當前一段，前兩次換段鎖血2秒。二／最終階段傷害、移速、出招頻率分別相對首階段+15%／+30%；最終階段持續循環隨機免控4–5秒、爆衝／瞬移3–5秒、一般狂暴9–11秒。只在免控期間顯示「免控」，不顯示循環秒數。
- 玩家最後一擊彈幕及獵王祝福：立即回血10%，15秒傷害+10%、移速+8%、瞬移耗能減半，刷新不疊加，死亡清除；不計入PvP戰績／成就。
- 玩家招式對Boss適配扣蓄力、延後下次大招、短封印、方程易傷、斷肢轉破甲及分階段麻痺抗性；宅宅吞對Boss最多扣當前生命50%，仍受單段傷害上限。晶能叱返反彈所有普通攻擊，Boss普通攻擊回擊沿原招繪圖，大招不反彈。
- 彩虹獸五隻均可隨機飛出；每施放一次50%判定留下親吻3秒，每秒扣整數1–10能量；死亡／離場清場，Boss走扣蓄力適配。
- 全80版進場共用最多1.5秒，保留較短版本，整段分鏡及角色同步加速；不截斷動作、不留殘影。
- 純背景模式左上Esc、原位KDA／加成、右下可最小化夥伴管理，皆半透明。輪播移除箭頭／頁碼／提示列，保留鍵盤與拖曳並可透視角色；死亡名牌名稱後加「死了」。設定工具列與招式頁排版沿共用元件。
