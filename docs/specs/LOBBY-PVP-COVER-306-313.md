# 大廳分隊、限時對戰與掩體（#306／#313）

2026-10-28：使用者已確認「先做初版」。本批候選版本 3.13.0；功能與本輪本機驗證已完成，待使用者驗收；未 PR 或部署。

## 首版玩法提案

- 大廳增加可發現的「大廳對戰」入口，沿用共用 Stitch 元件。
- 提供紅／藍兩隊，自由加入或退出；每隊最多 8 人。一個大廳同時一場對戰。
- 個人 PK 為兩人對戰；團隊戰需兩隊各至少一人，最多 16 人。玩家先主動報名，建立者開始；旁觀者不自動參賽。
- 每局固定 60 秒，伺服器時間為準。每次施放對同一玩家造成實際傷害計 1 分；多段攻擊不重複加分，護盾完全吸收不加分，分身不計分。
- 個人按個人分數、團隊按隊伍總分決勝，同分並列。沿用既有血量與復活；不寫入正式積分、成就或排行榜。
- 參賽者只能攻擊本場對手；團隊無友傷，旁觀者與參賽者相互隔離。開始後鎖定名單與隊伍；退出算棄權，斷線保留本局名額、可在本局重連。
- 結束後停止本場傷害與計分，保留結果直到下一場；伺服器重啟不保留臨時對戰。

## 掩體提案

- 首版配置三個固定小型掩體，設於遊戲入口以外的下方地板區；確切座標須依桌機與手機場景核對後決定。
- 所有用戶端接收相同的伺服器場景配置。掩體阻擋普通單體投射攻擊及直線光束；範圍爆炸、地面／全屏與穿透類招式另明示不受遮蔽，實作前依現有招式 metadata 列白名單。
- 命中時以當時位置檢查來源到目標的線段是否穿越掩體，包含延遲與多段攻擊；不能只在施放時過濾目標。
- 掩體為可穿行的遮蔽物，首版不加入角色碰撞，以避免卡住、瞬移落點與入口阻塞。此取捨須在操作說明清楚標示。
- 不新增媒體或粒子系統；阻擋結果沿用既有攻擊事件呈現，提供可讀狀態。

## 實作與驗收邊界

- 接入既有 lobby／HTTP handler／SSE snapshot／前端契約，伺服器統一判定隊伍、名單、時間、傷害與分數。
