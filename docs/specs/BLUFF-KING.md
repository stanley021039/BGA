使用者 2026-10-09 選口說：網站管理角色、題目、計分；外部語音或面對面討論。3–9 人，起始 3 分，開局從有效席位隨機選第一位想想，之後依座位順序循環，每人一次；重新開局重新抽選。一位老實人、其餘瞎掰人。只有老實人在看身分階段收到正解；前端秘密卡預設收合。房主在開桌前選 10／30／60 秒（預設 30），房內待開局可再調整。每輪全員共用伺服器倒數；全員準備可提前開始，到時由排程自動進入口說。API 到期即不再給 myRole／secretAnswer／secretExplanation，前端用伺服器時間與單調時鐘倒數並收起卡片；大字秒數置於 game 頂部且 sticky，準備時倒數，口說時保留已結束 0 秒；已看到的資訊無法從玩家記憶清除。準備確認→口說與質問→想想選人→揭曉。1 級一類別、2 級三類別、3 級無提示。

想想选中老實人，雙方各 +難度；選中瞎掰人，只有被選者 +難度。每輪兩張公三小、不可重複：質疑瞎掰人對方 -1 想想 +1，質疑老實人想想 -3。分數可負、並列最高分。網站版先採每人當一次想想、不重複抽題；這是初版改編輪數，非已核對實體輪數表。目前 148 題；原有 60 題每級 20，追加題依實際難度分級。所選題數不足三選一時拒開局。

## 2026-10-12 玩法追加

每輪新增 selecting 階段：想想私下三選一題名／難度，選定後才開始角色倒數。揭曉後該輪真人玩家可投票禁題，固定選民過半數即全站持久禁用；AI 不投票。口說時所有真人（包含想想）可按「哦是哦真的假的555555」，文字反應與本機 MP3 音效沿用共用開關／音量，5 秒冷卻及去重。詳 [整合證據與限制](../BLUFF-ROUND-FOCUS-PROGRESS.md)。
