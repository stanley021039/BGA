# #227 2026-10-25 試玩介面回饋

依使用者本輪九張截圖與逐項要求，沿用原票、原分支及 3.3.0 尚未發行批次。下列決策取代先前顯示文字玩家名、UUID 前綴、獨立 Twist 面板與能力清單在賽道下方的介面。Figma 仍依使用者先前指示暫緩；此為實作／人工驗收候選。

- 等待室牌庫順序為初代、Second Wind、混合，不改伺服器預設牌庫。
- 積分與擲骰採共用玩家頭像，hover／鍵盤聚焦顯示玩家名稱與席位 ID。積分內每位玩家頭像、分數、剩餘跑者群組綁定；跑者每列兩位、圖片下無名稱，能力與所屬玩家仍可 hover 查看。移除積分前的席位編號。
- 名次分改為標題旁問號的四列表格；最高不重複點數規則也移至先手標題問號。擲骰玩家由左至右、必要時換列，各自上下排列頭像／骰點／按鈕，只有自己有擲骰按鈕，既有權限與已擲防重維持。
- 選秀標題使用伺服器 draftOrder 的不重複順序與 ↔；競速標題使用以先手起始的玩家順序與 →。單行省略，當前操作者用適應深淺色的 link token 與粗體標示；能力決策時標出決策玩家。秘密選角維持同時鎖定，不以虛構輪流順序改動規則。移除原右上敘述。
- 賽道標題只顯示中文，左側規則問號合併規則文字及其下方「本場 Twist」說明／卡圖；移除獨立 Twist 面板、冗餘 hover 教學及輪到誰行動文字。本場角色能力移至積分下方，可收合、預設收合，房間切換後重設。
- 賽況只顯示事件本身，不再前綴重複的玩家名稱與 UUID。事件資料仍保留伺服器身份欄位，沒有修改玩法或資料追蹤。
- 積分面板改用與其他面板相同的 regular 內距；沒有逐頁位移補丁。UiPanel 新增 title-before／title-after slot，UiHoverInfo 新增 helpOnly 佔位問號來源，鍵盤與手機可點擊查看／關閉，兩個預設行為均維持相容；共用契約已更新。
