# Boss 擊殺後不自動重生（#439）

2026-11-27使用者要求Boss擊殺後先不重生；與#438合併為3.37.1候選。發布／CI狀態以關聯PR的固定head紀錄為準，本輪未部署。

## 行為

- Boss死亡不設定respawnAt；推進生命週期時也會清除舊的Boss重生排程，不能由舊倒數自動復活。
- 大廳、訓練場及競技場共用此規則；競技場切換對局僅重置仍活著的Boss，已擊殺者保留死亡狀態。普通玩家與普通機器人仍按原3秒規則重生。
- Boss持續顯示墓碑及名稱後的「死了」，副標改為「不會自動重生」，不建立重生倒數timer。保留管理清單及原有Boss數量限制。
- 擊殺公告、獵王祝福、補血與權限不變。擁有者可手動重置Boss，或移除後重新加入；訓練場明確的重置操作也可重設整場。不是自動清除Boss，不新增召喚獎勵。
