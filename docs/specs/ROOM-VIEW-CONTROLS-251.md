## 實作邊界

`RoomFullscreenToggle` 共用進出控制及退出入口；一般房間與 DrawPage 都接入原 `useGameFocus`，移除 DrawPage 重複的原生全螢幕生命週期。退出等 Vue 完成頁首 teleport 再恢復焦點，閒置卸載不改捲動。全螢幕入口將焦點交給可見退出控制。

`room-fullscreen.scss` 將原 grid 放到 viewport，保留既有遊戲宿主；中央內容及作畫、猜題欄不卸載。遊戲必要 dialog 仍保留 top layer。此輪沒有修改畫布 renderer、輸入座標、筆跡協定、音效、背景動畫或伺服器。

`room-space.scss` 只調整上方控制與標題的布局，按鈕仍由 UiButton 管理，保持 44px 命中範圍；不再使用原本 0.5 縮放。沒有調高 UI 或效能 baseline。
