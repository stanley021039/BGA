## 行為與範圍

- 大於1180px的桌機視窗，進入房間時玩家列表與聊天室預設展開。
- 1180px以下沿用手機抽屜：初入房間兩側收合，開啟時一次一側，Esc／背景關閉與焦點返回沿用。
- 左右仍可各自手動收合／展開；同房間一般狀態更新不覆寫手動選擇。重新載入或切換房間時套用各尺寸預設。
- 修改共用GameRoomPage與RoomSceneLayout的預設值。外層可選Boolean prop原本會把false傳入內層，因此兩層須同時修正；只改內層無法涵蓋一般遊戲。畫猜直接使用內層，休憩區既有明確展開設定保留。
- 不更動面板幾何、媒體同意、聊天室內容、遊戲規則或正式資料；股市沒有這組左右房間側欄，不新增無關布局。
