# 郎中八人加大桌、抽藥節奏與占卜卡正面

2026-10-15，本機候選 2.12.0。整合 main 2d53f00（#128 動態彈幕框），保留前批 Stitch 版面及使用者媒體。未推送、發 PR 或部署。

## 行為

- 基本版、女巫、煉金術士及合併模式都支援 2–8 人。八種釜色保持唯一，重新入座若原色被占用會分配空色；第九人拒絕。等待室、人數列、測試 AI 及大廳列表統一使用容量 8，版面沿用原樣。
- 親友加大桌沿用同步抽／停屏障，所有必要席位選完才抽；效果選擇完成才進下一抽。鄰座仍只計左右各一人；病患可重複、數位藥材不限、獎勵骰按未爆炸最遠與並列判定。九輪及隨機先手不變。
- 要拚原檔不修改，前 180ms 保留速度，後段以 atempo 0.62 保持音高地延長；輸出由 480ms 到 640ms。原不要錄音不改，來源及輸出 hash 見 quacks-action-user-manifest.json。
- 私有抽藥事件、公共爆炸及結算共用一個序列：抽藥播放清理後等 25ms，爆炸再等 180ms；爆炸聲與橫幅、震動／煙霧同時觸發，後續結算排在後面。640ms 音檔另留 160ms 解碼保護餘量，由 ended 正常結束；拒播或靜音仍顯示公共爆炸資訊。
- 進新輪、斷線、hidden、離頁取消待播演出；首載與重連不補播。減少動態保留靜態爆炸文字，不震動／煙霧。遊戲結果立即由伺服器決定，音效／動畫不推進規則。
- 占卜卡正面採金邊雙框、原創幾何印記、深翡翠／紫色底，分層顯示牌名、立即／本回合時機、完整效果與抽牌者；牌背、本人點擊和全桌 3600ms 翻牌保留。無新增外部圖像依賴。

## 驗證

- 新增六／八人四種模式完整九輪、同步第八席、重試不多抽、秘密資訊、容量／大廳列表、重入釜色，以及八人環狀鄰座規則測試。
- tools/qa/quacks-pacing-large-table.cjs：Edge 真 HTTP 八個登入席位，1280px 暗色與390px亮色兩個原生頁面；都看到新牌面，完整效果、17px文字、卡面 scrollHeight 與 clientHeight 相等。實際六次抽藥後八人爆鍋；native Audio 播放位置 0.639958 秒才清理，爆炸 playing 相隔約 253–254ms，橫幅約 212–214ms。每端爆炸一次，重載不補播、無頁面錯誤與水平溢出。
- 瀏覽器中首次重現舊 640ms 保護計時會在約0.572秒截音，已加解碼餘量並重驗完整尾音。初版 QA 在等待室等待隱藏人數列、未等待換輪基準就揭牌，已修正測試等待；不記為產品通過。
- 首輪全套 2268／2272；三項仍期待5人容量、另一項假定排隊題作者必為首位出題者。依八人與既有隨機先手契約修正斷言後，受影響50項通過；最終全套結果下方補記。
- 自動化的 native playing／時間與版面證據不等於真人喇叭聽感、真手機觸控、弱網／多人實體聚會驗收。
