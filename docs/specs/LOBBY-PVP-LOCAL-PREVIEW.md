# #306 / #313 多人整合版本機試玩交接

使用者於 2026-11-04 指定在本機「優化專用」開啟本次多人整合版。

候選分支：`feat/lobby-pvp-cover-306-313`。完整規則與驗證見
[本批規格](LOBBY-PVP-COVER-306-313.md)的「2026-10-30 正式版接合候選」。
這是正式 Vue 介面與 Node / SQLite 多人伺服器，並非 Sites 單人版。

在本機 BGA 儲存庫 fetch 此分支，建立獨立 worktree 後依序執行：

```text
npm ci
npm --prefix frontend ci
npm run frontend:build
node tools/playtest-lobby-arena.cjs
```

使用相容專案的 Node 22 或 24。啟動後開啟 `http://localhost:51334/`。
不要重新使用 `51331` 舊服務，也不要停掉其他工作中的伺服器。
若 51334 已被占用，先識別程序，不任意終止。

啟動程式會建立新的 `work/multiplayer-preview-*` 隔離資料夾，
兩個測試帳號 `arenaadmin` / `arenaguest` 共用本次隨機產生、僅印在終端的密碼。
以兩個獨立瀏覽器環境登入；大廳對戰入口選紅／藍隊與類型後開始 PK。
測試帳號開放成就獎勵，但不預填達成紀錄；正式資料與原本本機試玩資料不變。
不要分享終端輸出的密碼、cookie 或測試資料庫。

本機啟動後確認 HTTP 回應、登入、兩帳號報名與開始對戰，再在「優化專用」開啟瀏覽器分頁。
此交接不代表已在使用者電腦啟動，也不代表已同步本機其他未合併招式候選。
不要覆寫現有分支或未提交工作，不建立 PR、不合併、不操作正式站。
