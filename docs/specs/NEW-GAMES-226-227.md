## CEO 核心接線契約

入口是 `src/games/ceo.js` 的 `CeoGame`。由可信任伺服器提供 `playerIds`、`catalog` 及可選 `rng(maxExclusive)`，constructor 洗牌並隨機決定起始玩家；沒有任何預設正式牌庫。`view(playerId)` 回傳獨立副本，拒絕非在席玩家。

`act(playerId, action, expectedRevision)` 的 action 為 `{type:'acquire', companyId}`、`{type:'buyStock', issuerId}` 或 `{type:'dividend'}`。卡片用 ID 避免市場換位買錯；買股用原發行集團 ID，不接受賣家指定第三人。成功遞增 revision，回傳行動者專用 view。`CeoRoom` 沿用 PartyRoom 的 roundId／requestId receipt，成功重送回同一狀態，衝突拒絕。HTTP 身份由 session／席位取得，不信任 body 的 playerId。

`createApp({ceoEnabled:true})` 僅供目前隔離開發與測試接線；正式 settings 不啟用這個選項。預設 `POST /api/create {type:'ceo'}` 回 `GAME_NOT_ENABLED`，直到設計核對與新頁完成後再開放。房間 view 的 `game` 為各席位專用投影；新加入等待下局的席位不讀上一局私人狀態。離席中止不虛算勝利。測試 AI 只讀自己的 view，選可支付公司或發股利。

歷史開始保存三份引擎來源與暫用牌庫 provenance；對局中不公開完整歷史。`historyState()` 不序列化未抽牌序與私人變動牌，正常結局保存揭示結果，中止另外標記；不保證重啟續局。

公開 view 提供現金、持股、公開公司／資產／收入、下一股票售價、市場附加費／棄牌標記、剩餘公司張數、倒數及最近 60 筆事件。增減牌僅本人可讀，終局全部揭示；牌堆順序、未抽增減牌與內部狀態不輸出。結果含六集團資產／股票排名、各玩家股票／逐公司／現金計分及所有並列勝者。核心目前只保存在記憶體，未聲稱支援重啟續局或離席後繼續。
