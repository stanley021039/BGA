## 座標契約

公開頁首、聊天室、玩家區及玩家卡使用白名單語意 ID 加區塊內比例。畫猜使用畫布比例與場景代號；賽跑使用公開賽道格座標與格內比例。其餘位置（包括私人區域）只傳視窗比例，不傳私人文字、DOM 或選擇器。郎中大釜目前屬視窗比例後備定位，尚無釜格適配。

接收端依自己的布局重新計算；看不到或場景已更新時顯示文字提示；目標在捲動區外時顯示邊緣方向，不自動捲動。視窗比例只代表同一相對畫面位置，不能保證不同布局指向同一物件。

可關閉接收及本頁提示音，音效遵守既有全站音量與靜音。減少動態偏好保留靜態提示。
