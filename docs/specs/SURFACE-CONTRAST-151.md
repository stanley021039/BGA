## 問題與修正

原生瀏覽器重現極簡畫家：淺黃 hero `#fff2c4` 上的標題被共用規則改成夜間近白色，對比約 1.00:1；說明文字誤用頁面夜間 muted，約 1.74:1。角色頁已選卡片的次要文字也有同樣問題。

共用 `h1/h2/h3`、`label/legend` 改為繼承所在表面的前景色。新增 selected surface mixin，供極簡 hero 與角色已選卡片使用：背景 `#fff2c4`、正文 `#20211e`、次要文字 `#5a5b52`、連結／焦點 `#0051d5`；對比分別約 14.45、6.14、5.98:1。此表面在深淺色保持同組配對，不重綁全域 ink，避免影響巢狀控制項。

## 後續配色策略

- 普通面板採主題 surface／ink／muted；固定紙色與已選卡片同時指定前景及次要文字。
- 主按鈕、錯誤／成功狀態維持成對 tokens，不能只換背景。子標題與表單名稱繼承容器，不強制套全頁字色。
- 特殊表面集中擴充 mixin／tokens；不能逐頁以任意黑／白覆蓋。連結、焦點與 disabled 分開驗證。
- 依實際計算的文字／背景顏色量測；圖像、漸層、半透明特效等不確定項目留人工，不算通過。

## 實際取樣與畫布

27 個 Vue 頁面加音檔管理、音效素材庫共 29 個入口，涵蓋大廳、帳號、內容／管理工具及 11 款遊戲。每頁取樣桌機 1920×1080、手機 390×844 的深／淺色與跟隨系統，共 174 組；系統當時為深色。音效素材庫為獨立固定深色配色，不宣稱支援主題切換。

逐頁摘要：[contrast-matrix.json](../evidence/issue151/contrast-matrix.json)。各組可可靠量測的文字沒有低於 4.5:1 的項目；圖像／特效等仍另列人工，這不是所有狀態的 WCAG 認證。

畫布含 116 張入口四組合截圖，另加註冊、登入錯誤、個人設定、11 款遊戲開始後、送禮／同頻／極簡／電話畫猜結果、跑團場景紀錄與郎中藥材書，共 147 張原生完整頁面圖。長圖標真實尺寸，不標成 1080 高。結果只代表到達的取樣狀態，不代替完整對局驗收。


開啟 `http://127.0.0.1:15004`：29 頁平鋪於同一畫布，可切深淺色／桌機手機、搜尋、調整縮圖、選遊戲階段。點圖顯示完整長頁，可切原始大小與捲動。「已檢查」是使用者本機勾選，不是自動驗收。上述操作均已原生瀏覽器驗證。

## 回歸與限制

郎中沒有改來源；實際打開桌機深色、手機淺色烏鴉頭骨藥材書，圖像／數字及右頁完整規則保留，手機捲動、鍵盤焦點可見。病患、所有特效藥／獎勵格及效果選項本輪未逐一新增人工驗收。畫猜 renderer／同步未改，也未宣稱重新完成持筆、換輪與逐點時序測試。

未涵蓋所有隨機題目、全套對局分支、每個彈窗、正式資料量、真實觸控及 Safari。媒體／歷史等空資料入口不代替豐富內容狀態。等待使用者畫布最後檢查，#151 保持開啟。

唯讀 DOM 稽核工具含直接文字、透明背景合成與隱藏／disabled 分類的回歸測試；圖像／漸層／陰影等不確定項目留人工。不讀應用私有狀態、不修改頁面。測試含原錯誤配對的失敗反例及修正配對。

共用 CSS 納入固定 Prettier 3.9.10 格式，移除兩筆 legacy baseline。同版本格式化基準後比較 1,439 筆有序 CSS 宣告，只有兩條 color 語義改動；測試兼容等價引號，仍核對實際按鈕配色。
