# Stitch 匯出稿實作驗收

## 2026-10-14／2.5.1：深色文字對比

最後預覽發現舊樣式把倒數字色套為亮色按鈕前景、把畫者狀態套為黃底前景；新稿的背景已是深色 inset，造成對比不足。此版將一般倒數對應 st-ink、緊迫倒數對應 st-error，深色畫者狀態對應 st-primary。

隔離 Chrome 1412×1053 實際作畫階段：倒數 rgb(245,240,228)、畫者狀態 rgb(228,199,110)，並保存完整畫面。布局、原計分、平滑倒數及 15 秒音效不變；下方 2.5.0 功能與既有驗收仍適用。


## 2026-10-14／2.5.0：Stitch 完整操作與實際玩法

本節以 3e8ab01 的 2.4.1 為基線，取代下方舊稿對工具配置與選題動畫的描述。設計來源仍為 UX02–UX17 與修正版 UX14；新增 Plus Jakarta Sans 本機字型及三張匯出插畫，來源記於 public/assets/stitch/sources.json、字型授權隨檔保存。玩家與 AI 使用原有角色，沒有採用示意人物代替真人角色。

### 功能與資料

大廳建房可以選遊戲、預設 60／90／120 秒及 1–64 題；六格代碼由同一個原生 input 持有，保留貼上、鍵盤及輸入驗證。訪客等待室顯示精簡設定、就緒按鈕與聊天室，設定明細另開視窗。就緒為房間狀態，不新增開始遊戲門檻。房主可移交房主、解散房間；畫者／房主可跳過當前回合，需相符的 round／canvasEpoch。

原計分不變：猜中得分仍為 30 + floor(70 × 剩餘時間／總作畫時間)，每位猜中者讓畫者加 15 分。匯出示意的 50% 額外加分與固定第二名獎分沒有加入。MVP 畫作僅標示本局最多人猜中的畫作，不增加分數；最快猜中、成功率、保留筆畫與完整同分排名來自實際對局。統計以小型、非 enumerable 的 matchSummary 持有，不保留整局所有畫布；公開回看仍限最近八幅。

最近畫作提供全部／我作畫／已收藏篩選，空篩選清除舊預覽；明確點選精彩畫作會打開指定公開結果。PNG 及 ZIP 以獨立 renderer 重建不可變 snapshot，UTF-8 檔名與 CRC32 寫入 ZIP。取消收藏只處理目前帳號的私人收藏，需確認，公開原圖及分數保留。三個表情分頁使用真實社交傳送；保留原 24 表情，另支援匯出稿的新表情與快速吐槽。帳號選單可以儲存暱稱、切換原有角色。

### 組件與版面

共用階層為 tokens → 安全文字／圖示／角色／按鈕物件 → panel、dialogPanel、disclosure、podium 組合 → grid、完整宿主 portal、畫布量測 patterns → 頁面 adapter。新增能力由原 RoomApi／draw controller 持有；Stitch adapter 消費每次已接受的狀態，派送原控制器事件。不能把 ui-room-settings-slot 移出 RoomControls；等待室搬移整個 ui-room-waiting-controls 宿主。

桌機各遊戲階段共用 3:7:4 欄寬與高度預算，倒數固定 148×64；較矮桌機十工具使用 44px 横列，色盤另留 72px。捲動區預留捲軸寬度。小螢幕的非作畫場景使用正常文件流，頒獎、排名與操作不能依賴桌機 absolute overlay；作畫色盤／畫布／工具／提示分別占獨立列。專注模式保留題目、倒數、角色、作畫及猜題，使用兩欄並提供退出。

### 平滑倒數與 15 秒提醒

數字每秒更新，視覺倒數條以伺服器 deadline 線性縮短；一般瀏覽器沿用 compositor，缺少 Element.animate 時有 requestAnimationFrame fallback。恢復已停止的 animation 會重新對準剩餘時間；hidden／離頁清理及減少動態偏好保留。

作畫同一 canvasEpoch 由大於 15 秒跨到 15 秒時，經 GameSounds 播放一次 countdown-warning，重用現有 320ms 輪次雙音。全部依 AudioSettings.effects 開關、音量及原有播放上限；首次載入已不足 15 秒、背景或斷線不補播，重繪／校時不重播。音效不影響計分、畫作或換輪。

隔離 Chrome 實際觀察：同一 00:59 內 24 個樣本，scaleX 由 0.9795 連續降至 0.974596；完整 59→14 秒的音源回應一次 200。剩 13 秒重新載入後零音源回應；靜音整輪零音源回應。另有原生持筆與 stroke 200 確認，畫作保留。這些是畫面與 HTTP 證據，未觀察 native playing 事件或喇叭／耳機聽感；非 WAAPI fallback 與實機瀏覽器尚未實測。

## 實作

- 大廳：上方角色交誼區，下方扇形遊戲牌與入房／房間列表；選定遊戲的原說明移到共同操作框。12 款原遊戲、拖曳、旋轉、箭頭與鍵盤切換保留。
- 等待室：角色名單、中央插畫與右側完整設定；房間閒聊從圖示開啟。十類題庫、60／90／120 秒、1–64 題／分數模式、AI、管理、邀請與離房沿用原功能。
- 選題：中央三張實際題卡；只有畫者取得與顯示候選詞。其他玩家看到保密背面。
- 作畫：上方色票与尺寸、側邊十工具、原 512×256 畫布、下方猜題、右側社交聊天。較矮桌機改成橫向工具列；工具與畫布按固定 grid 槽量測。
- 揭曉／結算：公開作品、禁題、收藏、角色頒獎与重開操作。下一局設定放進共同對話框，必要操作留在中央底部。專注模式保留中央控制及設定出口。
- 共用層級：tokens → 安全文字／圖示／角色物件 → 面板／disclosure／dialogPanel → 名單／舞台／聊天／畫布量測 patterns → 大廳與畫猜頁面 adapter。
