## 共用結構與行為

- L02 改為右側固定寬度設定視窗，設定內容內捲動、版本與關閉操作保留位置。亮暗模式、音量、動畫、彈幕與音效試聽仍使用既有偏好 owner。
- L03／L04 共用標頭、說明、可捲動四欄縮圖、當前選擇與關閉列；手機改兩欄。使用真實 24 款目錄及原有框飾渲染器，點選後立即儲存個人偏好。播放器縮圖只展示外觀，不載入或播放媒體。
- FramePreview 自帶可量測 viewport 與獨立縮放 stage，同時適用設定、選擇器與收藏庫。以 ResizeObserver 完整等比置中，避免原渲染器的 transform 規則使外框裁切；卸載時清理 observer／resize handler。
- L05 桌機以暱稱／外觀和頭像／角色兩欄呈現，共用穩定預覽槽、角色清單內部捲動、底部儲存列。保留暱稱獨立儲存與形象表單的原 API、pending 防重複及實際上傳限制。
- L06 使用真實角色表情圖與名稱，保留 pending、離線與原送出流程；L07 使用真實邀請、接受／婉拒及座位導向，保留回應中的互斥與關閉防護。空邀請以共用信封圖示呈現。
- A10–A12 保留原畫布、歷史、照片圖層、尺寸與上傳 owner。工具改為頂部顏色／筆粗／透明度／縮放與左側圖示列，透明棋盤格畫布置於深綠工作區；窄螢幕工具橫向捲動。調色盤以 native popover 顯示，矩形色相／飽和度選色仍支援鍵盤，亮度及 HEX 延用既有色彩流程。
- 上傳區與作品區獨立對齊。沒有新增假資料、平滑度參數或超出後端支援的檔案大小；圖庫單張 1 MB、來源照片單張 12 MB 的限制保留。

## 介面驗收

在測試站進行實際操作，未執行自動測試套件：

- 設定視窗的音量、明暗模式、巢狀外觀選擇器及關閉焦點；切換彈幕／媒體框後確認立即更新，再還原原偏好。
- 暱稱儲存、遊戲角色表情切換與儲存；還原驗收前角色表情與頭像。
- 大廳送出真實表情、邀請空狀態、受控測試帳號邀請及接受後入座，完成後離開驗收房間。
- 畫布實際繪製、HEX 調色、復原／重做、640×480 尺寸套用及復原尺寸、加入照片圖層、儲存畫布、直接上傳圖庫與 PNG 下載。下載檔案核對為 640×480；本輪產生的兩件圖庫作品已清理，原作品保留。
- 以 CSS 視窗 1920×1080、1280×720、390×844、320×720 檢查相關面板對齊、預覽完整顯示、操作列、內部捲動和水平溢出；亦確認收藏庫切至彈幕框頁籤後，原本隱藏的共用預覽會重新量測。手機使用視窗模擬，並非實體裝置測試。
- 建置包含 vue-tsc，另執行 Node 語法、版本一致性及辨識既有 CRLF 的 diff 空白檢查；editor.js 保留原檔 CRLF，避免無關的整檔換行差異。

驗收連線、帳密、房間代碼、測試檔和截圖留在私有工作區，不加入來源檔或發布包。
