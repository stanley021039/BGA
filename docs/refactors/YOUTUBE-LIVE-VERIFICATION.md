# YouTube 實播與全桌同步驗收

2026-10-20，在 Vue 多頁測試站以兩個不同帳號、Chrome 與獨立 in-app browser 實際操作共用 RoomMedia。兩端皆使用真正 YouTube iframe，讀取其 HTML video 的 currentTime、readyState、paused 與 duration，並確認影片畫面；沒有替換播放器或模擬 YouTube callback。

## 修正

- 已載入的影片收到全桌暫停時，改為暫停、定位、再暫停，保留影片畫面；不再 cueVideoById 將影片重設為封面。
- 首次加入已暫停影片時，先靜音載入共享位置，在該 instance 第一個有效 PLAYING 回呼暫停並恢復個人音量。初始化意圖綁定 epoch、item、共享播放 signature 與 player；換片、退出、新指令及明確本機播放會取消或取代舊意圖。沒有週期強制覆蓋個人原生操作。
- 換片沿用已接受影片的觀看意圖，不再在 update 已建立新 iframe 後又 joinVideo 重建一次。
- YouTube API script 與 iframe ready 各有有界等待；iframe 20 秒未就緒時顯示人工重新載入／原生播放器入口。ready、error、退出、換片及銷毀會清理 ready timer；不自動重試或傳送共享控制。

行為依據：[YouTube IFrame API](https://developers.google.com/youtube/iframe_api_reference) 的 cue、load、seek、播放狀態及事件定義。原生影片播放器維持本機控制；全桌控制仍依既有 REST／SSE、權限、revision 及房間 instance。

## 實際結果

使用 Google for Developers 示範影片 `M7lc1UVf-VE` 與 Blender 官方短片 `aqz-KE-bpKQ`。下表為近乎同時讀取的實際媒體位置（秒），並非只讀共享進度文字。

| 情境 | 房主 | 一般房員 | 結果 |
| --- | ---: | ---: | --- |
| 初次實播 | 3.668 | 4.049 | readyState 4、兩端播放中 |
| 全桌暫停 | 10.441 | 10.441 | 兩端保留實際畫面並停住 |
| 暫停中重新加入 | 10.441 | 10.458 | 兩端 readyState 4、paused；再次取樣位置不變 |
| 暫停中回到開頭 | 0 | 0 | 仍維持 paused |
| 全桌恢復播放 | 8.255 | 8.264 | 兩端持續前進 |
| 播放中回到開頭 | 2.925 | 3.039 | 定位後維持 playing |
| A 切換 B | 6.833 | 6.820 | 正確影片、兩端 playing；只有一次 embed Document 請求 |
| 播放中關閉再加入 | 19.594 | 20.488 | 房主播放不中斷，新加入端追上共享位置 |
| B 切回 A、單端重試後 | 41.301 | 41.793 | 兩端正確影片並繼續播放 |

另於前一輪同功能修正版觀察一般房員以原生控制暫停自己的影片，房主繼續播放；按返回全桌進度後重新播放並對齊（33.182／33.522 秒）。原始版本換片有兩次相同 embed Document 請求，修正後 A→B 與 B→A 都只有一次。

Chrome 在切回 A 時兩次遇到外部文件未完成載入，開發工具亦回報 Browser Use 正在處理 paused document response。另一端仍實播。20 秒後出現重試入口，手動重試可恢復並跟上全桌；不能據此宣稱已排除所有 YouTube 網路、嵌入限制或瀏覽器情境。初版測試另一部影片遇不可播放提示，未將第三方內容限制誤判為同步成功。

390×844 手機視窗模擬的播放器為 374×720，位於 (8,116)，沒有外框溢出，影片實播且操作內容內捲動；驗證後已還原視窗。這不是實體手機或不同實體裝置驗證，也未驗證喇叭聽感。同步採共享錨點，沒有零毫秒同步保證；本輪取樣差小於 1 秒。

建置含 vue-tsc，Node 語法、release 版本與 diff 檢查通過；未執行自動測試套件。臨時房間、帳號憑證、截圖與原始量測留在私有工作區，不加入來源或發布包。

最後唯讀複查補齊「首次 paused 載入直接收到 ENDED」的初始化靜音清理，避免片尾未經 PLAYING 時保留旗標；這個精確片尾事件未獨立重現。重新建置後，再實際確認兩端播放、全桌暫停、暫停中重新加入（6.401／6.423 秒，readyState 4 且 paused）、恢復播放（9.141／9.154 秒）及切至 B（6.658／6.942 秒）。房主明確發布本機進度亦收到成功回覆，兩端取樣 99.473／99.635 秒。
