## 修正

- 媒體視窗保留同一個音訊／影片宿主與原 Pinia／REST／SSE owner。標頭固定 56px，頁籤固定 44px，明確提供播放中、播放清單數量及點播入口。曲庫、上傳入口、YouTube、排序、移除、同步與個人音量皆接原行為；清單在自己的區塊內捲動。
- C02 六個控制使用後端實際提供的播放／暫停、回到開頭、下一筆、停止、本機對齊及發布同步。現有 API 沒有播放歷史與重複模式，沒有以裝飾按鈕假裝支援。
- 手機浮窗優先保留可用高度，必要時覆蓋過高的頁首，避免影片將清單擠出視窗。縮小、橫條、關閉續播、個人外觀與原影片同意流程保留；切換頁籤不會隱藏或重建影片宿主。
- 自動開啟的 dialog 聚焦對話框本身；只有真實指標移動或鍵盤導覽才觸發提示。Tab 焦點、無障礙名稱與鍵盤提示保留。Escape 優先關閉 popover，再處理專注模式。
- 大廳手機場地、房間列表及代碼列採明確槽位與區塊內捲動。收藏卡取消空白徽章槽，標題、預覽與操作對齊；角色頁縮短空狀態槽；共編表單保留底部提交列與內容內捲動。資料來源連結及深色規則頁對比一併修正。
- 登入、共編、題庫、禮物及音樂提交入口使用共用按鈕；保留表單關聯、pending、disabled、驗證及原資料流程。
- 玩家列表將名稱與分數分配至獨立槽位，避免窄側欄擠掉名稱。普通與專注模式保留相同側欄寬度。畫猜等待框配對主題背景與字色，實際畫布仍保留白色。
- 極簡畫家、猜歌、瞎掰王、同頻俱樂部、霧港跑團、送禮及撲克調整手機等待頁或過大的內容槽；動態內容保留既定操作／提示槽，長內容在槽內捲動。極簡畫家與猜歌補齊較矮桌機布局。

另以受控房間實際確認：

- 320×720 的媒體視窗為 304×704，頂端 8px，清單可見區約 180px；播放器高於頁首，關閉／頁籤／清單操作可達。
