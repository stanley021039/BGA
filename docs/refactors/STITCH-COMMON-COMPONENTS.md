## 共用契約

| 元件 | 行為與邊界 |
| --- | --- |
| `UiButton`、`UiDialog` | 以 `stitch` 明確選用核定色彩、字級、間距與樣式；未選用者維持原外觀。按鈕保留 pending、disabled、可及名稱與至少 44px 命中區。 |
| `stitch-tokens.scss` | 新增獨立命名的明暗語意 tokens；不按序號錯配既有 SCSS 與 legacy CSS 間距。 |
| `RoomChat`、`ReactionPicker`、`UiPopover` | 社交工具置頂；角色動作與表情分頁，聊天室 emoji 先填入草稿。保留 160 字、輸入法、失敗重試、未讀及局部捲動。彈出層不受遊戲面板裁切。 |
| `RoomMedia` | 每頁仍只有一個實例，由聊天室工具槽開啟；新視窗預設 430px，既存個人尺寸保留。支援原有拖移、縮放、橫條與小窗，影片同意獨立處理，原播放器與 API 保留。 |
| `SiteHeader` | 品牌靠左、導覽居中、頭像最右；個人設定及背景音樂音量放入頭像選單。沿用既有 music 通道，不新增全桌或 master 音量。 |
| `RoomWaitingInfo` | 三欄資訊與固定提示／操作槽，由呼叫頁提供真實設定；Draw 的就緒及開局事件、Telephone 的原開局入口維持。 |

聊天 API 沒有公開訊息作者的座位或帳號 ID，因此使用姓名首字作中性頭像槽；不按同名猜測玩家、不虛構自己的訊息標示。等待資訊使用真實設定，不把未開局的 `roundLimit=0` 誤顯示為零回合。

本批沒有將各遊戲規則、畫布輸入與媒體播放引擎合併進視覺元件。後續整合已將房間頂欄、玩家列表及 Draw／Telephone 繪畫工具接上同一份已審核規格。

## 本次實際觀察

- TypeScript 與 Vite 多頁建置完成，版號一致性與差異空白檢查通過。
- 1920×1080 桌機、1280×720 矮桌機及 390×844 手機 CSS viewport 實際觀察；受檢頁面沒有水平溢出。
- 聊天角色動作成功寫入訊息；emoji 選擇只填入草稿、返焦輸入框，按發送後清稿，聊天記錄與新彈幕均出現。
- 媒體視窗單一實例，桌機量得 430×720，手機寬度約 374px 並留在 viewport 內；橫條、小窗、完整模式皆可切換。略過影片後沒有載入 YouTube iframe。
- 頭像選單桌機／手機均在畫面內，不推動主舞台；音量由 30% 調至 31% 後還原 30%，個人遊戲設定可開啟，關閉後返焦頭像。
- Draw 等待卡正確顯示人數與每人作畫一次；改為 60 秒後同步更新卡片。加入一名腳本玩家並從卡片開局，等待資訊與房間設定收起，原畫布顯示。1280×720 的聊天訊息槽仍有高度，發送鈕可見，社交工具各約 44px 高。進入／退出專注模式正常。
- Telephone 等待卡正確顯示 90 秒／頁與畫圖／猜詞交替；人數 1→3 正確更新。開局後等待資訊與房間設定收起，原私人畫布與倒數恢復。
- 驗收操作沒有觀察到未處理的頁面例外。這些觀察涵蓋本批更改，沒有重新宣稱所有遊戲階段、第三方影片真播放、實體觸控或全裝置均已驗證。

## 房間頂欄、玩家欄與 C04 整合

- `RoomHeader` 將同一組房號、入座人數、邀請、導覽及房間操作移入頁首。專注模式透過 Teleport 移回房間內，保留同一個畫廊、邀請與管理實例。頭像維持最右側；小螢幕換列。
- 品牌圖示直接從 Figma「已同步｜共用頂欄｜C03」的原始圖層匯出 SVG，保留 26×26 viewBox；來源紀錄見 `public/assets/stitch/room-brand.source.json`。Node 以明確路徑提供該資產。
- `RoomRoster` 使用 40px 頭像、固定右側分數欄及兩行狀態槽，長姓名左對齊省略，完整姓名提示保留。遊戲提供原始狀態／雙分數／操作槽；Telephone 不虛構分數，Draw 回饋保留固定槽位。
- `DrawingToolbar`／`ColorPicker` 在 Draw、Telephone 共用。十二色、草稿式 HSV／HEX 色盤、筆粗及既有八種畫具、復原與清空；所有工具有 44px 命中區。桌機使用側欄，矮桌機及窄螢幕換成橫排。原畫布節點、筆畫輸入、REST／SSE、草稿與提交契約不變。
- 房間外框在頁首整合後以狀態列＋主面板兩列排列；共用遊戲與 Draw 均套用，Race 教學頁沒有房間操作時不套用。


### 整合後的實際觀察

- 測試站房號複製、邀請視窗、導覽選單及房主管理可操作；原始品牌 SVG 載入成功，naturalWidth 為 26。
- Draw／Telephone 在 1920×1080、1280×720 與 390×844 CSS viewport 觀察。玩家頭像 40px、分數在第三欄，長姓名由左側開始省略，Draw 回饋列約 95px 並維持固定高度。
- Draw 實際畫筆、自訂有效／無效 HEX、復原、取消清空與確認清空均可操作。專注模式切換後筆畫保留；猜題者沒有畫具且看到對方畫作。遊戲開始後房間設定收起。
- Telephone 三人開局後實際作畫，畫面顯示「伺服器已接受 1 筆」，送出後切換為不可修改等待狀態，沒有提早傳頁。修改僅共用操作外觀及布局，未改私人草稿或傳頁契約。
- Telephone 短桌機使用局部捲動保留畫布最低尺寸；1280×720 量得畫布約 556×277px，繪畫區可捲動，底部送出列保持原位置。1920 畫布約 943×471px；手機約 264×131px，均含邊框且保持原繪圖座標比例。
- 抽查送禮達人的雙分數、雷霆之路房間與獨立教學。共用房間使用 220px／彈性主欄／280px，教學頁沒有房間頂欄。受檢頁面沒有水平溢出。
- TypeScript／Vite 多頁建置、Node 語法、版本一致性與差異空白檢查完成。這批觀察不擴大為所有遊戲階段或實體裝置全數驗證。
