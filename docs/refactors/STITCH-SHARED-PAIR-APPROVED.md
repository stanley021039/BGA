## 共用契約

RoomRoster 僅負責名單、欄位、狀態轉接與容器捲動，RoomPlayerCard 持有角色、名字、分數、身份圖示、完成框線與提示外觀。各遊戲與雷霆本機教學沿用同一張卡；真實頭像、角色、分數及遊戲專屬資料從原 snapshot／slots 傳入。等待時隱藏分數；猜歌以「張」呈現真正年代卡數，前奏分保留於真實狀態；傳情不新增零分；殘酷與自動淘汰賽不顯示虛構出題者。房主為皇冠，一般真正出題／行動者為鉛筆；身份與詳細狀態可聚焦／懸停查看，不顯示「你」「在線」標籤。

郎中高資訊卡保留公開紅寶石、鼠尾、藥袋數、水滴、白色風險與女巫幣。私人／隱藏的大釜資料不推算、不回填。公開投入藥材移到所查看的大釜下方，來源僅為該公開 recipe；保留分數、寶石及玩家動畫錨點。原大釜繪製器與操作不替換。

十一款等待區統一使用插畫、介紹、真實設定摘要及房間設定槽。原設定與開始處理器各一份；Draw／MusicQuiz／Majority 用具名 Teleport 目標搬移同一實例。開局後不殘留等待設定；結算仍能修改下一局並重開。

傳情保留私人上一棒、草稿、90 秒固定傳頁、原 Canvas 筆跡與工具、跳過／清除確認、80 字限制，以及完成後才公開的故事簿。一般同頻保留秘密作答、撤回、填空分組與計分；殘酷保留真正組隊／個人／單人與一次換題；音樂／情境淘汰賽保留完整規模、曲目與音訊實例，不以設計示意內容替換。
