# 其他遊戲 Vue 遷移巡檢（2026-10-20）

## 基準與範圍

對照遷移前 v2.17.0（`9f79b8d`）的獨立服務、目前 Vue 測試站與第三份 Figma。第三份的雷霆之路、撲克、跑團及猜歌候選頁仍標為待審核；不把候選稿當成已核准的新布局。同頻俱樂部、送禮達人及瞎掰王已有新增內容設計，保留目前實作，沒有用舊圖覆蓋。共用頂欄、玩家與聊天沿用現有元件。

## 修正

- 德州撲克恢復橢圓桌、二至六人環桌座位、其他玩家的背牌、莊家、當前行動、籌碼與下注狀態。本人位於下方；私人底牌仍由原快照決定，不新增公開資料。籌碼動畫優先使用桌面座位作為起點。
- 雷霆之路補回特效所需的場景與棋盤捲動錨點，以及車輛標籤、氮氣、滑痕、射擊與命中樣式；保留既有控制器與生命週期。恢復原四輪車型、車窗、槍管、車燈與地形紋理，未更動六角座標或點擊範圍。等待頁恢復插圖及車型資訊。
- 極簡畫家在窄手機將同步與完成按鈕各置於完整一列，避免中文被擠成直排；計數保留兩欄，內容仍在既定槽位內捲動。

瀏覽器桌機採 1920×1080、1280×720，手機為 320×720 或 390×844 的視窗模擬。
