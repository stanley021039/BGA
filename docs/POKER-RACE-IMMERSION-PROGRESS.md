## 賽道動畫可見性修正

先前一般移動只有約一秒的短輪跡，車輛直接跳到終點；碰撞圓環、特殊事件卡和終局焦點則只在事件發生時短暫播放。瀏覽器若回報 `prefers-reduced-motion: reduce`，舊版會把輪跡和事件卡全部隱藏；舊的「關閉演出」儲存設定也會持續抑制動效，因此玩家可能完全看不到動畫。

新版每次確認一般移動都讓 SVG 車輛在 700 毫秒內從舊格平滑抵達新格，原有輪跡、碰撞圓環、2.2 秒事件卡與終局焦點保留。雷霆之路不再顯示或讀取動畫開關，即使系統回報減少動態、瀏覽器留有舊的關閉設定，也直接播放；音效仍預設靜音並保留控制。背景分頁、重連與教學桌不補播舊事件，事件卡仍可按「略過」或 Esc 關閉。

Windows／Linux `npm test` 各 132/132。隔離背景 Chrome 在減少動態與舊設定關閉的條件下，量到車輛位移持續變化，碰撞事件卡有進場與車輛相撞動畫且沒有頁面錯誤。正式版 `8b32222` 已部署到 shhuang.cc；公開站用測試帳號與 AI 實際走兩格，位移矩陣在 0／180／480 毫秒依序從 -44px 到 -10.6px、-0.7px，動畫開關不存在，頁面無 JavaScript 錯誤。Linux 服務、Tunnel 與 SQLite v9 完整性均正常。
