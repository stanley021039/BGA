# 撲克與末路狂飆體驗進度

本輪接續[跨遊戲沉浸感研究](IMMERSIVE-EXPERIENCE-RESEARCH.md)的第 5 項，先以已確認可用的素材做短事件回饋與入門成就。規則、牌型、車輛位置與勝負仍由伺服器決定；動畫和短音不阻塞下一步操作。

| 資源 | 已有或已確認 | 本輪取捨 |
| --- | --- | --- |
| 短介面音 | 專案內已有 Kenney Interface Sounds 的兩個短 WAV 與 CC0 授權檔，先前已供送禮達人和同頻俱樂部使用 | 重用於成功操作與已公開的重要結果；預設靜音，可調音量。專屬紙牌聲、引擎聲與碰撞聲尚未找到合適且已核對授權的素材，先不加入。 |
| 撲克牌與籌碼 | 原有 HTML/CSS 牌面和底池數字 | 翻公共牌時只讓新牌短暫落入；攤牌後完整結果立即可讀，另可播放最多三筆非阻塞焦點。沒有新增牌面圖或背景音樂。 |
| 賽道與車輛 | 原有自製 SVG 賽道、車形及公開事件資料 | 確認移動後短暫標出已知起終點；碰撞在伺服器確認的格位顯示圓環；終局完整文字即時可讀，另提供可跳過的短焦點。未知地形與骰面不提前顯示。 |
| 成就圖像 | 既有收藏冊使用自製文字與 CSS 卡片 | 增加「第一手牌」、「公路初航」及跨遊戲「第一桌」，不需要額外美術。 |

| 步驟 | 狀態與驗證 |
| --- | --- |
| 撲克牌局回饋 | **Windows 完成**。公共牌增加只針對新揭露牌的短落牌動效；結算完整結果直接顯示，最多三筆焦點可跳過與手動重播。重複輪詢、重連及背景切回不補播。成功操作才播放可選短音，失敗不播放。 |
| 賽道事件回饋 | **Windows 完成**。已確認的車位變化顯示短輪跡，碰撞在事件提供的格位顯示短圓環；終局結果直接顯示，勝負焦點可跳過與重播。事件 ID 去重，背景／重連／教學桌不自動演出。 |
| 個人控制 | **Windows 完成**。兩款各自記錄演出開關與音量；音效預設關閉，玩家手動開啟。系統「減少動態」優先關閉裝飾動效；可隨時跳過焦點，所有結果仍以文字呈現。 |
| 入門成就 | **Windows 完成**。撲克只在已結算的一手中本人有合法 HTTP 操作時給「第一手牌」，棄牌仍算；賽車需先完成有本人操作的回合並等到比賽結束才給「公路初航」。四款遊戲的有效單位都可授予「第一桌」。超時或 AI 代走不算本人操作；踢出者不授予，重試與輪詢去重。 |
| 測試與部署 | Windows `npm test` 111/111；隔離背景 Chrome 驗證撲克翻牌／結算、賽車輪跡／碰撞／終局、跳過、預設靜音、減少動態及 390px 版面。Linux 測試、正式資料庫備份與公開網域驗收待完成；公開多人實玩及聲音主觀聽感仍需玩家確認。 |

本輪沒有新增需要外部下載的資產；專屬音效與較完整的美術場景保留為後續素材工作。成就採伺服器已確認事件，不依前端播放次數。既有對局不回溯補發徽章；會員下次完成符合條件的遊玩單位時授予。
