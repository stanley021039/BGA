## 範圍與操作

沿用使用者原 Chrome 分頁，1767×1196，全程背景 DOM 操作。三個既有專用帳號，新建一局三輪；主帳號透過 Chrome 開局、選題、猜題、重新載入、開關說明及 emoji 選單。另外兩席以正常遊戲 API 準備筆畫、猜測與保活。沒有瀏覽器拖曳作畫、真人新手／熟手對照、實體網路斷線或跨設備訪談。

第一輪熱氣球由兩席猜中；第二輪垃圾車，主帳號猜中後讓另一席不回答，最後時間到；第三輪飛機，停止畫者 API 保活，伺服器以畫者斷線揭曉，之後走完原有結算。後兩轮是刻意測試 timeout／失聯，不能當作三輪全員正常作答的成功範例。
