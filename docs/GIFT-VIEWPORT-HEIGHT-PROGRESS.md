# 送禮遊戲可用高度修正

2026-10-06，候選 **v1.3.2**，程式提交及本地annotated tag指向 `df7846d4c6512f716f86e54f4460c18e8d6b1993`。包含尚未部署的v1.3.1等待按鈕間距；保留既有v1.3.1 tag，不覆寫候選內容。未 push／PR。

## 原因與實作

在1803×1190的實際Chrome頁面重現：遊戲主區 `clientHeight=560`、`scrollHeight=685`，整頁高度1190，玩家列底部814。原CSS `clamp(300px,calc(100dvh - 420px),560px)` 把主區永遠限制在560px，即使視窗更高，仍會產生局部捲軸。

一般桌機（寬大於1000px、高至少680px）改用100dvh的column flex外殼；導覽列及工具列採實際高度，剩餘空間給兩列grid，主區／操作區在第一列，玩家列採第二列的內容高度。主區只在真正超出剩餘空間時捲動。操作區保留min-content最小高度，避免較矮視窗或較長回饋時蓋住玩家列。大字模式、較矮桌機及手機沿用可自然延伸的版面。
