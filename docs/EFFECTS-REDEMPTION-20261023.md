# 五款特效修訂、收藏光暈與獎勵兌換

此紀錄補充同批未發布的 2.28.0 候選；沒有推送、PR 或部署。

## 來源與範圍

使用者提供「特效.zip」，只讀取其中 stitch_party_game_stage_picker/20_x/code.html，以靜態 DOM 解析五張指定卡片：殘火太刀、王之財寶、替身 · 近身狂拳、黑翼大魔 · 歸刃、黑暗大法師。保留原圖形、色彩與動作，轉為本機 CSS／SVG；沒有執行附檔腳本或載入其外部素材。

新版 CSS 與關鍵影格用獨立 stitch-vfx-update／stitch-update 命名範圍，只加到這五款。其他十五款保持不變；千本櫻另外的中央落花層繼續保留。既有角色、成就條件、單次播放、清理與減少動態規則不變。

## 成就與兌換

- 已達成的成就卡與已領取獎勵卡具有較亮的金色邊線、內外光暈；進頁時短暫呼吸兩次。減少動態時保留靜態光暈。
- 成就收藏冊新增「獎勵兌換」，輸入「作者們好帥」即可取得全套成就外觀獎勵：24 款成就框及播放器外觀、20 款新角色進場、所有成就背景、14 款語音與屍魂界網站開場。
- 兌換僅影響登入帳號，不增加遊玩完成次數、不偽造已達成徽章。資格由伺服器保存在帳號資料，修改形象與重啟仍保留；重複兌換不重複發放。
- 普通玩家可兌換；未登入與停用帳號不可操作。伺服器驗證固定兌換碼並限制嘗試頻率，客戶端不能透過形象設定寫入資格。
- 管理員全體重設會清除這項兌換資格；重設後可再次輸入相同碼兌換。未操作任何既有玩家的正式資料。

## Ping 配色

十種原生圖示有獨立配色；新增五款為生氣紅、睡覺紫、無言灰、驚訝橙、崇拜粉。顏色跟隨圖示，與輪盤方向和音效分開。設定預覽、Vue 方向盤、實際標記與舊版標記一致。補強標記光暈的樣式優先級，避免頁面文字配色將光暈變成深色。

## 驗證

HTTP 測試涵蓋錯誤碼與資料型別、正常兌換、重複兌換、帳號隔離、不能以形象輸入偽造資格、形象儲存與重啟保存、不偽造徽章、全體重設及重設後再兌換。靜態資源測試確認舊版收藏頁的共用光暈 CSS 可正常讀取。

Edge 實測兌換表單成功／失敗、24 款即時解鎖與重整保留、金色光暈、減少動態、390px 排版、五款新動畫實際運作，以及 Ping 方向盤／送出標記與圖示同色。證據：work/effects-redeem-browser-final.log 與 work/playtest/updated-effect-0.png 至 updated-effect-4.png、redeemed-reward-glow.png、redeem-mobile.png。

最終完整受影響測試：2,592 項，2,591 通過、0 失敗、1 項可選 ffmpeg 環境略過，證據 work/effects-redeem-affected-final.log。型別、Vite 建置、固定版本格式與版本檢查通過。首次完整檢查發現舊版光暈 CSS 的靜態路由缺漏，已補齊並以完整回歸複驗。最終瀏覽器紀錄為 effects-redeem-browser-final.log；本機 3009 是獨立試玩，既有 3006、3007、3008 未重啟。

最新修正：背景依截圖指定九款卡片改動態、共用冷卻 30 秒；兌換改四類且試玩僅開獎勵，法院降亮度並加強對比。先前較舊的單碼、60 秒、預填成就描述由 [最新紀錄](BACKGROUNDS-REWARD-CODES-20261023.md) 取代。
