# 大廳環繞移動與攻擊特效（2.37.0）

對應需求：[四邊穿越 #204](https://github.com/stanley021039/BGA/issues/204)、[F 鍵互動 #197](https://github.com/stanley021039/BGA/issues/197)。本文件記錄本機實作與驗證，不代表遠端發布。

## 行為

- WASD／方向鍵走出任一邊界，從對側接續移動；左右穿越保留縱座標，上下穿越保留橫座標。滑鼠沿用點擊目的地移動，R 沿用隨機換位及已選入場特效。
- 位置與速度由伺服器計算。方向指令只指定下一小步，不因鍵盤重複累積遠端目的地；斜向移動沿用既有速度限制。前端逐幀將位置環繞，避免跨界時插值成橫穿全螢幕；穿越不增加隨機換位／入場版本。
- 按 F，或點開桌區的發射圖示，向最近的其他大廳玩家發射共用青色能量球與金色命中環。依發射者視窗比例計算距離，同距離按穩定玩家 ID 排序。目標由伺服器選擇，事件在大廳短暫同步。
- 冷卻兩秒；按住 F 不連發；沒有目標時顯示簡短提示。輸入框、可編輯內容、組字中及開啟的對話視窗不觸發移動／F／R；切到背景或離開頁面清理動畫與按鍵狀態。
- 減少動態／關閉動態時只顯示靜態命中環；不新增音效、不更動玩家音量偏好。重連或回到前景不補播舊攻擊。
- 這是視覺互動，沒有傷害、分數、生命值或勝負變動。本批提供共用特效；自選攻擊外觀與成就綁定不在本批範圍。
