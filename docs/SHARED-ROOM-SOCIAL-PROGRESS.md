## 實作

依 [規格](specs/SHARED-ROOM-SOCIAL.md)，十款接上共用 RoomControls。聊天室提供唯一的 160 字輸入、全文紀錄與單行 40 字省略彈幕，沒有大廳發送或保留期限說明。媒體、emoji、角色表情入口集中於聊天室。離房統一確認、取消、送出中、錯誤及重試流程。

原生測試找到並修正：畫猜設定搬移後的讀取範圍與委派事件；瞎掰王的完整難度 fieldset；雷霆既有 AI 與新 botSupport 欄位差異；共用 sender 抽取測試的按鈕選取範圍。雷霆結束後的重新開始也轉接至共用開始按鈕。

## 已驗證

- VM 上使用合成資料與獨立連接埠執行，沒有讀寫正式房間或正式資料。
- Headless 原生 Chrome：十款 × 1440／390px × light／dark，共 40 組等待畫面；沒有水平溢出，可見操作按鈕至少 44px。
- 十款房主與一般玩家操作：開始與 AI 權限、41 字完整紀錄／40 字省略彈幕、媒體與表情位置、設定儲存、AI 入座、開局、離房取消與返回對應遊戲大廳。頁面 JS 錯誤為零。一般玩家沒有房主開始／AI 按鈕。
- 畫猜原生頁面：15 次持筆採樣，ACK 前後筆跡不消失；觀看者有逐點播放樣本；倒數前進；猜中後揭曉並切至第二輪不同畫者。
- 離房：Escape 取消；503 保持入座；重試期間確認／取消停用；Escape 無法取消已送出操作；一次重試成功回大廳。
- 程式測試覆蓋十款 160 個 emoji 的完整訊息與截短、舊 social API 的相同 requestId 重試、跨房／踢出／離席限制、40／41／161 字界線、不合法框不可留下部分紀錄，以及十個頁面的共用資源契約。

Linux VM Node 22.22.1：`npm test` **2049／2049 通過**，失敗、取消、跳過均為零，412534ms。完整測試後補充的純彈幕 CSS 與舊互動開關隱藏，另以原生頁面及相關測試複驗。彈幕四種框 × 1440／390px × 動畫開／關，共 16 組：內容均單行；動畫時框寬包含完整短彈幕，靜態模式在框內省略超出螢幕的內容。
