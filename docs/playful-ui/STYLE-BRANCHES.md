# Afterhours 視覺風格與分支策略

更新日期：2026-10-08

## 目前完成的風格

名稱：**Playful Paper｜繽紛紙卡**；識別碼：`playful-paper`。

大型原創插畫卡片、明亮粉彩、粗邊框與紙卡陰影構成全站視覺。各遊戲依玩法保留不同排版，統一區塊對齊、間距與共用操作元件。保留大廳角色移動、遊戲棋盤、API、即時同步與帳號設定暱稱。

| 分支 | 用途 |
| --- | --- |
| `style/playful-paper` | 原 `codex/playful-board-game-ui` 重新命名；此風格的後續維護分支。 |
| `archive/playful-paper-v1.17.1` | 從本次完成版本複製的保存分支，包含風格文件；後續不在此直接開發。 |

兩個分支在建立時指向同一份程式與文件提交。保存分支是完整 Git 歷史的另一個引用，不是另一套資料庫或部署。正式版本仍為 `v1.17.1`／`35c1e519d7fc2ae6ab52e9ef0e41d48d36bb933e`；發行 tag 不移動。文件提交不升版、不重新部署。部署證據見 [全站發布紀錄](full-site/deployment.md)，截圖及驗收見 [全站改造](full-site/README.md)。本次分支操作在 Linux Git 專案完成，尚未推送 GitHub。

## 使用者決策：未來讓玩家選擇不同風格

未來可能製作多套視覺風格，讓大家在同一個平台選擇自己喜歡的外觀。這是產品方向，目前只有繽紛紙卡風格已完成並部署；尚未實作風格選單、偏好儲存或即時切換。

新風格採 `style/<style-id>` 分支開發並驗收，完成時可建立 `archive/<style-id>-v<version>` 保存。共同功能修正應同步到需要的風格分支；避免每個分支長期複製各自的遊戲邏輯。分支用於開發與保存，玩家實際選擇應由同一份應用程式的主題系統處理。

## 後續實作方向（提案，尚未完成）

1. 使用既有架構，把顏色、字體、間距、邊框、陰影、動效與插畫資產整理成可註冊的主題；以穩定 style-id 識別，保留共用元件語意與功能契約。
2. 讓個人設定選擇主題。主題屬於每位玩家的顯示偏好，不改變房間設定、遊戲結果或其他玩家的外觀；登入偏好與訪客預設值的儲存方式另行設計。
3. 六款遊戲、大廳、登入、等待房、個人頁、Navigation 和 Dialog 都須涵蓋；未知或失效主題應回退到可用預設主題，避免無樣式頁面。
4. 保留玩法各自需要的布局；任何主題都要維持區塊對齊、繁中可讀性、玩家／回合狀態辨識及行動效率。主題不可覆寫 API、權限、帳號暱稱或同步流程。
5. 每套風格驗收 Desktop／Tablet／Mobile、鍵盤焦點、對比、reduced motion、200% 文字、隱藏／disabled／pending 狀態，以及多人同步；提供前後截圖及相關回歸測試。切換不重載對局、不丟畫猜筆跡、不造成棋盤跳動是後續驗收條件，尚未驗證。

建立新風格前先確認視覺方向，再以大廳作基準擴展全站。不因一頁漂亮就視為整套風格完成，也不以保存分支代表玩家已能切換主題。
