# 郎中原生圖像代稱保留契約

使用者於2026-10-20明確要求：保留之前本機的藥材顯示與範例，特效藥亦同；維持UI圖像代稱，滑過才顯示完整文字。後續任何人不得改這部分，除非使用者特別指定。

- 不把規則文字解析成新圖示串或算式。上一輪試作的詞彙解析器已刪除，取代其相關說明及測試。
- `QuacksRuleVisual.vue` 僅顯示既有藥材、病患、資源或操作圖像，完整伺服器說明放title／aria-label，保留鍵盤焦點。
- `QuacksFlask.vue` 直接使用整合前本機既有 `public/quacks-art.js` 的 `essenceFlask`，恢復原藥瓶與0–10圓形軌道；逐格保留該病患原獎勵文字於SVG title／aria-label。可選格與確認動作沿用原權限，未達格可查看提示但不送出。
- 藥材效果面改回既有藥材圖像代稱，頁碼控制縮成緊湊翻面入口；不常駐長段效果文字、不重寫來源中的說明／例子。價格、採購與庫存規則不變。
- 主AGENTS、郎中目錄AGENTS、本機永久記憶已明確記錄保留規則；目前未推送，其他協作者需取得這批規則才會看到。

回歸檢查在 `tests/quacks-visual-rules.test.js`：圖像接線、完整hover／可及性文字、不允許解析效果prose、原生藥瓶使用及選格guard。型別、production build與格式檢查另行執行；本輪沒有把全套單元測試等同所有畫面的視覺驗收。
