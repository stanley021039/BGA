# 郎中 Stitch 與畫猜共用介面

2026-10-15，候選 2.7.0。以完成的畫猜 2.6.1 預覽與最新郎中控制器為整合基礎，保留既有遊戲引擎；早期郎中 Stitch 原型只提供視覺、圖片與動態參考，沒有覆蓋較新的規則和操作。

## 共用契約

兩個遊戲的等待室由 `GameUI.Template.patterns.waitingScene` 組裝相同準備提示、插畫介紹、名冊／空席、邀請連結、設定入口與操作列；`RoomWaiting`、`RoomControls` 持有原房間設定與權限。郎中在開局後切回自己的三欄大釜場景，避免通用作畫舞台再建立另一份名冊和聊天室。

聊天室使用同一份 `SharedChat`、`GameShell`、`GameUI` 與媒體元件，保留原有全部表情、角色分頁、吐槽、快速文字、彈幕、個人音量及媒體清單。等待室把完整聊天室宿主移入共同視窗，開局後移回原聊天欄，沒有複製另一個輸入框或傳送器。郎中也接入既有 `RoomHost` 管理入口与状态回调，等待室保留房間管理，開局後移入更多選單。

動態面板、採購操作列與提示槽预留寬高。桌機名冊、大釜／採購與聊天上下緣對齊，名冊及商品在既定區塊捲動；手機換列並保留必要資訊。

## 郎中行為

- 大釜 53 格保留金幣數字。中央提示由單一宿主管理，離開格子或鍋內空白區即關閉，點選留下焦點也不阻止滑鼠離開關閉；鍵盤、Escape、觸控點選外部和放大視窗沿用同一提示生命週期。
- 常駐皇冠／成就底欄移到「更多房間工具」，環形記分板、放大、成就與原連結保留。藥材寶典由按鈕開啟，逐色查看本局效果。
- 採購保留原生按鈕及購買／取消指令，以藥材圖片、面值、金幣數字、勾選與已購藥袋呈現。預算不足仍禁用，已購可再點取消並退回原藥材與金額。不可用商品仍有獨立的效果查看入口。
- 原兩步房間設定／選書開局、自動保存、最新共選藥材效果、原平票狀態處理、AI、女巫、病患／特效藥、額外抽藥、藥水瓶、溢出盆、結算與歷史入口保留。額外煮藥選擇移到帶數量的更多選單，保留原按鈕和處理函數。
- 圖片飛行、漣漪、危險、爆炸、女巫與分數動畫遵守 `MotionPolicy`。原抽卡、抽藥、喝藥水、爆炸與結算音檔保留；額外購物／紅寶石／女巫音效接入 `AudioSettings`，每次狀態輪詢更新 `GameSounds` 連線基線，避免停留商品頁一段時間後沒有聲音。
- 新增六段可重建原創合成 WAV，来源和 SHA256 在 `quacks-synthesis.json`。合成瓶聲使用 `quacks-potion-synth.wav`，不覆蓋既有使用者瓶聲 `quacks-potion.wav`。实际喝藥水仍使用原瓶聲。

## 本輪實際驗收

使用隔離測試資料及原生瀏覽器操作，未執行自動測試套件。以下只記錄本輪觀察，不把先前版本的九回合或雙人實玩當作此次結果。
