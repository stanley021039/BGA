# 九款進場特效設計原型

追蹤：#400。來源：[Stitch 專案](https://stitch.google.com/projects/16226792553515652128)。

最終可播放檔為 **stitch-final.html**。直接以瀏覽器開啟，不需登入或下載依賴。先選款式，點播放／重播；時間軸與毫秒欄位可停格；「結尾＋1秒檢查」檢查清場。

Stitch R3 為設計與生命周期基礎；最終稿另修正六款分鏡、手機鏡像與版面。R2／R3／R4 僅留本機歷史封存，不納入本批最終交付。storyboard-renderers.js 是修正來源，已內嵌於最終 HTML，播放不需另外載入。

九款稀有度與需求保持原指示；動畫清場時程依序為 2.2、2.8、3.5、3.2、1.9、2.4、2.1、2.5、3.3 秒。

這份 HTML 仍是獨立設計原型；九款已另外接入本機 3.32.0 遊戲候選（尚未合併／部署），驗收詳規格最新實裝節。角色為示意，正式整合必須接入玩家角色與既有資源預算／取消機制。Figma 匯入依使用者指示延後。詳細驗收與限制見 ../../specs/NINE-STITCH-ENTRANCES-400.md。
