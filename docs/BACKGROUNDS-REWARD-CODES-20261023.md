使用者透過截圖確認來源為 背景.zip 的 stitch_party_game_stage_picker/party_game_lobby_9/code.html 中「9 款精選動態舞台背板」的九張卡片。直接讀取 #cardsGrid .stage-card 的 SVG 與原頁動態 CSS，沒有採用同包其他展示頁或該頁 script 中不同版本的全尺寸 stageTemplates。

九款為城堡、暮色花園、法院、宇宙、舞廳、教室、監獄、實驗室、極光雪山。保留原圖、圖形層次與動畫，沿用原有背景 ID 和成就條件；其他既有背景未混入不同匯出稿，也未移除。正式執行使用本機靜態 JSON 與 CSS，不執行附檔腳本或載入外部素材。

依後續指定，法院牆面改成較柔和的灰藍大理石色，柱線、柱座、頂部輪廓加深，減少陽光泛白。既有天秤與光塵動態保留。法院場景的標題、計數、玩法與授權短文字加上隨日／夜模式變化的襯底，避免亮牆或深色講台吃掉文字。

動態 SVG 直接放在大廳背景層，避免 CSS 背景圖片無法跟隨個人動態開關；關閉動態、減少動態及頁面隱藏均暫停，離頁移除監聽。各實例的 SVG 漸層 ID 會重新命名，避免互相覆蓋。選單縮圖使用同一批新圖形的靜態版本。
