# 同頻俱樂部：互動體驗與逐步實作

更新日期：2026-10-02。依[五個視角的討論結論](IMMERSIVE-EXPERIENCE-RESEARCH.md#五個視角的討論結論)，優先處理秘密作答、等待、公開票數及分數的閱讀節奏。伺服器一公開結果，完整文字資料就可讀；演出只在本機、可跳過，不能延後房主操作。新玩法「猜朋友」、觀眾投票及長背景音樂暫緩。

| 步驟 | 可驗收的成果 | 狀態 |
| --- | --- | --- |
| 0. 資源與規則盤點 | 對照五視角結論、現有介面、伺服器公開界線及素材授權 | **完成**；此表列出可用與暫緩資源。 |
| 1. 作答與完整揭曉 | 自己交卷後顯示倒扣便箋和等待進度；公開後立即看見所有答案組、票數、玩家及每人得分 | **完成本機驗證**。未公開時只看自己的答案，揭曉時顯示完整票數、玩家、每人本題得分及目前總分；填空的房主合併介面保留。3 人選擇題與填空、8 人平手畫面已檢視。 |
| 2. 可選的局部演出 | 票數分布有短暫焦點，可跳過／重播；減少動態、背景切回及重連不自動播放 | **完成本機驗證**。最多三組、每組 650 毫秒；完整結果與下一題按鈕始終可操作。只從作答／審核正常轉入揭曉才自動開始，直接重連停在靜態結果。隔離 Chrome 驗證重播、跳過、關閉演出、390px 無水平溢出及系統減少動態。 |
| 3. 個人音效控制 | 預設靜音；成功提交與新揭曉才播短音，可關閉並調音量 | **程式完成，聽感待實機確認**。沿用已入庫的 Kenney CC0 短音；成功交卷且仍在作答／審核時播確認音，首次轉入揭曉時播短開啟音。預設靜音、可調音量，背景分頁不播，音效失敗不影響操作。 |
| 4. 入門成就 | 有效提交一題並正式揭曉後，授予私人「第一次舉牌」；不要求得分，重複輪詢不重發 | **完成本機驗證**。伺服器依帳號座位、正式結算與本人答案授予一次；未揭曉、未交卷、中途等下一題及被踢者不授予。SQLite 重複寫入去重，不修改原分數；收藏冊只供本人查看。單元與 HTTP 測試涵蓋 0 分揭曉、未參與者及重複回合。 |
| 5. 驗證與部署 | 3／8 人、二／三選一與填空、平手、未交卷、中途加入、重連、窄版、減少動態及公開站驗證 | **本機驗證完成；公開站待切換**。Windows 全套 `npm test` 106/106；隔離 Chrome 檢查 3 人交卷／填空審核／揭曉、8 人平手、390px 版面與控制、減少動態。伺服器既有測試涵蓋中途加入、重連、平手及未交卷；公開網域多人實玩、短音聽感仍待確認。 |

同頻遊戲規則與題庫不因本輪體驗修改。若部署須重啟正式服務，先確認目前房間狀態；記憶體房間會在重啟時消失。
