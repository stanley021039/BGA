# 2026-10-05 正式站畫猜驗收

本批桌機介面修改已提交 [GitHub PR #30](https://github.com/stanley021039/BGA/pull/30)，尚未合併。依使用者要求，發出 PR 後改為試玩你畫我猜；沿用原 Chrome 分頁，全程背景 DOM 操作，沒有提高視窗。正式程式仍是部署來源 `9f041d3`，本次沒有更動遊戲程式或重新部署。

三個專用測試帳號完成一局三輪，每人當一次畫者，題目為熱氣球、飛機、公車。主帳號透過 Chrome 選題、選色、填色、復原、猜题、發送文字／emoji 彈幕與收藏；另外兩席透過正式遊戲 API 入座、選題、提交筆畫與猜測。封閉輪廓由筆畫 API 準備，沒有把 API 作畫宣稱為瀏覽器滑鼠拖曳驗收。
