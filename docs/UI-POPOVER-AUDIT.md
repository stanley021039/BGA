# 展開內容與資訊可見性驗收

本批由使用者回報的雷霆之路「車隊、提示與紀錄」錯位開始，並依新指示先恢復重要資訊。舊版比較與 I／F／D 評分見 [資訊優先級](UI-INFORMATION-PRIORITY.md)；分數不能用來把低頻但會影響決策的資訊藏起來。

## 浮層合約

偶爾使用的選單以實際觸發按鈕／summary 的 `getBoundingClientRect()` 定位，優先向下，空間不足才向上；左右平移保留 8px 邊界。長內容限制可用高度並在內容內捲動，避免把第一個控制裁掉。支援的瀏覽器以原生 manual popover top layer 顯示，避開祖先 overflow 及不同 stacking context；沒有 Popover API 時採 fixed 定位。捲頁、視窗／文字尺寸變更與動態內容重新量測；觸發按鈕離開可視區或被隱藏時收起。

Outside click、Escape、重新按入口可關閉；Escape 返回可見入口。原生 dialog 保留 modal 與鍵盤焦點，不能用提高 z-index 模擬。重要名單／車隊／骰子不適用浮層合約，直接在主布局中顯示。
