# PR 審查指南

合併到 `main` 前，完成以下兩個分開的審查回合。可由同一位 agent 開 PR、自行審查與合併；Draft、測試、逐項回覆、版號及 UI 驗收依 `AGENTS.md` 執行。

## 分工與範圍

實作者可自行完成兩個審查回合，不需要另外安排 reviewer 或分開上下文。先做規格符合性審查，再做程式品質與風險審查，分別留下結論；修正與複查也可由同一位 agent 完成。

兩個回合使用相同的 base、head、merge-base SHA 與 commit 範圍，直接讀差異、必要呼叫端和測試，分別留下結論。引用已確認的 spec／計畫、驗收條件與後續決策；沒有正式 spec 時用已確認的任務需求，列出假設與缺漏，不把提案或作者摘要當作完成證據。

## 第一回合：規格符合性

- 逐項對照需求與驗收條件，連到實作／測試／操作證據，標「符合、部分符合、不符合、待確認或不適用」
- 檢查漏做、超出範圍、失敗與邊界流程、相容性，以及尚未確認的取捨
- UI 改動沿用專案的桌機／手機、可及性、作畫過程與共用元件驗收，不能只看最終截圖
- 核對文件與實作狀態，依既有打版規範檢查版號及 CHANGELOG；純文件不因此升版

## 第二回合：程式品質與風險

依改動風險檢查，不適用可註明：

- **邏輯與回歸**：追到實際可達的輸入、呼叫端與狀態轉換，檢查極值、失敗、重試、取消、重連及既有功能
- **安全與秘密**：檢查身分／資源權限、輸入與輸出界線，以及本次 diff、commits、新增檔、日誌、測試資料與發布資源的秘密風險；gitignore 不代表安全。疑似密鑰只提供不含秘密的定位，通知維護者處理，不貼值到公開評論
- **同步與資料**：檢查重複提交、亂序、競態、鎖、跨房間／回合隔離、交易、migration、舊資料、備份與中斷／回退路徑
- **效能與維護**：檢查相關資源上限、查詢、廣播、釋放、共用契約及回歸測試；效能結論附量測或可驗證路徑，不因個人風格要求無關重構，不重複報 lint 已負責的項目

問題要有可達條件與證據；合理懷疑標待驗證，不直接稱為已確認漏洞。

## 證據、修正與複查

區分「實作階段已執行」「審查階段執行或複驗」「只讀程式」；引用他人提供的證據時註明來源。測試記錄命令、環境、SHA，以及通過／失敗／未執行／受阻；focused、全套、瀏覽器與 CI 分開列。CI pending、未設定或無法查看均不算通過。測試前確認副作用，使用隔離資料，不因審查觸碰正式資料或取得額外權限。

每個 finding 給穩定編號、所屬審查、嚴重度、固定 SHA 的檔案／行號、觸發條件、預期與實際、影響及修正／驗證方向；規格問題另附需求位置。高＝重大安全／資料或主要流程問題，中＝功能／規格／回歸問題，低＝有限影響或維護建議。未解的重大安全、資料、功能或規格問題須先修正並複驗。

作者在原 PR 逐項回覆已修正／不同意／延後及原因。修正後複驗相關 finding、相鄰路徑與必要回歸，可由同一位 agent 完成。Head、base、需求或相依項改變時，先比較差異，受影響結論標待複查；未受影響的可附理由保留，不盲目重跑全部，也不沿用過期通過。

未發現問題時寫「本次已檢查範圍未發現問題」，保留限制，不保證沒有 bug。兩個回合的報告分開保留，彙整不能隱去分歧或未驗項目。

## 合併前確認

同一位 agent 可在兩個審查回合完成、測試與必要檢查全部通過，且無未解重大問題後，自行合併 PR。合併前確認報告與 CI 對應目前 head，平台已有規則仍須滿足；Ready 本身不代表審查或檢查已通過。

測試失敗、CI pending、必要檢查受阻或仍有重大問題時，先修正、複驗或回報阻礙，不自行視為通過。緊急 hotfix 也須如實記錄已檢查與未驗證範圍、風險及後續安排；無法滿足上述條件時，回報使用者決定下一步。

摘要可標「待審查／待複查」「待檢查／受阻」「先修正」或「可合併」，並說明證據及剩餘風險。合併不包含部署；部署與正式資料操作仍需明確授權。

## 精簡回報範本

```text
PR／任務、日期、實作者／審查者（人類／AI，可為同一位）：
Base／head／merge-base SHA、commit 範圍：
Spec／計畫／需求版本、範圍與假設：

規格符合性：逐項狀態、實作／證據、缺口
程式品質與風險：檢查路徑、結論、未驗項目
Findings：ID、所屬審查、嚴重度、SHA／檔案／行號、
          需求位置、觸發條件、預期與實際、影響／建議
測試：實作階段／審查階段／只讀，外部證據來源；命令、環境、SHA、結果
CI：對應 SHA、通過／失敗／pending／未設定／無法確認
修正與複查：finding ID、修正 SHA、結果及剩餘風險
合併前確認：兩回合完成、測試及必要檢查通過、無未解重大問題
總結狀態、剩餘風險、受阻原因及後續安排
```
