# 畫猜高解析度與 Figma 版面驗證

2026-10-14，相容修正候選 2.5.2。

`StrokeCanvas.createDrawingRenderer` 將實際 raster 提高到 1536 × 768，直接繪製向量路徑。傳送座標仍為 512 × 256，筆刷粗細、quadratic 跨包拼接、pointTimes、POST／SSE、計分與額度不變。填色 seed 依 context transform 轉換到實際像素，所有畫猜呼叫端使用相同 raster scale；預設 generic renderer 供其他繪圖入口使用。

作畫、揭曉、最近畫作、結算縮圖、收藏與 PNG／ZIP 共用此入口。高解析度 renderer 最多保留五個快取大小的表面，預設快取像素合計小於 24 MiB；此數值不代表整個頁面的記憶體上限。收藏維持原圖片大小限制，必要時縮小已完成的 raster，不能重新計算另一解析度的填色。PNG 下載保留 1536 × 768。

清空採用共用網站確認對話框；確認後重新檢查作畫權限及 round／canvasEpoch，避免舊對話框清掉下一輪。聊天標題與工具採不同 DOM 槽，狀態文字不會移除表情、媒體及房間操作。

原生瀏覽器驗證：

- 雙席持筆途中可看到部分曲線，畫者放開後保留完整曲線；確認與下一輪未觀察到舊筆跡回灌。此為有限輸入 trace，未量測所有畫面或裝置的 FPS。
- 實際直線、矩形、區域填色、填色復原、橡皮擦、清空後再畫及公開回看均完成。
- PNG 實際下載檔為 1536 × 768；收藏與取消收藏完成。
- 1440 × 946 桌機與 390 × 844 窄螢幕檢查；窄螢幕無水平溢出、工具可換列，亮暗切換保持白色作畫紙；深色粗細 label 與數值有對比。
- 表情分類／角色表情可載入，聊天工具在選題、作畫及結算仍存在；兩席回合按原規則出現畫者 15 分與猜題者的實際分數。
- JS 語法、Git whitespace、發行 metadata 與測試站七份資源 SHA256 核對完成。此輪未執行自動測試套件；高量筆畫／填色及真實觸控筆仍未驗。

Figma 原生匯出已讀等待室房主、畫者工作台的 design context，其他狀態以相同元件及既有功能呈現。尚未完成其餘所有 flow 的原生 Figma frame 匯入與逐一像素比對，不能宣稱全部畫面已完全一致。
