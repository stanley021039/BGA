## 實作

- 撲克、末路狂飆、同頻、送禮、你畫我猜、跑團、傳情畫意、猜歌、極簡、瞎掰及郎中都使用 `RoomSceneLayout`。十款經 `GameRoomPage` 接入，畫猜保留獨立中央版型並直接使用同元件。
- `RoomBackground` 共用移動、Q/E 配裝、R 瞬移、四向穿越、表情及倒地墓碑；活著不顯示血條。伺服器所有房間都提供 `roomSpace`，未來遊戲使用共用房間版型即可繼承後續場景功能，不需要逐遊戲啟用名單。
- 每桌位置及戰鬥仍依房間實例隔離，不改遊戲分數、版本、私人牌面、畫布或勝負。保留專注模式、背景檢視／Esc、手機互斥抽屜、inert 與焦點返回。
- 畫布上的方向鍵交給作畫工具；已處理的按鍵、輸入框、組字、對話框及 inert 區域不觸發角色快捷鍵。畫猜以 display:contents 排卡，因此中央畫板與猜題卡需各自位於背景上方，避免背景攔截選題或作畫。
