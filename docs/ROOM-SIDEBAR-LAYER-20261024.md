# 場景左右側欄的殘留底板

2026-10-24，本機候選，未提交／發布。

使用者提供雷霆之路截圖，進一步確認是左右側欄收合後各留下大片底板，郎中也有。檢查範圍是原先確認的十一款房間遊戲，不包含股市。

## 已確認原因與範圍

`room-surfaces.scss` 的舊 C00 桌面外框規則仍匹配 `has-room-space`。它在整桌 grid 以及兩側欄位上指定不透明底色與框線；新 `RoomSidePanel` 只有內部 `UiPanel` 滑出，整桌／欄位的舊底色仍留在原處。桌機深色下實際取樣為 `rgb(21,21,22)`，因此看起來像左右多卡一層。

十一款都重現：德州撲克、雷霆之路、同頻俱樂部、送禮達人、你畫我猜、霧港跑團、傳情畫意、猜歌挑戰、極簡畫家、瞎掰王、郎中闖江湖。等待室與開局後都受到影響，並非某款遊戲新增了私人遮罩。

## 修正

只調整 `room-surfaces.scss` 的三處適用範圍：普通面板表面排除 `vue-room-side-panel`，舊 roster 框與整桌框排除 `has-room-space`。新場景的底板由 `RoomSidePanel` 內部 `UiPanel` 負責。展開時保留面板，收合後只剩 32px 框邊與原箭頭；必要遊戲內容卡、畫布、彈窗與捲動區仍保留自己的外觀。

未加入 !important、提高 UI baseline 或逐遊戲覆寫。未修改伺服器、遊戲規則與玩家資料。

## 證據

- 修正前對十一款各取等待／開局、1920×1080／390×844，桌機 22 個狀態全部有舊不透明整桌底板。
- 修正後十一款 × 等待／開局 × 桌機／手機 × 深／淺色，共 88 組，grid 及兩側宿主都為透明且沒有舊框線，無 pageerror／水平溢出。沒有彈窗時，側欄空白區的 hit-test 可到達場景背景。
- 十一款各實測左右面板展開／收合；桌機實際可見框邊約 32px，內容收合後 inert。手機兩種抽屜、主內容 inert 與 Esc 返回皆通過。
- CSS 回歸測試使用實際 Sass 編譯及 DOM selector 匹配；對修改前來源，兩個新場景案例失敗、兩個舊版型案例通過；修正版 4/4 通過，並保留真正內容卡的表面。
